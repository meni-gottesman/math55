02The six skills

Each card says when to use it, the method, a worked example, and the classic mistake.

1 · Extended Euclid gcd(a, b) = sa + tb

When
“Find gcd and integers s, t”, or any time you need an inverse.
Do
Forwards: divide, then replace (a, b) by (b, r) until the remainder is 0. The last nonzero remainder is the gcd.
Backwards: solve the second-to-last line for the gcd, then substitute the line above it, and keep going up. Collect terms after every substitution.
Speed version (table): keep columns r, s, t where every row means r = s·a + t·b. Start with rows (a, 1, 0) and (b, 0, 1). Each new row = row two above − q × row above. The row before the 0 gives the answer.
Example
gcd(84, 33):
84 = 2·33 + 18 3 = 18 − 1·15 33 = 1·18 + 15 = 18 − (33 − 18) = 2·18 − 33 18 = 1·15 + 3 ← gcd = 2(84 − 2·33) − 33 = 2·84 − 5·33 15 = 5·3 + 0 check: 168 − 165 = 3 ✓

The q in each row is the quotient when the row above is divided by this row's r.
Trap
Arithmetic slips in the back-substitution. Always plug s, t back in to check. It takes 10 seconds.

2 · Inverse mod m find ā with aā ≡ 1

When
“Find an inverse of a modulo m”, or you need to divide in a congruence.
Do
An inverse exists iff gcd(a, m) = 1. Extended Euclid gives 1 = sa + tm, so s is the inverse. Reduce s into 0…m−1. Small m: just try multiples.
Example
Inverse of 33 mod 84? gcd = 3, so none. Inverse of 11 mod 26: 26 = 2·11 + 4, 11 = 2·4 + 3, 4 = 3 + 1, so 1 = 4 − 3 = 4 − (11 − 2·4) = 3·4 − 11 = 3(26 − 2·11) − 11 = 3·26 − 7·11. s = −7 ≡ 19. Check: 11·19 = 209 = 8·26 + 1 ✓
Trap
Leaving the answer negative (−7). Write −7 ≡ 19 (mod 26). Also: you want the coefficient of a, not of m.

3 · Solve ax ≡ b (mod m)

Do
1. d = gcd(a, m).
2. If d ∤ b: no solution.
3. Else write d = sa + tm. Then x₀ = (b/d)·s.
4. All solutions: x₀ + k·(m/d). That's exactly d answers in 0…m−1.
Example
12x ≡ 8 (mod 20). d = gcd(12, 20) = 4 and 4 | 8 ✓. 20 = 12 + 8, 12 = 8 + 4, so 4 = 12 − 8 = 12 − (20 − 12) = 2·12 − 20, so s = 2. x₀ = (8/4)·2 = 4. m/d = 5, so x ≡ 4 (mod 5): x = 4, 9, 14, 19. Check 12·9 = 108 ≡ 8 ✓
Trap
Giving one answer when d > 1. The quiz will want all d of them in 0…m−1, or the form x ≡ x₀ (mod m/d).

4 · Chinese remainder theorem

When
Several congruences x ≡ aᵢ (mod mᵢ) with pairwise coprime mᵢ. There's a unique answer mod M = m₁m₂⋯.
Do
M = product. Mᵢ = M/mᵢ (the product of the other moduli). yᵢ = inverse of Mᵢ mod mᵢ (reduce Mᵢ mod mᵢ first, it's tiny). Then x = Σ aᵢMᵢyᵢ, reduced mod M.
Why: mod mᵢ, every other term has mᵢ hiding inside its Mⱼ, so it's 0, and Mᵢyᵢ ≡ 1.
Example
x ≡ 1 (mod 3), x ≡ 4 (mod 5), x ≡ 6 (mod 7). M = 105.
M₁ = 35 ≡ 2 (mod 3) inverse of 2 mod 3 → y₁ = 2 M₂ = 21 ≡ 1 (mod 5) → y₂ = 1 M₃ = 15 ≡ 1 (mod 7) → y₃ = 1 x = 1·35·2 + 4·21·1 + 6·15·1 = 70 + 84 + 90 = 244 ≡ 34 (mod 105)
Check: 34 = 11·3+1 ✓, 34 = 6·5+4 ✓, 34 = 4·7+6 ✓. Back-substitution also works: x = 6 + 7t, then plug into the others one at a time.
Trap
Using the inverse of mᵢ instead of the inverse of Mᵢ. Forgetting to reduce mod M at the end.

5 · Big powers: repeated squaring + Fermat

Do
If the modulus p is prime and p ∤ a: ap−1 ≡ 1, so replace the exponent n by n mod (p − 1).
Then (or if the modulus isn't prime): square repeatedly, a, a², a⁴, a⁸, …, reducing each time. Write the exponent in binary and multiply the matching squares.
Example
41000 mod 13: 13 is prime, so the exponent works mod 12. 1000 = 83·12 + 4, so 41000 ≡ 4⁴ = 256 = 19·13 + 9 ≡ 9.
345 mod 20 (not prime, so square):
3¹ ≡ 3, 3² ≡ 9, 3⁴ ≡ 81 ≡ 1, 3⁸ ≡ 1, 3¹⁶ ≡ 1, 3³² ≡ 1 45 = 32 + 8 + 4 + 1 → 3⁴⁵ ≡ 1·1·1·3 = 3 (mod 20)
Trap
Reducing the exponent mod p instead of mod p − 1. Using Fermat with a composite modulus.

6 · RSA

Setup
Primes p, q. n = pq. φ = (p−1)(q−1). Pick e with gcd(e, φ) = 1.
Public: (n, e). Private: p, q, d where d = inverse of e mod φ.
Encrypt: c = me mod n. Decrypt: m = cd mod n.
Example
p = 7, q = 13: n = 91, φ = 6·12 = 72. e = 5 (gcd(5, 72) = 1). 72 = 14·5 + 2, 5 = 2·2 + 1, so 1 = 5 − 2·2 = 5 − 2(72 − 14·5) = 29·5 − 2·72, so d = 29. Check 5·29 = 145 = 2·72 + 1 ✓.
Encrypt m = 2: c = 2⁵ = 32. Decrypt: 3229 mod 91 gives back 2 (by repeated squaring: 32² ≡ 23, 32⁴ ≡ 74, 32⁸ ≡ 16, 32¹⁶ ≡ 74; 29 = 16+8+4+1 → 74·16·74·32 ≡ 2 ✓).
Trap
Finding d mod n instead of mod φ = (p−1)(q−1). Mixing up which numbers are public.

04Flashcards

Say the answer out loud, then tap.

Bézout's theorem

For positive integers a, b there are integers s, t with gcd(a, b) = sa + tb. Extended Euclid finds them.

The lemma that makes Euclid work

If a = bq + r then gcd(a, b) = gcd(b, r): a, b and b, r have exactly the same common divisors.

When does a have an inverse mod m?

Exactly when gcd(a, m) = 1. It's the s in 1 = sa + tm, and it's unique mod m.

When is ax ≡ b (mod m) solvable?

Exactly when d = gcd(a, m) divides b.

How many solutions does ax ≡ b (mod m) have?

d of them mod m (when d | b): x₀ + k(m/d) for k = 0, …, d − 1.

When can you cancel c from ac ≡ bc (mod m)?

When gcd(c, m) = 1 (multiply by c's inverse). Counterexample otherwise: 2·3 ≡ 4·3 (mod 6) but 2 ≢ 4.

gcd(a, b) = 1 and a | bc ⇒ ?

a | c. (1 = sa + tb, multiply by c: c = sac + tbc, and a divides both terms.)

p prime and p | ab ⇒ ?

p | a or p | b. Fails for composites: 6 | 3·10 but 6 ∤ 3 and 6 ∤ 10.

Chinese remainder theorem

If m₁, …, mₙ are pairwise relatively prime, then x ≡ aᵢ (mod mᵢ) for all i has a solution, and it's unique mod M = m₁⋯mₙ.

CRT construction formula

x = Σ aᵢMᵢyᵢ where Mᵢ = M/mᵢ and yᵢ is the inverse of Mᵢ mod mᵢ.

Fermat's little theorem

p prime, p ∤ a ⇒ ap−1 ≡ 1 (mod p). For every a: ap ≡ a (mod p).

Freshman's dream

(x + y)p ≡ xp + yp (mod p) for p prime, because p divides C(p, k) for 0 < k < p. That's the key step in the lecture's proof of Fermat.

an mod a prime p: what do you do to n?

Reduce n mod (p − 1), as long as p ∤ a.

Fermat primality test

If an−1 ≢ 1 (mod n) then n is definitely composite. If ≡ 1, it proves nothing.

Pseudoprime vs Carmichael number

Pseudoprime to base b: a composite n with bn−1 ≡ 1 (mod n). Carmichael: a composite that passes for every b coprime to n (e.g. 561 = 3·11·17).

RSA: what's public, what's private?

Public: n = pq and e. Private: p, q, (p−1)(q−1), and d.

RSA: how do you get d?

d is the inverse of e mod (p−1)(q−1). Needs gcd(e, (p−1)(q−1)) = 1; find it with extended Euclid.

Why does RSA decryption work?

mde = m·(m(p−1)(q−1))k. By Fermat that's ≡ m mod p and mod q, so ≡ m mod n by CRT uniqueness.

When is m ↦ me mod p one-to-one?

When gcd(e, p − 1) = 1. The inverse is c ↦ cd with de ≡ 1 (mod p − 1).

Why is Euclid fast?

Every two steps the remainder at least halves. So if a < 2ⁿ it takes at most 2n steps.

05Proof skeletons

The short proofs from Lectures 10–11. Know the one key move in each.

Lemmaa = bq + r ⇒ gcd(a, b) = gcd(b, r)

Show the two pairs have the same common divisors. If d | a and d | b, then d | a − bq = r. If d | b and d | r, then d | bq + r = a. Same set of common divisors, so the same greatest one.

Corgcd(a, b) = 1 and a | bc ⇒ a | c

Bézout: 1 = sa + tb. Multiply by c: c = csa + ctb. a | csa, and a | ctb because a | bc. So a | c.

Thmp prime, p | ab ⇒ p | a or p | b

If p | a, done. Otherwise p ∤ a; p's only positive divisors are 1 and p, so gcd(a, p) = 1. By the corollary, p | b.

Thmgcd(a, m) ∤ b ⇒ ax ≡ b (mod m) has no solution

By contraposition. If ax ≡ b, then ax − b = km for some k, so b = ax − km. d = gcd(a, m) divides a and m, so it divides ax − km = b.

Thmd = gcd(a, m) | b ⇒ a solution exists

Write d = sa + tm and b = cd. Then a(cs) = c(sa) = c(d − tm) ≡ cd = b (mod m), since m ≡ 0.

ThmCancellation: ac ≡ bc and gcd(c, m) = 1 ⇒ a ≡ b

gcd(c, m) = 1 gives an inverse c̄ with cc̄ ≡ 1. Multiply both sides by c̄: a ≡ a(cc̄) ≡ b(cc̄) ≡ b (mod m).

ThmCRT existence

Let M = m₁⋯mₙ and Mᵢ = M/mᵢ. Since the moduli are pairwise coprime, gcd(Mᵢ, mᵢ) = 1, so Mᵢ has an inverse yᵢ mod mᵢ. Set x = Σ aⱼMⱼyⱼ. Mod mᵢ, each Mⱼ with j ≠ i contains the factor mᵢ, so it's ≡ 0, leaving x ≡ aᵢMᵢyᵢ ≡ aᵢ·1 = aᵢ.

ThmFermat's little theorem

Write a = 1 + 1 + ⋯ + 1 and use the Freshman's dream repeatedly: ap = (1 + (a−1))p ≡ 1 + (a−1)p ≡ ⋯ ≡ 1 + 1 + ⋯ + 1 = a (mod p). If p ∤ a, gcd(a, p) = 1, so cancel one a: ap−1 ≡ 1.

ThmRSA decrypts correctly (case gcd(m, n) = 1)

de = 1 + k(p−1)(q−1), so cd ≡ mde = m·x with x = mk(p−1)(q−1). Mod p: x = (mp−1)k(q−1) ≡ 1 by Fermat. Same mod q. 1 also solves both congruences, so by uniqueness in the CRT x ≡ 1 (mod pq). So cd ≡ m (mod n).

Proof rules still apply: say “by contraposition” or “assume for a contradiction” in the first line.

06Traps

  • Negative answers. −7 mod 26 is 19. Answers live in 0…m−1 unless the question says otherwise.
  • One answer when there are d. ax ≡ b (mod m) with d = gcd(a, m) > 1 has d solutions mod m.
  • Cancelling illegally. Never divide a congruence by c unless gcd(c, m) = 1.
  • CRT inverses. yᵢ inverts Mᵢ (the product of the other moduli) mod mᵢ. And the moduli must be pairwise coprime.
  • Fermat's exponent. Reduce it mod p − 1, not p, and only if p is prime and p ∤ a.
  • RSA's d. Inverse of e mod (p−1)(q−1), not mod n.
  • Euclid line order. Write it as “dividend = quotient · divisor + remainder”, with 0 ≤ remainder < divisor.
  • Always plug back in. Every answer on this quiz can be checked in seconds. Do it.

07Just in case: induction

The syllabus put induction on Thu Oct 8. If it was covered, a quiz question could be a simple induction proof.

Idea
Dominoes: if the first one falls (base case) and each falling domino knocks over the next (inductive step), then they all fall.
Template
To prove P(n) for all n ≥ 1: Base case: check P(1). Inductive step: “Assume P(k) for some k ≥ 1” (the inductive hypothesis). Use it to prove P(k + 1). Conclude P(n) for all n ≥ 1 by induction.
Example
1 + 2 + ⋯ + n = n(n + 1)/2. Base: 1 = 1·2/2 ✓. Step: assume 1 + ⋯ + k = k(k + 1)/2. Then 1 + ⋯ + k + (k + 1) = k(k + 1)/2 + (k + 1) = (k + 1)(k + 2)/2, which is P(k + 1) ✓.
Strong
Strong induction: in the step, assume P(1), …, P(k) all hold, not just P(k). Use it when k + 1 breaks into smaller pieces (e.g. every n ≥ 2 is a product of primes). Well-ordering: every nonempty set of positive integers has a least element.
Trap
Assuming what you want to prove (P(k + 1)). Skipping the base case.
