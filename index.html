Lecture 7 · Rosen §4.1–4.2

07Divisibility, mod, bases, fast powers

7.1 · Divisibility a | b

Idea
“a divides b” means b is a whole-number multiple of a. 3 | 12 because 12 = 3·4.
Rule
For a ≠ 0: a | b ⟺ b = a·c for some integer c. Write a ∤ b for “doesn't divide.”
Facts: if a | b and a | c, then a | (b + c), and more generally a | (mb + nc) for any integers m, n. If a | b then a | bc. If a | b and b | c then a | c.
Example
3 | 12 ✓   5 ∤ 12   7 | 0 ✓ (0 = 7·0)   −4 | 12 ✓ (12 = (−4)(−3)).
Prove: if 3 | x and 3 | y then 3 | 5x − 2y.
Step 1, unpack the definition: x = 3s and y = 3t for integers s, t.
Step 2, substitute: 5x − 2y = 15s − 6t.
Step 3, factor out the 3: = 3(5s − 2t), and 5s − 2t is an integer, so 3 | 5x − 2y. ∎
Every divisibility proof is this: turn “divides” into “= a·(integer)”, do algebra, then factor a back out.
Trap
“a | b” is a sentence (true or false). b/a is a number. Never write “3 | 12 = 4.”

7.2 · Division algorithm a = dq + r

Idea
Long division with a remainder. Divide a by d: you get a quotient q and a leftover r that's smaller than d.
Rule
For any integer a and positive d there are unique q, r with a = dq + r and 0 ≤ r < d.
q = a div d, r = a mod d. To find them: q = a/d rounded down, then r = a − dq.
Example
47 ÷ 10: 4.7 rounds down to 4, r = 47 − 40 = 7. So 47 = 10·4 + 7: 47 div 10 = 4, 47 mod 10 = 7.
Negative: −11 ÷ 3 = −3.67. Round down means toward −∞, so q = −4 (not −3). r = −11 − 3(−4) = −11 + 12 = 1. So −11 = 3(−4) + 1 and −11 mod 3 = 1. Check 0 ≤ 1 < 3 ✓.
Another: −47 mod 6. −47/6 = −7.83, so q = −8 and r = −47 + 48 = 1.
Trap
The remainder is never negative. −11 = 3(−3) − 2 is wrong because r = −2 < 0.

7.3 · Congruence a ≡ b (mod m)

Idea
Picture a clock with m hours, labeled 0 to m − 1. a ≡ b (mod m) means a and b land on the same spot. 17 and 2 land on the same spot of a 5-hour clock.
Rule
a ≡ b (mod m) ⟺ m | (a − b). Two equivalent ways to say it: a mod m = b mod m (same remainder), or a = b + km for some integer k.
You can add, subtract, multiply, and raise both sides to powers: if a ≡ b and c ≡ d then a + c ≡ b + d and ac ≡ bd. So reduce numbers first, then compute.
Example
17 ≡ 2 (mod 5) since 5 | 15. Also 17 ≡ −3 (mod 5) since 5 | 20.
Compute (347·58 + 1001) mod 9 without big numbers.
Reduce each piece: 347 = 38·9 + 5, so 347 ≡ 5. 58 = 6·9 + 4, so 58 ≡ 4. 1001 = 111·9 + 2, so 1001 ≡ 2.
Combine: 5·4 + 2 = 22 ≡ 4 (mod 9). (The real number 21127 also leaves remainder 4.)
Use negatives to save work: 10⁵ mod 11. 10 ≡ −1, so 10⁵ ≡ (−1)⁵ = −1 ≡ 10.
Trap
You can't divide/cancel freely: 2·3 ≡ 4·3 (mod 6), but 2 ≢ 4 (mod 6). (Lecture 10 says when you can.)
mod vs ≡: “a mod m” is a number in 0…m−1; “a ≡ b (mod m)” is a true/false statement. 17 ≡ −3 (mod 5) is true; “17 mod 5 = −3” is false.

7.4 · Base-b numbers

Idea
Base 10 uses place values 1, 10, 100, … Base b uses place values 1, b, b², b³, … and digits 0 … b−1. (Base 16 uses A = 10, …, F = 15.) Every positive integer has exactly one base-b expansion.
Rule
To decimal: multiply each digit by its place value and add.
From decimal: divide by b over and over. The remainders are the digits, last digit first, so read them bottom-up.
Example
(1101)₂ = 1·8 + 1·4 + 0·2 + 1·1 = 13.   (2A)₁₆ = 2·16 + 10 = 42.
100 to base 3:
100 = 33·3 + 1 ← last digit 33 = 11·3 + 0 11 = 3·3 + 2 3 = 1·3 + 0 1 = 0·3 + 1 ← first digit read up: 100 = (10201)₃
Check: 1·81 + 0·27 + 2·9 + 0·3 + 1 = 100 ✓. Why it works: dividing by 3 peels off the last base-3 digit, just like dividing by 10 peels off the last decimal digit.

7.5 · Fast modular powers repeated squaring

Idea
To get an mod m, don't multiply n times. Square repeatedly to get a, a², a⁴, a⁸, … (reduce mod m each time), then multiply the ones whose exponents add up to n (that's n in binary).
Example
5¹³ mod 7.
5¹ ≡ 5 5² = 25 ≡ 4 (25 = 3·7 + 4) 5⁴ ≡ 4² = 16 ≡ 2 (each line squares the line above) 5⁸ ≡ 2² = 4 13 = 8 + 4 + 1 (13 in binary is 1101) 5¹³ = 5⁸·5⁴·5¹ ≡ 4·2·5 = 40 ≡ 5 (mod 7)
Only 5 multiplications instead of 12, and no number ever gets bigger than 6·6.
Trap
Reduce after every multiplication. Square the reduced value, not the original.

Lecture 8 · Rosen §4.3

08Primes, gcd, lcm, Euclid

8.1 · Primes & factorization

Rule
Prime: an integer p > 1 whose only positive divisors are 1 and p. Otherwise (if > 1) it's composite. 1 is neither.
Fundamental Theorem of Arithmetic: every integer > 1 is a product of primes in exactly one way (up to order).
Primality test: if n is composite, it has a prime factor ≤ √n. So only try primes up to √n.
Example
Factor 924: 924 = 2·462 = 2·2·231. 231 = 3·77 = 3·7·11. So 924 = 2²·3·7·11. (Peel off the smallest prime that divides, repeat.)
Is 97 prime? √97 ≈ 9.8, so test 2, 3, 5, 7. None divide 97, so it's prime. No need to test 11 or higher: if 97 = ab with both factors ≥ 11, then ab ≥ 121.
Thm
There are infinitely many primes. Assume for a contradiction there are only finitely many, p₁, …, pₙ. Let Q = p₁p₂⋯pₙ + 1. Dividing Q by any pᵢ leaves remainder 1, so no pᵢ divides Q. But Q > 1 has some prime factor, and it isn't on the list. Contradiction! ∎ (Q itself needn't be prime: 2·3·5·7·11·13 + 1 = 59·509.)

8.2 · Divisibility, gcd, lcm from factorizations

Idea
Write both numbers with the same primes (use exponent 0 for a missing prime). Then compare exponents prime by prime.
Rule
a | b ⟺ every exponent in a ≤ the matching exponent in b.
gcd(a, b) = the largest number dividing both: take the min exponent of each prime.
lcm(a, b) = the smallest positive number both divide: take the max exponent.
gcd(a, b) · lcm(a, b) = a·b, because min + max = the two exponents added.
a, b are relatively prime if gcd(a, b) = 1. A list is pairwise relatively prime if every pair is.
Example
a = 600 = 2³·3¹·5²·7⁰ and b = 126 = 2¹·3²·5⁰·7¹.

Does a | b? No: the exponent of 2 in a is 3 > 1. Does 2²·3 | 2³·3²·5? Yes: 2 ≤ 3 and 1 ≤ 2.

gcd(0, n) = n (everything divides 0). gcd(−12, 18) = 6: the gcd is always positive.

8.3 · Euclidean algorithm gcd without factoring

Idea
Factoring big numbers is slow. Euclid's trick: gcd(a, b) = gcd(b, a mod b). The numbers shrink fast, and when the remainder hits 0 you're done.
Why
If a = bq + r, then anything dividing a and b also divides r = a − bq, and anything dividing b and r also divides a = bq + r. So the pairs (a, b) and (b, r) have the same common divisors, and therefore the same gcd.
Example
gcd(252, 198):
252 = 1·198 + 54 gcd(252,198) = gcd(198,54) 198 = 3·54 + 36 = gcd(54,36) 54 = 1·36 + 18 = gcd(36,18) 36 = 2·18 + 0 = gcd(18,0) = 18
Each line divides the previous divisor by the previous remainder. The answer is the last nonzero remainder: 18. Check: 252 = 2²·3²·7 and 198 = 2·3²·11 give gcd 2·3² = 18 ✓.
Speed
Every two steps the remainder at least halves, so it takes at most about 2·log₂(a) steps.

Lecture 10 · Rosen §4.3–4.4

10Bézout, inverses, solving congruences

10.1 · Bézout & extended Euclid gcd(a, b) = sa + tb

Idea
Bézout's theorem: the gcd can always be written as an integer combination of a and b. Getting s and t is the key to everything else in this lecture.
How
Run Euclid forwards. Then go backwards: solve the second-to-last line for the gcd, and keep replacing the smallest remainder using the line above it. Collect terms after every substitution.
Example
gcd(84, 33) as s·84 + t·33:
FORWARDS BACKWARDS 84 = 2·33 + 18 3 = 18 − 1·15 (line 3, solved for 3) 33 = 1·18 + 15 = 18 − (33 − 18) (15 = 33 − 18, from line 2) 18 = 1·15 + 3 ← gcd = 2·18 − 33 (collect: two 18s) 15 = 5·3 + 0 = 2(84 − 2·33) − 33 (18 = 84 − 2·33, from line 1) = 2·84 − 5·33 (collect: −4·33 − 33)
So 3 = 2·84 − 5·33 with s = 2, t = −5. Check: 168 − 165 = 3 ✓. Each step only uses the line above, and you stop once only 84 and 33 remain.
Faster
Table method (same answer, fewer slips): keep columns r, s, t, where each row means r = s·84 + t·33. Start with (84, 1, 0) and (33, 0, 1). Each new row = (row two up) − q·(row above), where q is the quotient from Euclid.

10.2 · Two facts Bézout gives you

Thm
If gcd(a, b) = 1 and a | bc, then a | c. Proof: 1 = sa + tb. Multiply by c: c = sac + tbc. a divides sac, and a divides tbc (since a | bc), so a | c.
Thm
If p is prime and p | ab, then p | a or p | b. Proof: if p ∤ a, then gcd(a, p) = 1 (p's only divisors are 1 and p), so p | b by the fact above. Fails for non-primes: 6 | 3·10 but 6 ∤ 3 and 6 ∤ 10.

10.3 · Inverses mod m “dividing” in mod world

Idea
An inverse of a mod m is a number ā with a·ā ≡ 1 (mod m). It plays the role of 1/a.
Rule
a has an inverse mod m ⟺ gcd(a, m) = 1, and it's unique mod m. Find it with extended Euclid: 1 = s·a + t·m, so s·a ≡ 1 (mod m) and s is the inverse (reduce it into 0…m−1). For small m, just try multiples.
Example
Inverse of 11 mod 26. Euclid: 26 = 2·11 + 4, 11 = 2·4 + 3, 4 = 1·3 + 1. Backwards: 1 = 4 − 3 = 4 − (11 − 2·4) = 3·4 − 11 = 3(26 − 2·11) − 11 = 3·26 − 7·11.
The coefficient of 11 is −7, and −7 + 26 = 19. Check: 11·19 = 209 = 8·26 + 1 ✓.
Inverse of 33 mod 84? gcd = 3 ≠ 1, so none. (33x is always a multiple of 3, and so is 84k, so 33x − 84k can never equal 1.)
Trap
Leaving it negative (−7). Taking the coefficient of m instead of a.

10.4 · Solving ax ≡ b (mod m)

Recipe
1. d = gcd(a, m).
2. If d ∤ b → no solution. (ax − km is always a multiple of d, so it can't equal b.)
3. Else write d = s·a + t·m. Then x₀ = (b/d)·s is a solution.
4. All solutions: x ≡ x₀ (mod m/d). That's exactly d answers in 0…m−1.
Shortcut when d = 1: x ≡ ā·b (multiply both sides by the inverse).
Example
7x ≡ 3 (mod 10). gcd = 1. Inverse of 7 mod 10 is 3 (7·3 = 21 ≡ 1). Multiply both sides by 3: x ≡ 9. Check 7·9 = 63 ≡ 3 ✓.
12x ≡ 8 (mod 20). d = gcd(12, 20) = 4, and 4 | 8, so it's solvable. Euclid: 20 = 1·12 + 8, 12 = 1·8 + 4, so 4 = 12 − 8 = 12 − (20 − 12) = 2·12 − 20, so s = 2. x₀ = (8/4)·2 = 4. Step size m/d = 5, so x = 4, 9, 14, 19 (4 answers, since d = 4). Check 12·9 = 108 = 5·20 + 8 ✓.
12x ≡ 7 (mod 20): 4 ∤ 7, so no solution.
Cancel
Cancellation law: if ac ≡ bc (mod m) and gcd(c, m) = 1, then a ≡ b (mod m). (Multiply by c's inverse.) Without gcd = 1 it fails, like 2·3 ≡ 4·3 (mod 6).

11CRT, Fermat, RSA

11.1 · Chinese remainder theorem

Idea
Knowing x's remainder mod 3, mod 5 and mod 7 pins x down completely mod 3·5·7 = 105, as long as the moduli share no common factors.
Rule
If m₁, …, mₙ are pairwise relatively prime, then x ≡ aᵢ (mod mᵢ) for all i has a solution, and it is unique mod M = m₁⋯mₙ.
Build it: Mᵢ = M/mᵢ (the product of the other moduli), yᵢ = inverse of Mᵢ mod mᵢ, then x = Σ aᵢMᵢyᵢ mod M.
Example
x ≡ 1 (mod 3), x ≡ 4 (mod 5), x ≡ 6 (mod 7). M = 105.
M₁ = 105/3 = 35. 35 ≡ 2 (mod 3). Inverse of 2 mod 3 is 2 (2·2=4≡1) → y₁ = 2 M₂ = 105/5 = 21. 21 ≡ 1 (mod 5). → y₂ = 1 M₃ = 105/7 = 15. 15 ≡ 1 (mod 7). → y₃ = 1 x = 1·35·2 + 4·21·1 + 6·15·1 = 70 + 84 + 90 = 244 ≡ 34 (mod 105)
Why it works: mod 3, the terms 4·21 and 6·15 vanish (21 and 15 are multiples of 3), and 35·2 ≡ 1, so x ≡ 1·1 = 1 ✓. The same thing happens mod 5 and mod 7. Each term is “1 on its own modulus, 0 on the others.”
Check 34: 34 = 11·3 + 1 ✓, 34 = 6·5 + 4 ✓, 34 = 4·7 + 6 ✓.
Alt
Back-substitution: x ≡ 6 (mod 7) means x = 6 + 7t. Plug into mod 5: 6 + 7t ≡ 4, so 1 + 2t ≡ 4, so 2t ≡ 3, so t ≡ 4 (multiply by 3, the inverse of 2). Now x = 34 + 35u. Mod 3: 34 + 35u ≡ 1 + 2u ≡ 1, so u ≡ 0. So x ≡ 34 (mod 105). Same answer.
Trap
yᵢ inverts Mᵢ, not mᵢ. Moduli must be pairwise coprime (x ≡ 0 mod 2 and x ≡ 1 mod 4 has no solution). Reduce mod M at the end.

11.2 · Fermat's little theorem

Rule
If p is prime and p ∤ a, then ap−1 ≡ 1 (mod p). For every a: ap ≡ a (mod p).
Use: mod a prime, exponents only matter mod p − 1. Write n = q(p−1) + r; then an = (ap−1)q·ar ≡ 1·ar.
Example
3¹⁰⁰ mod 7. 7 is prime and 7 ∤ 3, so 3⁶ ≡ 1. 100 = 16·6 + 4, so 3¹⁰⁰ = (3⁶)¹⁶·3⁴ ≡ 1·81 ≡ 4 (81 = 11·7 + 4).
4¹⁰⁰⁰ mod 13. Exponents work mod 12: 1000 = 83·12 + 4, so 4¹⁰⁰⁰ ≡ 4⁴ = 256 ≡ 9 (256 = 19·13 + 9).
Why
Freshman's dream: (x + y)p ≡ xp + yp (mod p), because p divides every middle binomial coefficient C(p, k). Write a = 1 + 1 + ⋯ + 1 and apply it repeatedly: ap ≡ 1 + 1 + ⋯ + 1 = a. Then cancel one a (allowed since gcd(a, p) = 1).
Test
Primality test: if an−1 ≢ 1 (mod n), then n is definitely composite. If it ≡ 1, n might still be composite. Example: 2¹⁴ mod 15 = 4, so 15 is composite. A composite that passes for base b is a pseudoprime; one that passes for every b coprime to n is a Carmichael number (561).
Trap
Reduce the exponent mod p − 1, not p. Only for prime moduli, and only if p ∤ a. For a composite modulus, use repeated squaring (7.5).

11.3 · RSA

Idea
Public-key encryption works like an open padlock. Anyone can lock a message with the public key (n, e), but only the owner knows d, which unlocks it. Security comes from factoring n being hard.
Setup
1. Pick primes p, q. Let n = pq and φ = (p−1)(q−1).
2. Pick e with gcd(e, φ) = 1. Public key: (n, e).
3. d = inverse of e mod φ (extended Euclid). Private: p, q, d.
4. Encrypt: c = me mod n. Decrypt: m = cd mod n.
Example
p = 7, q = 13 → n = 91, φ = 6·12 = 72. e = 5 works (gcd(5, 72) = 1).
Find d: 72 = 14·5 + 2, 5 = 2·2 + 1. Back: 1 = 5 − 2·2 = 5 − 2(72 − 14·5) = 29·5 − 2·72. So d = 29 (check: 5·29 = 145 = 2·72 + 1 ✓).
Encrypt m = 2: c = 2⁵ = 32 mod 91 = 32.
Decrypt: 32²⁹ mod 91 by repeated squaring: 32² ≡ 23, 32⁴ ≡ 74, 32⁸ ≡ 16, 32¹⁶ ≡ 74. Since 29 = 16 + 8 + 4 + 1, the product 74·16·74·32 ≡ 2 ✓, the original message.
Why
de = 1 + k(p−1)(q−1), so cd = mde = m·(m(p−1)(q−1))k. By Fermat this is ≡ m mod p and ≡ m mod q, so ≡ m mod pq by the uniqueness part of the CRT.
Trap
d is the inverse of e mod (p−1)(q−1), not mod n. n and e are public; p, q, d are secret.

From earlier chapters

★Proof tools you'll need

Defs
even: n = 2k; odd: n = 2k + 1 (k an integer). In mod language: n ≡ 0 or n ≡ 1 (mod 2). Use a different letter for each number (m = 2j + 1, n = 2k + 1).
Direct
Assume the hypothesis, unpack the definitions, and do algebra until the conclusion appears (like 7.1).
Contra­position
To prove p → q, prove ¬q → ¬p. Write “By contraposition” first. Example: “if 3 ∤ ab then 3 ∤ a” is the same as proving “if 3 | a then 3 | ab”, which is easy.
Contra­diction
Assume the opposite and reach something impossible (infinitely many primes, √2 irrational). Start with “Assume for a contradiction” and end by naming the contradiction.
Cases mod m
Every integer is ≡ 0, 1, …, m−1 (mod m), so you can check each case. Example: n² mod 3 is always 0 or 1. If n ≡ 0, n² ≡ 0. If n ≡ 1, n² ≡ 1. If n ≡ 2, n² ≡ 4 ≡ 1. So n² ≢ 2 (mod 3) ever.
“iff”
Prove both directions separately, labeled (⇒) and (⇐).

Definition of a | b

a ≠ 0 and b = ac for some integer c.

a | b and a | c ⇒ ?

a | mb + nc for all integers m, n (in particular a | b + c).

Division algorithm

For integer a and d > 0: unique q, r with a = dq + r and 0 ≤ r < d. q = a div d, r = a mod d.

−11 mod 3 = ?

1, since −11 = 3(−4) + 1. Round the quotient down, and the remainder is never negative.

m | (a − b). Same as a mod m = b mod m, same as a = b + km.

What can you do to congruences?

Add, subtract, multiply, raise to powers. Not divide, unless the divisor is coprime to m.

Decimal → base b

Divide by b repeatedly; the remainders are the digits, read from the last one up.

Repeated squaring

Compute a, a², a⁴, a⁸, … mod m; write n in binary; multiply the matching powers.

Prime

An integer p > 1 whose only positive divisors are 1 and p. 1 is not prime.

Every integer > 1 is a product of primes in exactly one way, up to order.

How far do you test to see if n is prime?

Primes up to √n. A composite always has a prime factor ≤ √n.

Why are there infinitely many primes?

For any finite list, p₁⋯pₙ + 1 leaves remainder 1 when divided by each one, so its prime factors aren't on the list.

gcd / lcm from factorizations

gcd: min of the exponents. lcm: max. And gcd·lcm = ab.

a | b from factorizations

Euclid's key lemma

a = bq + r ⇒ gcd(a, b) = gcd(b, r). Stop when the remainder is 0; the gcd is the last nonzero remainder.

Bézout's theorem

gcd(a, b) = sa + tb for some integers s, t. Find them with extended Euclid.

gcd(a, b) = 1 and a | bc ⇒ ?

a | c.

p prime, p | ab ⇒ ?

p | a or p | b. False for composites: 6 | 3·10.

When does a have an inverse mod m?

Exactly when gcd(a, m) = 1. It's the s from 1 = sa + tm.

When is ax ≡ b (mod m) solvable, and how many solutions?

When d = gcd(a, m) divides b. Then there are d solutions mod m, spaced m/d apart.

ac ≡ bc (mod m) and gcd(c, m) = 1 ⇒ a ≡ b (mod m).

For pairwise coprime moduli, the system x ≡ aᵢ (mod mᵢ) has a unique solution mod M = ∏mᵢ.

x = Σ aᵢMᵢyᵢ, with Mᵢ = M/mᵢ and yᵢ = Mᵢ⁻¹ mod mᵢ.

p prime, p ∤ a ⇒ ap−1 ≡ 1 (mod p). For every a, ap ≡ a.

(x + y)p ≡ xp + yp (mod p) for p prime.

Fermat test says an−1 ≢ 1 (mod n). Conclusion?

n is composite. (If it is ≡ 1, you can't conclude anything.)

Public (n, e) with n = pq. Private d = e⁻¹ mod (p−1)(q−1). c = me, m = cd (mod n).

∎Proof skeletons

The short proofs from these lectures. Each has one key move.

L7a | b and a | c ⇒ a | b + c

b = sa, c = ta, so b + c = (s + t)a. Similarly bc = (sc)a gives a | bc.

L7a ≡ b, c ≡ d (mod m) ⇒ a + c ≡ b + d and ac ≡ bd

m | a − b and m | c − d. Sum: (a + c) − (b + d) = (a − b) + (c − d). Product: ac − bd = c(a − b) + b(c − d). m divides each piece, so m divides the total.

L8Infinitely many primes

Assume for a contradiction p₁, …, pₙ are all the primes. Q = p₁⋯pₙ + 1 leaves remainder 1 on division by each pᵢ, so no pᵢ divides Q. Q > 1 has a prime factor, which isn't on the list. Contradiction!

L8a = bq + r ⇒ gcd(a, b) = gcd(b, r)

If d | a and d | b then d | a − bq = r. If d | b and d | r then d | bq + r = a. Same common divisors, so same gcd.

L8gcd(a, b)·lcm(a, b) = ab

Exponent of each prime: min(aᵢ, bᵢ) + max(aᵢ, bᵢ) = aᵢ + bᵢ (check both cases aᵢ ≤ bᵢ and aᵢ > bᵢ).

L10gcd(a, b) = 1 and a | bc ⇒ a | c

1 = sa + tb, so c = sac + tbc. a | sac, and a | tbc since a | bc. So a | c.

L10gcd(a, m) ∤ b ⇒ no solution

By contraposition: if ax ≡ b, then b = ax − km. d divides a and m, so d | b.

L10d | b ⇒ a solution exists

d = sa + tm and b = cd. Then a(cs) = c(d − tm) ≡ cd = b (mod m).

L10Cancellation law

gcd(c, m) = 1 gives an inverse c̄. Multiply ac ≡ bc by c̄: a ≡ b.

L11CRT existence

gcd(Mᵢ, mᵢ) = 1, so yᵢ exists. Mod mᵢ, every Mⱼ with j ≠ i contains mᵢ, so it's ≡ 0. That leaves x ≡ aᵢMᵢyᵢ ≡ aᵢ.

L11Fermat's little theorem

ap = (1 + ⋯ + 1)p ≡ 1p + ⋯ + 1p = a by the freshman's dream. If p ∤ a, cancel one a to get ap−1 ≡ 1.

L11RSA decrypts (gcd(m, n) = 1)

mde = m·(m(p−1)(q−1))k ≡ m mod p and mod q by Fermat, so ≡ m mod n by CRT uniqueness.

!Traps

  • Negative remainders. −11 mod 3 = 1, not −2. Always land in 0…m−1.
  • Dividing congruences. Only cancel c when gcd(c, m) = 1.
  • Base conversion order. The first remainder is the last digit. Read bottom-up.
  • Repeated squaring. Square the reduced number and reduce every time.
  • 1 isn't prime, and p₁⋯pₙ + 1 isn't necessarily prime.
  • gcd vs lcm. gcd uses the smaller exponents, lcm the larger.
  • Euclid's answer is the last nonzero remainder.
  • Missing solutions. ax ≡ b has d = gcd(a, m) solutions mod m.
  • CRT. Invert Mᵢ (not mᵢ) mod mᵢ; the moduli must be pairwise coprime.
  • Fermat. Reduce exponents mod p − 1, only for prime p with p ∤ a.
  • RSA. d inverts e mod (p−1)(q−1), not mod n.
  • Check by plugging in. Every computation here takes seconds to verify.
