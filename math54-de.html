Nagle 4.5 · Superposition

The one piece of Chapter 4 not in your notes yet: what to do when the forcing is a sum.

1y = yₕ + yₚ and superposition

Big idea

Find one solution yₚ of the forced equation, any one at all. Then every solution is yₚ plus a solution of the unforced (homogeneous) equation. It’s exactly like Ax = b: particular solution plus the null space.

y = yₕ + yₚ = c₁y₁ + c₂y₂ + yₚyₕ: general solution of L[y] = 0 (recap idea 1). yₚ: any single solution of L[y] = g.

Why: if y is any solution, then L[y − yₚ] = g − g = 0, so y − yₚ is homogeneous, i.e. equals c₁y₁ + c₂y₂.

Superposition principle

L[y₁] = g₁, L[y₂] = g₂ ⟹ L[k₁y₁ + k₂y₂] = k₁g₁ + k₂g₂So if the forcing is a sum, find a particular solution for each piece separately and add them.
Trap

The sum of two solutions of L[y] = g solves L[y] = 2g, not L[y] = g. The solutions of a nonhomogeneous equation do not form a subspace. But the difference of two of them solves the homogeneous equation.

D3 · Linear systems

Nagle 9.1, 9.4 (plus matrix calculus from 9.3). Several unknown functions changing together, written with matrices.

2Systems in normal form; converting higher-order equations

Big idea

Stack the unknowns into a vector x(t). A linear system becomes one equation x′ = Ax + f, which looks just like a first-order scalar ODE. Any higher-order linear ODE can be rewritten this way, so systems include all of Chapter 4.

x′(t) = A(t)x(t) + f(t)Normal form: x = (x₁, …, xₙ) unknown, A(t) an n×n coefficient matrix, f(t) the forcing. Homogeneous if f = 0.

Converting an n-th order equation

  1. Solve for the highest derivative.
  2. Name x₁ = y, x₂ = y′, …, xₙ = y(n−1).
  3. Then x₁′ = x₂, x₂′ = x₃, …, and xₙ′ = (the highest derivative from step 1).
Example · y‴ − 2y″ + y′ − 5y = sin t
  1. y‴ = 5y − y′ + 2y″ + sin t.
  2. x₁ = y, x₂ = y′, x₃ = y″.
  3. x₁′ = x₂, x₂′ = x₃, x₃′ = 5x₁ − x₂ + 2x₃ + sin t.
x′ = [0 1 0; 0 0 1; 5 −1 2] x + (0, 0, sin t)A companion matrix: ones above the diagonal, the coefficients (moved to the right side) on the bottom row.
Example · the link to Chapter 4

y″ − y′ − 6y = 0 becomes x′ = [0 1; 6 1]x. Its eigenvalues solve det[−λ 1; 6 1−λ] = λ² − λ − 6 = 0: the same polynomial as the auxiliary equation, roots 3 and −2. Eigenvalues of the companion matrix = roots of the auxiliary equation, always.

Trap

Signs on the bottom row: move everything except the highest derivative to the right side first. y″ + 3y′ + 2y = 0 gives bottom row (−2, −3), not (2, 3).

3Matrix calculus basics

Big idea

A matrix of functions is differentiated and integrated entry by entry. The usual rules hold, except you must keep products in order.

(d/dt)[aᵢⱼ(t)] = [aᵢⱼ′(t)],   ∫ [aᵢⱼ(t)] dt = [∫ aᵢⱼ(t) dt]And (AB)′ = A′B + AB′ (order matters!), (CA)′ = CA′ for a constant matrix C.
Example

M(t) = [t² e2t; sin t 1]. Then M′(t) = [2t 2e2t; cos t 0] and ∫₀¹ M dt = [1/3 (e² − 1)/2; 1 − cos 1 1].

Checking a proposed solution is just matrix calculus: compute x′ entrywise, compute Ax, compare.

Example · check x = e3t(1, 1) solves x′ = [1 2; 2 1]x
  1. x′ = 3e3t(1, 1).
  2. Ax = e3t(1 + 2, 2 + 1) = 3e3t(1, 1). Equal ✓.
Trap

(A²)′ = A′A + AA′, which is not 2AA′ unless A and A′ commute.

4Fundamental solution sets, fundamental matrix, Wronskian

Big idea

Exactly as for second-order equations (recap idea 2): the solutions of x′ = A(t)x (n×n) form an n-dimensional vector space. Find n independent solutions and you have all of them.

The theorems

  • Existence–uniqueness: if A(t), f(t) are continuous on an interval I containing t₀, then x′ = Ax + f, x(t₀) = x₀ has exactly one solution, valid on all of I.
  • Dimension n: same argument as before. The map x ↦ x(t₀) is a linear bijection from solutions to ℝⁿ.
  • Fundamental solution set: n linearly independent solutions x₁, …, xₙ. Fundamental matrix: X(t) = [x₁ ⋯ xₙ] (solutions as columns). It satisfies X′ = AX.
  • General solution: x = X(t)c = c₁x₁ + ⋯ + cₙxₙ; for the forced system, x = X(t)c + xₚ.
W(t) = det X(t) = det [x₁(t) ⋯ xₙ(t)]For solutions of x′ = Ax: either W(t) ≠ 0 for every t in I (fundamental set) or W ≡ 0 (dependent). In fact W(t) = W(t₀)·exp(∫ tr A), and an exponential is never 0.

Why one point suffices: if W(t₀) = 0, some combination c₁x₁(t₀) + ⋯ + cₙxₙ(t₀) = 0 with c ≠ 0. Then c₁x₁ + ⋯ + cₙxₙ is a solution with initial value 0, and so is the zero function. By uniqueness they’re equal for all t, so the solutions are dependent everywhere.

Example · x′ = [1 2; 2 1]x
  1. Check (as in section 3) that x₁ = e3t(1, 1) and x₂ = e−t(1, −1) are solutions.
  2. X(t) = [e3t e−t; e3t −e−t], W = −e2t − e2t = −2e2t ≠ 0. Fundamental. (Matches W(0)e(tr A)t = −2e2t, tr A = 2.)
  3. IVP x(0) = (3, 1): solve X(0)c = (3, 1), i.e. c₁ + c₂ = 3, c₁ − c₂ = 1. So c = (2, 1).
  4. x = 2e3t(1, 1) + e−t(1, −1).
Trap

The “all or nothing” rule needs the vectors to be solutions of the same system with continuous A. The functions (t, 1) and (t², 2t) have W = t², zero only at 0. So they can’t both solve any x′ = A(t)x with A continuous on an interval containing 0.

True or false?

Every 3rd-order linear ODE can be written as a 3×3 first-order system.tap

True. Set x₁ = y, x₂ = y′, x₃ = y″ (after dividing by the leading coefficient).

If x₁, x₂ solve x′ = Ax (2×2) and W(5) ≠ 0, then every solution is c₁x₁ + c₂x₂.tap

True. W ≠ 0 at one point means it’s a fundamental set, and the solution space has dimension 2.

(et, 2et) and (3et, 6et) could form a fundamental set.tap

False. The second is 3 times the first; W = 6e2t − 6e2t = 0.

Check yourself

Write y″ + 3y′ + 2y = e−t as a system.tap

x₁ = y, x₂ = y′: x′ = [0 1; −2 −3]x + (0, e−t).

Show (et, et) and (e2t, 2e2t) form a fundamental set for x′ = [0 1; −2 3]x.tap

Check each: A(1, 1) = (1, 1) so Ax₁ = x₁ = x₁′ ✓; A(1, 2) = (2, 4) so Ax₂ = 2x₂ = x₂′ ✓. W = 2e3t − e3t = e3t ≠ 0.

D4 · Constant-coefficient systems, real eigenvalues

Nagle 9.5. For x′ = Ax with a constant matrix A, eigenvalues do all the work.

5The eigenvector method

Big idea

Guess x = eλtv: a fixed direction v that just stretches exponentially. Plugging in turns the ODE into Av = λv, the eigenvalue problem. So each eigenpair gives a solution, and n independent eigenvectors give the general solution.

x = eλtv solves x′ = Ax ⟺ Av = λvWhy: x′ = λeλtv and Ax = eλtAv. These are equal for all t exactly when Av = λv.
x = c₁eλ₁tv₁ + ⋯ + cₙeλₙtvₙValid whenever v₁, …, vₙ are linearly independent eigenvectors. At t = 0 the Wronskian is det[v₁ ⋯ vₙ] ≠ 0. Distinct eigenvalues always give independent eigenvectors.

Recipe

  1. Solve det(A − λI) = 0. For 2×2: λ² − (tr A)λ + det A = 0.
  2. For each λ, row-reduce A − λI and find a basis of its null space.
  3. Write x = Σ cᵢeλᵢtvᵢ.
  4. For an IVP, solve [v₁ ⋯ vₙ]c = x(0).
Example · x′ = [4 −2; 1 1]x, x(0) = (1, 0)
  1. tr = 5, det = 4 + 2 = 6: λ² − 5λ + 6 = (λ − 2)(λ − 3), so λ = 2, 3.
  2. λ = 2: A − 2I = [2 −2; 1 −1] → v₁ = (1, 1).
  3. λ = 3: A − 3I = [1 −2; 1 −2] → v₂ = (2, 1).
  4. x = c₁e2t(1, 1) + c₂e3t(2, 1). At 0: c₁ + 2c₂ = 1, c₁ + c₂ = 0, so c₂ = 1, c₁ = −1.
  5. x = −e2t(1, 1) + e3t(2, 1) = (2e3t − e2t, e3t − e2t).
Trap

Keep each eigenvector glued to its own eigenvalue. Swapping them gives something that looks right but fails x′ = Ax. Quick check: Av should equal λv.

6Repeated eigenvalues & phase pictures

Big idea

A repeated eigenvalue is harmless if its eigenspace is as big as its multiplicity: you still get n independent eigenvectors, and the same formula works. Real symmetric matrices always have this property (orthogonal diagonalization, Lay 7.1).

Example · x′ = [2 1 1; 1 2 1; 1 1 2]x, x(0) = (2, 1, 3)
  1. A = I + J with J the all-ones matrix. J has eigenvalues 3, 0, 0, so A has 4, 1, 1.
  2. λ = 4: v₁ = (1, 1, 1).
  3. λ = 1: A − I = J, null space x₁ + x₂ + x₃ = 0, dimension 2: v₂ = (1, −1, 0), v₃ = (1, 0, −1). Enough eigenvectors ✓.
  4. x = c₁e4t(1, 1, 1) + c₂eᵗ(1, −1, 0) + c₃eᵗ(1, 0, −1).
  5. At 0: c₁ + c₂ + c₃ = 2, c₁ − c₂ = 1, c₁ − c₃ = 3. Adding all three gives 3c₁ = 6: c₁ = 2, c₂ = 1, c₃ = −1.
  6. x = 2e4t(1, 1, 1) + eᵗ(1, −1, 0) − eᵗ(1, 0, −1).

When there aren’t enough eigenvectors

If λ has multiplicity 2 but only a 1-dimensional eigenspace (defective), you’re one solution short. The fix uses a generalized eigenvector u with (A − λI)u = v, giving x = eλt(tv + u). Example: A = [3 1; 0 3] gives e3t(1, 0) and e3t(t, 1). That’s Nagle 9.8, beyond our sections; on the exam, the main thing is recognizing when the plain method fails.

Phase pictures (2×2, real eigenvalues)

EigenvaluesPictureAs t → ∞
both negativestable nodeall solutions → 0

Long-term, the term with the largest eigenvalue dominates. In section 5’s example, x(t) ≈ e3t(2, 1) for large t, so solutions run off parallel to (2, 1).

Trap

A repeated eigenvalue doesn’t automatically mean teλt terms, unlike scalar equations with a repeated root. Check the eigenspace dimension (= n − rank(A − λI)) first.

True or false?

If A is a real symmetric n×n matrix, x′ = Ax always has n independent solutions of the form eλtv.tap

True. Spectral theorem: A has an orthonormal eigenbasis, so there are n independent eigenvectors even when eigenvalues repeat.

If A has eigenvalues 1, 1, 2, then x′ = Ax always has three independent eigen-solutions.tap

False. [1 1 0; 0 1 0; 0 0 2] has a 1-dimensional eigenspace for λ = 1 (defective).

For x′ = Ax with eigenvalues −3 and 2, every solution tends to 0.tap

False. A saddle: any solution with a nonzero e2t component blows up.

Check yourself

Solve x′ = [1 3; 3 1]x, x(0) = (4, 0).tap

tr 2, det −8: λ² − 2λ − 8 = (λ − 4)(λ + 2). v = (1, 1) for 4 and (1, −1) for −2. c₁ + c₂ = 4, c₁ − c₂ = 0. x = 2e4t(1, 1) + 2e−2t(1, −1).

General solution of x′ = [0 1; −6 −5]x. Which scalar ODE is this?tap

λ² + 5λ + 6: λ = −2 with v = (1, −2), λ = −3 with v = (1, −3). x = c₁e−2t(1, −2) + c₂e−3t(1, −3). It’s y″ + 5y′ + 6y = 0 with x = (y, y′): notice the second entries are the derivatives of the first.

x′ = 5I·x (2×2). What are all the solutions?tap

λ = 5 twice, and every nonzero vector is an eigenvector. x = e5tx(0): straight rays out of the origin.

D5 · Complex eigenvalues

Nagle 9.6. Real matrices can have complex eigenvalues; they produce rotation.

7Two real solutions from one complex one

Big idea

For λ = α + iβ with eigenvector v = a + ib, eλtv is a complex solution. Because A is real, its real part and imaginary part are each real solutions, and they’re independent. One complex eigenpair gives two real solutions; skip the conjugate.

x₁ = eαt(a cos βt − b sin βt)
x₂ = eαt(a sin βt + b cos βt)From expanding eαt(cos βt + i sin βt)(a + ib) and collecting real and imaginary parts. You can memorize this or just expand every time; expanding is safer.

Why real and imaginary parts work: if z = u + iw solves z′ = Az with A real, then u′ + iw′ = Au + iAw. Real and imaginary parts must match separately: u′ = Au, w′ = Aw.

Recipe

  1. Find λ = α ± iβ from λ² − (tr A)λ + det A = 0.
  2. Take λ = α + iβ. Find v from one row of A − λI (the rows are automatically multiples of each other): for a row (p, q), use v = (q, −p), or (−q, p).
  3. Split v = a + ib into real vectors.
  4. Expand eαt(cos βt + i sin βt)(a + ib); take its real and imaginary parts.
  5. x = c₁x₁ + c₂x₂. For an IVP: x₁(0) = a, x₂(0) = b, so solve c₁a + c₂b = x(0).
Example · x′ = [1 −5; 1 −3]x, x(0) = (3, 1)
  1. tr = −2, det = −3 + 5 = 2: λ² + 2λ + 2 = 0, λ = −1 ± i.
  2. λ = −1 + i: the second row of A − λI is (1, −2 − i), so v = (2 + i, 1). Check with the first row: (2 − i)(2 + i) − 5 = 5 − 5 = 0 ✓.
  3. a = (2, 1), b = (1, 0).
  4. x₁ = e−t[cos t(2, 1) − sin t(1, 0)] = e−t(2cos t − sin t, cos t); x₂ = e−t[sin t(2, 1) + cos t(1, 0)] = e−t(2sin t + cos t, sin t).
  5. IVP: c₁(2, 1) + c₂(1, 0) = (3, 1), so c₁ = 1, c₂ = 1.
  6. x = e−t(3cos t + sin t, cos t + sin t).
Example · x′ = [0 4; −1 0]x (a center)
  1. tr = 0, det = 4: λ = ±2i, so α = 0.
  2. λ = 2i: first row of A − λI is (−2i, 4) → v = (4, 2i), or divide by 2: v = (2, i). So a = (2, 0), b = (0, 1).
  3. x₁ = (2cos 2t, −sin 2t), x₂ = (2sin 2t, cos 2t).
  4. Every solution stays on an ellipse x₁²/4 + x₂² = const: periodic, period π.
Trap

Don’t use both λ and its conjugate to make four solutions: a 2×2 system has only two. And don’t drop the minus sign in a cos βt − b sin βt; it comes from i·i = −1.

8Spirals, centers and 3×3 systems

Big idea

The real part α controls size (eαt); the imaginary part β controls rotation speed. So: α < 0 spirals in, α > 0 spirals out, α = 0 orbits forever.

α = Re λPictureAs t → ∞
< 0stable spiral→ 0 while rotating
= 0center (closed ellipses)periodic, bounded
> 0unstable spiral|x| → ∞

Direction of rotation: evaluate A(1, 0), the velocity at the point (1, 0). If its second entry is positive, the motion there is upward: counterclockwise. In the first example A(1, 0) = (1, 1): counterclockwise. In the center example A(1, 0) = (0, −1): clockwise.

Example · 3×3 with one real and one complex pair

A = [−1 0 0; 0 0 −3; 0 3 0]. The first coordinate is decoupled: λ = −1, solution e−t(1, 0, 0). The lower block has λ = ±3i and gives (0, cos 3t, sin 3t) and (0, −sin 3t, cos 3t).

General: x = c₁e−t(1, 0, 0) + c₂(0, cos 3t, sin 3t) + c₃(0, −sin 3t, cos 3t). Solutions decay toward a circle in the x₂x₃-plane.

True or false?

If a real 2×2 A has eigenvalue 2 + 3i, every nonzero solution of x′ = Ax is unbounded as t → ∞.tap

True. Both eigenvalues have real part 2, so every nonzero solution is e2t times a nonzero periodic vector: unstable spiral.

If v is an eigenvector for λ = α + iβ, then v̄ is an eigenvector for λ̄.tap

True. Conjugate Av = λv; A is real, so Av̄ = λ̄v̄. That’s why the conjugate gives nothing new.

A real 3×3 matrix can have eigenvalues i, −i, 2i.tap

False. Complex eigenvalues of real matrices come in conjugate pairs, so 2i would need −2i: four eigenvalues. A real 3×3 matrix always has at least one real eigenvalue.

Check yourself

Find two real solutions of x′ = [3 −2; 4 −1]x. Spiral in or out?tap

tr 2, det 5: λ = 1 ± 2i. For 1 + 2i, the first row (2 − 2i, −2) gives v = (1, 1 − i), so a = (1, 1), b = (0, −1).

x₁ = eᵗ(cos 2t, cos 2t + sin 2t), x₂ = eᵗ(sin 2t, sin 2t − cos 2t). α = 1 > 0: spirals out.

Eigenvalues of the system form of y″ + 2y′ + 5y = 0?tap

Companion matrix [0 1; −5 −2], eigenvalues = auxiliary roots −1 ± 2i.

D6 · Fourier series

Nagle 10.3–10.4 (lectures Nov 30–Dec 4). Write a function on an interval as an infinite combination of sines and cosines. It’s really orthogonal projection (Lay 6.7) in a function space.

9Periodic functions and orthogonality

Big idea

On [−L, L], the functions 1, cos(nπx/L), sin(nπx/L) are mutually orthogonal under ⟨f, g⟩ = ∫−LL f g dx. So, just like with an orthogonal basis of ℝⁿ, each coefficient is a projection: ⟨f, φ⟩/⟨φ, φ⟩.

A function is periodic with period T if f(x + T) = f(x) for all x. Both cos(nπx/L) and sin(nπx/L) have period 2L/n, so all of them repeat every 2L.

∫−LL cos(mπx/L) cos(nπx/L) dx = 0 (m ≠ n), L (m = n ≥ 1)
∫−LL sin(mπx/L) sin(nπx/L) dx = 0 (m ≠ n), L (m = n)
∫−LL sin(mπx/L) cos(nπx/L) dx = 0 alwaysAnd ∫−LL 1·1 dx = 2L. Why: product-to-sum turns each product into cosines of (m ± n)πx/L, which integrate to 0 over whole periods unless m = n. The sin·cos integrand is odd, so it integrates to 0 on a symmetric interval.

Facts you’ll use constantly: sin(nπ) = 0, cos(nπ) = (−1)ⁿ, and sin(nπ/2) = 1, 0, −1, 0, …, cos(nπ/2) = 0, −1, 0, 1, … for n = 1, 2, 3, 4, …

10Fourier series and the coefficient formulas

f(x) ~ a₀/2 + Σn≥1 [aₙ cos(nπx/L) + bₙ sin(nπx/L)]The “~” means “has Fourier series”; whether it actually equals f at each point is section 11.
aₙ = (1/L) ∫−LL f(x) cos(nπx/L) dx   (n ≥ 0)
bₙ = (1/L) ∫−LL f(x) sin(nπx/L) dx   (n ≥ 1)The a₀/2 convention lets one formula cover a₀: then a₀/2 is the average value of f on [−L, L].

Where the formulas come from: multiply the series by cos(mπx/L) and integrate over [−L, L]. By orthogonality every term dies except aₘ·L. So ∫ f cos(mπx/L) = aₘL. Same for sines.

Recipe

  1. Identify L (half the period) and the pieces of f.
  2. Check for symmetry (section 12): an odd f has all aₙ = 0; an even f has all bₙ = 0.
  3. Compute a₀ separately (the general aₙ formula often divides by n).
  4. Integrate piece by piece. For x·cos or x·sin, use integration by parts or the formulas below.
  5. Simplify with cos nπ = (−1)ⁿ and write out the series.
∫₀ᴸ x cos(nπx/L) dx = L²((−1)ⁿ − 1)/(nπ)²
∫₀ᴸ x sin(nπx/L) dx = L²(−1)ⁿ⁺¹/(nπ)
∫₀ᴸ sin(nπx/L) dx = L(1 − (−1)ⁿ)/(nπ)Handy integration-by-parts results (n ≥ 1). And ∫₀ᴸ cos(nπx/L) dx = 0.
Example · a step: f = 0 on (−2, 0), f = 3 on (0, 2)
  1. L = 2. a₀ = ½∫₀² 3 dx = 3, so the constant term is a₀/2 = 3/2, the average. ✓
  2. aₙ = ½∫₀² 3cos(nπx/2) dx = 0.
  3. bₙ = ½∫₀² 3sin(nπx/2) dx = (3/2)·2(1 − (−1)ⁿ)/(nπ) = 3(1 − (−1)ⁿ)/(nπ): that’s 6/(nπ) for odd n, 0 for even n.
  4. f ~ 3/2 + (6/π)[sin(πx/2) + ⅓sin(3πx/2) + ⅕sin(5πx/2) + ⋯].

Sanity check: f − 3/2 is odd, which is why only sines appear.

Example · f(x) = x + x² on [−1, 1]
  1. L = 1. Split: x² is even (only cosines), x is odd (only sines).
  2. a₀ = ∫−11 x² dx = 2/3, constant term 1/3.
  3. aₙ = ∫−11 x²cos(nπx) dx = 4(−1)ⁿ/(n²π²) (parts twice).
  4. bₙ = ∫−11 x sin(nπx) dx = 2∫₀¹ x sin(nπx) dx = 2(−1)ⁿ⁺¹/(nπ).
  5. f ~ 1/3 + Σ [4(−1)ⁿ/(n²π²) cos nπx + 2(−1)ⁿ⁺¹/(nπ) sin nπx].
Trap

Forgetting the ½ on a₀ is the most common lost point. Also: compute a₀ on its own, since plugging n = 0 into a simplified aₙ often means dividing by 0.

11Convergence: what the series actually adds up to

Big idea

The series sees the 2L-periodic extension of f. Where that extension is continuous, the series equals it. At a jump, it lands exactly at the midpoint of the jump.

Series at x = ½[f(x⁺) + f(x⁻)]Theorem: if f and f′ are piecewise continuous on [−L, L], the Fourier series converges at every x to the average of the left and right limits of the periodic extension. At the endpoints x = ±L: ½[f(−L⁺) + f(L⁻)].

Recipe for “what does the series converge to at x = c?”

  1. If c is outside (−L, L], shift it by multiples of 2L into that window.
  2. If f is continuous there (and c isn’t an endpoint), the answer is f(c).
  3. If it’s a jump, or c = ±L, average the left and right limits. At ±L, use f(L⁻) and f(−L⁺).
Example · the step from section 10

At x = 0: ½(0 + 3) = 3/2 (every sine is 0 there, consistent). At x = 1: 3. At x = 2: ½[f(2⁻) + f(−2⁺)] = ½(3 + 0) = 3/2. At x = 7: 7 − 8 = −1, so 0.

Example · x + x² on [−1, 1]

At x = ½: continuous, so ½ + ¼ = 3/4. At x = 1: f(1⁻) = 2 but f(−1⁺) = 0, so the series gives 1, not f(1) = 2.

Trap

The value f(c) itself is irrelevant at a jump: changing f at a single point doesn’t change any integral, so it can’t change the series.

12Even/odd functions; Fourier cosine and sine series

Big idea

Symmetry kills half the coefficients. And a function given only on [0, L] can be extended to [−L, L] as even (cosines only) or odd (sines only): two different series for the same function on (0, L).

  • Even: f(−x) = f(x) (graph symmetric about the y-axis): x², cos, |x|. Odd: f(−x) = −f(x): x, x³, sin.
  • even·even = even, odd·odd = even, even·odd = odd.
  • ∫−LL odd = 0; ∫−LL even = 2∫₀ᴸ.
f even: bₙ = 0, aₙ = (2/L)∫₀ᴸ f(x) cos(nπx/L) dx
f odd: aₙ = 0, bₙ = (2/L)∫₀ᴸ f(x) sin(nπx/L) dxWhy: for even f, f·sin is odd (integral 0) and f·cos is even (double the half-interval).

Example · f(x) = 2 − x on [0, 2], both series
  1. Cosine: a₀ = (2/2)∫₀²(2 − x) dx = 2, constant term 1.
  2. aₙ = ∫₀²(2 − x)cos(nπx/2) dx = 0 − ∫₀² x cos(nπx/2) dx = −4((−1)ⁿ − 1)/(nπ)² = 4(1 − (−1)ⁿ)/(n²π²).
  3. Cosine series: 1 + (8/π²)Σn odd cos(nπx/2)/n².
  4. Sine: bₙ = ∫₀²(2 − x)sin(nπx/2) dx = 2·2(1 − (−1)ⁿ)/(nπ) − 4(−1)ⁿ⁺¹/(nπ) = 4/(nπ) (check n odd and even separately: both give 4/(nπ)).
  5. Sine series: Σ (4/(nπ)) sin(nπx/2).
  6. At x = 0: the cosine series gives f(0) = 2 (the even extension is a continuous “tent”); the sine series gives 0 (the odd extension jumps from −2 to 2).
Traps

• Half-range coefficients use 2/L and ∫₀ᴸ; full series use 1/L and ∫−LL. Don’t mix them.

• For half-range series, the period of the extension is still 2L, not L.

True or false?

The Fourier series of an odd function on [−L, L] has only sine terms.tap

True. f·cos is odd, so every aₙ (including a₀) is 0.

The Fourier sine series of f(x) = 1 on [0, π] converges to 1 at x = 0.tap

False. Every sine is 0 at x = 0; the odd extension jumps from −1 to 1, average 0.

sin(3x) + 2cos(5x) is its own Fourier series on [−π, π].tap

True. By orthogonality, b₃ = 1, a₅ = 2, all other coefficients 0.

If f is continuous on [−L, L], its Fourier series converges to f(L) at x = L.tap

False in general. It converges to ½[f(−L) + f(L)]; that equals f(L) only if f(−L) = f(L).
