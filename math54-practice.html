1Inner product space · 10 pts

Give C[0, 1] the inner product ⟨f, g⟩ = ∫₀¹ f(t)g(t) dt.

  1. (4) Find an orthogonal basis for W = span{1, t}.
  2. (4) Find the function in W closest to t², and the distance from t² to W.
  3. (2) Is ⟨p, q⟩ = p(0)q(0) + p(1)q(1) an inner product on P₂? Justify.
Solutiontap
  1. (a) Gram–Schmidt: v₁ = 1. ⟨t, 1⟩ = 1/2, ⟨1, 1⟩ = 1, so v₂ = t − (1/2)·1 = t − 1/2. Basis {1, t − 1/2}.
  2. (b) ⟨t², 1⟩ = 1/3. ⟨t², t − ½⟩ = 1/4 − 1/6 = 1/12. ⟨t − ½, t − ½⟩ = ∫₀¹(t − ½)² dt = 1/12.
  3. Projection: (1/3)·1 + (1/12)/(1/12)·(t − ½) = t − 1/6.
  4. Error: ‖t² − t + 1/6‖² = ∫₀¹(t² − t + 1/6)² dt = 1/180, so the distance is 1/√180 = √5/30 ≈ 0.075.
  5. (c) No. p = t² − t is not the zero polynomial but p(0) = p(1) = 0, so ⟨p, p⟩ = 0: positivity fails.
What this tests / common mistake

Projection in a function space (Lay 6.7) uses exactly the ℝⁿ formula, but only with an orthogonal basis. Projecting onto 1 and t separately (they aren’t orthogonal on [0, 1]) gives the wrong answer 1/3 + (3/4)t. Also, the distance is the square root of the integral.

2Orthogonal diagonalization · 10 pts

A = [ 1 2 −1 ; 2 −2 2 ; −1 2 1 ]
  1. (6) You’re told 2 is an eigenvalue of A. Find an orthogonal matrix P and diagonal D with A = PDPᵀ.
  2. (2) Write A as 2I + c·uuᵀ for a unit vector u and a number c.
  3. (2) Find the eigenvalues of A² + A, without computing A².
Solutiontap
  1. A − 2I = [−1 2 −1; 2 −4 2; −1 2 −1] has rank 1, so λ = 2 has a 2-dimensional eigenspace: x₁ = 2x₂ − x₃, basis (2, 1, 0), (−1, 0, 1).
  2. Trace: 1 − 2 + 1 = 0 = 2 + 2 + λ₃, so λ₃ = −4. Eigenvector: orthogonal to the λ = 2 eigenspace (A is symmetric), i.e. the normal vector of x₁ − 2x₂ + x₃ = 0: (1, −2, 1). Check: A(1, −2, 1) = (−4, 8, −4) ✓.
  3. Gram–Schmidt inside the λ = 2 eigenspace: (−1, 0, 1) − (−2/5)(2, 1, 0) = (−1/5, 2/5, 1), or scaled, (−1, 2, 5).
  4. P = [ (1, −2, 1)/√6   (2, 1, 0)/√5   (−1, 2, 5)/√30 ], D = diag(−4, 2, 2).
  5. (b) Spectral decomposition: A = −4uuᵀ + 2(I − uuᵀ) = 2I − 6uuᵀ with u = (1, −2, 1)/√6. (Check: 6uuᵀ = [1 −2 1; −2 4 −2; 1 −2 1] and 2I minus that is A ✓.)
  6. (c) If Av = λv then (A² + A)v = (λ² + λ)v: eigenvalues 16 − 4 = 12 and 4 + 2 = 6 (twice).
What this tests / common mistake

For a repeated eigenvalue, the two eigenvectors you get from row reduction usually aren’t orthogonal: (2, 1, 0)·(−1, 0, 1) = −2. Normalizing without Gram–Schmidt gives a non-orthogonal P. The trace and the “orthogonal to the other eigenspace” shortcut save a cubic.

3SVD and least squares · 10 pts

A = [ 1 1 ; 1 1 ; 2 −2 ],   b = (1, 3, 4)
  1. (6) Find a singular value decomposition A = UΣVᵀ.
  2. (1) Read off an orthonormal basis for Nul Aᵀ from your SVD.
  3. (3) Use the SVD to find the least-squares solution of Ax = b and the least-squares error.
Solutiontap
  1. AᵀA = [6 −2; −2 6], eigenvalues 8, 4: σ₁ = 2√2, σ₂ = 2.
  2. v₁ = (1, −1)/√2 (for 8), v₂ = (1, 1)/√2 (for 4).
  3. Av₁ = (0, 0, 4)/√2, so u₁ = Av₁/σ₁ = (0, 0, 1). Av₂ = (2, 2, 0)/√2, so u₂ = (1, 1, 0)/√2.
  4. Complete with a unit vector orthogonal to both: u₃ = (1, −1, 0)/√2.
  5. U = [u₁ u₂ u₃], Σ = [2√2 0; 0 2; 0 0], V = [v₁ v₂].
  6. (b) Nul Aᵀ = (Col A)⊥ = span{u₃}: basis {(1, −1, 0)/√2}.
  7. (c) x̂ = VΣ⁺Uᵀb. u₁·b = 4, u₂·b = 4/√2 = 2√2. So x̂ = (4/(2√2))v₁ + (2√2/2)v₂ = √2v₁ + √2v₂ = (1, −1) + (1, 1) = (2, 0).
  8. Error: b − Ax̂ = (1, 3, 4) − (2, 2, 4) = (−1, 1, 0), length √2. (It’s the u₃-component of b, as it should be.) Check with normal equations: AᵀA x̂ = (12, −4) = Aᵀb ✓.
What this tests / common mistake

Getting uᵢ from Avᵢ/σᵢ (not independently from AAᵀ, which can flip signs). Ordering σ’s decreasingly and keeping vᵢ matched. Σ must be 3×2, the same shape as A.

4Homogeneous second-order equations · 8 pts

  1. (4) Solve y″ + 2y′ + 10y = 0, y(0) = 2, y′(0) = −5.
  2. (2) For which b > 0 do the solutions of y″ + by′ + 10y = 0 oscillate? What happens at the boundary value?
  3. (2) Is there a second-order, constant-coefficient, homogeneous linear ODE with solution y = te−2t + 5? If not, find one of the lowest possible order.
Solutiontap
  1. (a) r² + 2r + 10 = 0, r = −1 ± 3i. y = e−t(c₁cos 3t + c₂sin 3t).
  2. y(0) = c₁ = 2; y′(0) = −c₁ + 3c₂ = −5, so c₂ = −1. y = e−t(2cos 3t − sin 3t).
  3. (b) Oscillation needs complex roots: b² − 40 < 0, i.e. 0 < b < 2√10. At b = 2√10, the double root −√10 gives critical damping: (c₁ + c₂t)e−√10 t, no oscillation.
  4. (c) te−2t needs −2 as a double root and the constant 5 needs root 0: three roots in total, so no second-order equation works. Lowest order: r(r + 2)² = r³ + 4r² + 4r, i.e. y‴ + 4y″ + 4y′ = 0.
What this tests / common mistake

In (a), y′(0) = αc₁ + βc₂: students drop the αc₁ = −c₁ from the product rule and get c₂ = −5/3. In (c), forgetting that a constant solution means r = 0 is a root.

5Undetermined coefficients · 10 pts

  1. (7) Solve y″ − 2y′ + y = 6tet + 2cos t, y(0) = 1, y′(0) = 0.
  2. (3) Write down the form of a particular solution of y″ + 4y = t sin 2t + e2t. Do not solve for the coefficients.
Solutiontap
  1. (a) r² − 2r + 1 = (r − 1)²: double root 1, yₕ = (c₁ + c₂t)eᵗ.
  2. Piece 6teᵗ: degree 1, α = 1 is a double root, so s = 2: try t²(At + B)eᵗ. Shortcut: the operator is (D − 1)² and (D − 1)(ueᵗ) = u′eᵗ, so L[ueᵗ] = u″eᵗ. With u = At³ + Bt²: (6At + 2B)eᵗ = 6teᵗ, so A = 1, B = 0. yₚ₁ = t³eᵗ.
  3. Piece 2cos t: i is not a root, try C cos t + D sin t. L[cos t] = 2sin t, L[sin t] = −2cos t. So −2D cos t + 2C sin t = 2cos t: D = −1, C = 0. yₚ₂ = −sin t.
  4. y = (c₁ + c₂t)eᵗ + t³eᵗ − sin t. y(0) = c₁ = 1. y′(0) = c₁ + c₂ + 0 − 1 = 0, so c₂ = 0.
  5. y = eᵗ + t³eᵗ − sin t.
  6. (b) Roots ±2i. t sin 2t: degree 1 with 2i a simple root, s = 1: t[(At + B)cos 2t + (Ct + D)sin 2t]. e2t: 2 is not a root: Ee2t.
  7. yₚ = t[(At + B)cos 2t + (Ct + D)sin 2t] + Ee2t. (For the record: A = −1/8, D = 1/16, E = 1/8, B = C = 0.)
What this tests / common mistake

The tˢ rule with a double root (s = 2, not 1), and using full polynomials. Common errors: trying t(At + B)eᵗ (gives no solution), writing At sin 2t alone in (b), and applying the initial conditions before adding yₚ.

6Systems and Wronskians · 8 pts

  1. (2) Rewrite y″ − 2y′ − 3y = 0 as a system x′ = Ax with x = (y, y′), and find the eigenvalues of A.
  2. (2) Show that x₁ = (e3t, 3e3t) and x₂ = (e−t, −e−t) form a fundamental solution set.
  3. (2) Solve the system with x(0) = (0, 4). What scalar initial value problem have you solved?
  4. (2) Can (t, 1) and (t², 2t) both be solutions of some x′ = A(t)x with A(t) continuous on all of ℝ? Explain.
Solutiontap
  1. (a) y″ = 3y + 2y′: A = [0 1; 3 2]. det(A − λI) = λ² − 2λ − 3 = (λ − 3)(λ + 1): λ = 3, −1 (same as the auxiliary roots).
  2. (b) A(1, 3) = (3, 9) = 3(1, 3) and A(1, −1) = (−1, 1) = −(1, −1), so both are solutions. W = det[e3t e−t; 3e3t −e−t] = −e2t − 3e2t = −4e2t ≠ 0.
  3. (c) c₁ + c₂ = 0, 3c₁ − c₂ = 4: c₁ = 1, c₂ = −1. x = (e3t − e−t, 3e3t + e−t). The first entry solves y″ − 2y′ − 3y = 0, y(0) = 0, y′(0) = 4: y = e3t − e−t.
  4. (d) No. Their Wronskian is det[t t²; 1 2t] = t²: zero at t = 0 but not identically zero. For solutions of one system with continuous coefficients, W is either never 0 or always 0.
What this tests / common mistake

The bottom row of the companion matrix has the signs of the coefficients after moving them to the right side. In (d), the “all or nothing” Wronskian property holds only for solutions, which is exactly what you’re using to rule them out.

7A 3×3 system with real eigenvalues · 10 pts

x′ = Ax,   A = [ 2 0 0 ; 3 2 −3 ; 3 0 −1 ]
  1. (4) Find the eigenvalues of A and a basis of each eigenspace.
  2. (4) Solve the initial value problem x(0) = (1, 2, 0).
  3. (2) For which initial vectors x(0) does x(t) → 0 as t → ∞?
Solutiontap
  1. (a) Expand along the first row: det(A − λI) = (2 − λ)·[(2 − λ)(−1 − λ) − 0] = (2 − λ)²(−1 − λ). Eigenvalues 2, 2, −1.
  2. λ = 2: A − 2I = [0 0 0; 3 0 −3; 3 0 −3], rank 1, so x₁ = x₃, x₂ free. Basis (1, 0, 1), (0, 1, 0): dimension 2, enough eigenvectors.
  3. λ = −1: A + I = [3 0 0; 3 3 −3; 3 0 0]: x₁ = 0, x₂ = x₃. Basis (0, 1, 1).
  4. (b) x = c₁e2t(1, 0, 1) + c₂e2t(0, 1, 0) + c₃e−t(0, 1, 1). At 0: c₁ = 1, c₂ + c₃ = 2, c₁ + c₃ = 0. So c₃ = −1, c₂ = 3.
  5. x = (e2t, 3e2t − e−t, e2t − e−t).
  6. (c) The e2t terms blow up unless c₁ = c₂ = 0. So exactly when x(0) is a multiple of (0, 1, 1) (including 0).
What this tests / common mistake

Repeated eigenvalue with a full eigenspace: no teλt terms are needed. Students who assume “repeated ⟹ defective” waste time on generalized eigenvectors. Any basis of the λ = 2 eigenspace works; the final x(t) is the same.

8Complex eigenvalues · 10 pts

x′ = Ax,   A = [ −3 −2 ; 4 1 ]
  1. (5) Find a general solution in terms of real functions.
  2. (3) Solve with x(0) = (2, 1).
  3. (2) Describe the trajectories: do they spiral in or out, and in which direction?
Solutiontap
  1. (a) tr = −2, det = −3 + 8 = 5: λ² + 2λ + 5 = 0, λ = −1 ± 2i.
  2. λ = −1 + 2i: first row of A − λI is (−2 − 2i, −2) → v = (−2, 2 + 2i), or dividing by −2, v = (1, −1 − i). So a = (1, −1), b = (0, −1).
  3. x₁ = e−t[cos 2t·a − sin 2t·b] = e−t(cos 2t, −cos 2t + sin 2t).
  4. x₂ = e−t[sin 2t·a + cos 2t·b] = e−t(sin 2t, −sin 2t − cos 2t).
  5. x = c₁x₁ + c₂x₂.
  6. (b) c₁a + c₂b = (2, 1): c₁ = 2, −2 − c₂ = 1, so c₂ = −3.
  7. x = 2x₁ − 3x₂ = e−t(2cos 2t − 3sin 2t, cos 2t + 5sin 2t). Check: x(0) = (2, 1) ✓.
  8. (c) α = −1 < 0: spirals in to the origin (stable spiral). A(1, 0) = (−3, 4) points upward at (1, 0): counterclockwise.
What this tests / common mistake

Splitting eλtv into real and imaginary parts correctly (the minus sign in a cos − b sin). Eigenvectors differ by complex scalars, so your x₁, x₂ may look different, but the IVP answer must match. For direction, check one velocity vector rather than guessing from the sign of β.

9Fourier series · 10 pts

f(x) = 1 for −2 < x < 0,   f(x) = x for 0 < x < 2
  1. (6) Compute the Fourier series of f on [−2, 2].
  2. (2) To what value does the series converge at x = 0, 1, 2, 5?
  3. (2) Use (b) at x = 0 to evaluate 1 + 1/9 + 1/25 + 1/49 + ⋯
Solutiontap
  1. L = 2. a₀ = ½[∫−20 1 dx + ∫₀² x dx] = ½(2 + 2) = 2: constant term 1.
  2. aₙ = ½[∫−20 cos(nπx/2) dx + ∫₀² x cos(nπx/2) dx] = ½[0 + 4((−1)ⁿ − 1)/(nπ)²] = 2((−1)ⁿ − 1)/(n²π²): −4/(n²π²) for odd n, 0 for even.
  3. ∫−20 sin(nπx/2) dx = −2(1 − (−1)ⁿ)/(nπ) and ∫₀² x sin(nπx/2) dx = 4(−1)ⁿ⁺¹/(nπ).
  4. bₙ = ½[−2(1 − (−1)ⁿ) − 4(−1)ⁿ]/(nπ) = −(1 + (−1)ⁿ)/(nπ): −2/(nπ) for even n, 0 for odd.
  5. f ~ 1 − (4/π²)Σn odd cos(nπx/2)/n² − (2/π)Σn even sin(nπx/2)/n.
  6. (b) x = 0: jump from 1 to 0, so 1/2. x = 1: continuous, 1. x = 2: endpoint, ½[f(2⁻) + f(−2⁺)] = ½(2 + 1) = 3/2. x = 5: shift by 4 to x = 1: 1.
  7. (c) At 0, all sines vanish and cos 0 = 1: 1/2 = 1 − (4/π²)Σodd 1/n², so Σodd 1/n² = π²/8.
What this tests / common mistake

Splitting integrals at the break point, the a₀/2 convention, and the convergence theorem at a jump and at the endpoints (where the periodic extension jumps from f(2⁻) to f(−2⁺)). Answering “f(0)” or “f(2) = 2” loses the points.

10Cosine and sine series · 8 pts

g(x) = 1 for 0 < x < 1,   g(x) = 0 for 1 < x < 2
  1. (3) Find the Fourier cosine series of g on [0, 2].
  2. (3) Find the Fourier sine series of g on [0, 2], writing out b₁, …, b₄.
  3. (2) What does the cosine series converge to at x = 1 and x = −1/2? What does the sine series converge to at x = −1/2 and x = 2?
Solutiontap
  1. (a) L = 2, so 2/L = 1. a₀ = ∫₀¹ 1 dx = 1 (constant term 1/2). aₙ = ∫₀¹ cos(nπx/2) dx = 2sin(nπ/2)/(nπ).
  2. g ~ ½ + (2/π)[cos(πx/2) − ⅓cos(3πx/2) + ⅕cos(5πx/2) − ⋯].
  3. (b) bₙ = ∫₀¹ sin(nπx/2) dx = 2(1 − cos(nπ/2))/(nπ).
  4. b₁ = 2/π, b₂ = 2·2/(2π) = 2/π, b₃ = 2/(3π), b₄ = 0.
  5. (c) Cosine (even extension): at x = 1 the jump from 1 to 0 gives 1/2; at x = −1/2 the even extension equals g(1/2) = 1.
  6. Sine (odd extension): at x = −1/2, −g(1/2) = −1; at x = 2, every sin(nπ) = 0: 0.
What this tests / common mistake

Half-range formulas use 2/L and ∫₀ᴸ. Patterns of sin(nπ/2) and cos(nπ/2) (not (−1)ⁿ!) because the break is at the midpoint. For negative x, decide which extension you’re in before answering.

11True or false, with a reason · 20 pts (2 each)

(a) If A is symmetric, eigenvectors for different eigenvalues are orthogonal.tap

True. λ₁v₁·v₂ = Av₁·v₂ = v₁·Av₂ = λ₂v₁·v₂, and λ₁ ≠ λ₂ forces v₁·v₂ = 0.

(b) The singular values of a square matrix are the absolute values of its eigenvalues.tap

False. [0 1; 0 0] has eigenvalues 0, 0 but singular values 1, 0. (It’s true for symmetric matrices.)

(c) ⟨p, q⟩ = ∫₀¹ p′(t)q′(t) dt is an inner product on P₂.tap

False. p = 1 is nonzero but p′ = 0, so ⟨1, 1⟩ = 0.

(d) If y₁ and y₂ solve y″ + y = eᵗ, so does y₁ + y₂.tap

False. L[y₁ + y₂] = 2eᵗ. (The difference solves the homogeneous equation.)

(e) A particular solution of y″ + y = cos t can be found in the form A cos t + B sin t.tap

False. ±i are roots, so that form is homogeneous: L[A cos t + B sin t] = 0. Need t(A cos t + B sin t).

(f) If x₁, x₂ solve x′ = Ax (A constant 2×2) and their Wronskian is 0 at t = 0, it is 0 for all t.tap

True. W(t) = W(0)e(tr A)t (or: a vanishing combination at 0 is the zero solution by uniqueness).

(g) If a real 2×2 A has eigenvalue 2 + 3i, every nonzero solution of x′ = Ax is unbounded as t → ∞.tap

True. Every solution is e2t times a periodic vector that is never zero for a nonzero solution, so the length grows like e2t.

(h) The Fourier series of an odd function on [−L, L] contains only sine terms.tap

True. f(x)cos(nπx/L) is odd, so every aₙ = 0.

(i) If a real 3×3 matrix A has eigenvalues 1, 1, 2, then x′ = Ax has three linearly independent solutions of the form eλtv.tap

False. [1 1 0; 0 1 0; 0 0 2]: the λ = 1 eigenspace is 1-dimensional, so only two independent eigen-solutions exist.

(j) Every orthogonally diagonalizable matrix is symmetric.tap

True. A = PDPᵀ ⟹ Aᵀ = (Pᵀ)ᵀDᵀPᵀ = PDPᵀ = A.

What this tests / common mistake

A True needs a reason, not a restatement; a False needs a specific counterexample. The favorites here: (b) and (i) (repeated ≠ defective, but it can be), (d) (nonhomogeneous solutions aren’t a subspace).

12Short proofs · 6 pts

  1. (4) Let A be a real symmetric matrix and x(t) a solution of x′ = Ax. Show (d/dt)‖x‖² = 2xᵀAx. Deduce that if every eigenvalue of A is negative, then ‖x(t)‖ is strictly decreasing for any nonzero solution.
  2. (2) Show that for positive integers m ≠ n, ∫−LL sin(mπx/L) sin(nπx/L) dx = 0.
Solutiontap
  1. (a) ‖x‖² = xᵀx, so by the product rule (xᵀx)′ = x′ᵀx + xᵀx′ = (Ax)ᵀx + xᵀAx = xᵀAᵀx + xᵀAx = 2xᵀAx, using Aᵀ = A.
  2. Spectral theorem: write x = Σ cᵢuᵢ in an orthonormal eigenbasis. Then xᵀAx = Σ λᵢcᵢ² ≤ λmax‖x‖² < 0 when x ≠ 0.
  3. A nonzero solution is never 0 (uniqueness: the zero solution is the only one through 0), so (‖x‖²)′ < 0 for all t: ‖x‖ strictly decreases.
  4. (b) sin A sin B = ½[cos(A − B) − cos(A + B)]. With k = m − n ≠ 0 and m + n ≠ 0, ∫−LL cos(kπx/L) dx = (L/(kπ))[sin(kπ) − sin(−kπ)] = 0, and likewise for m + n. So the integral is 0.
What this tests / common mistake

Linking the spectral theorem (Lay 7.1) to ODE behavior. Writing (xᵀx)′ = 2xᵀx′ is fine here, but say why the two terms are equal (they’re scalars and transposes of each other). In (b), you must say why m − n ≠ 0 matters: that’s where m ≠ n is used.
