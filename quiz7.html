1Repeated roots

Big idea

A degree-k recurrence needs k different solutions to fit k initial conditions. If the characteristic equation has fewer than k different roots, a repeated root supplies the missing ones by multiplying by powers of n.

root r repeated m times  ⟹  rn, n·rn, …, nm−1rn are all solutionsFor a double root r0 of a degree-2 recurrence: an = α1r0n + α2n·r0n.
Lecture example · an = 4an−1 − 4an−2, a0 = 2, a1 = 12
  1. r² − 4r + 4 = (r − 2)² = 0: root 2, repeated twice.
  2. General solution: an = α12n + α2n2n.
  3. a0 = 2 gives α1 = 2. a1 = 12 gives 12 = 2·2 + α2·2, so α2 = 4.
  4. an = 2·2n + 4n·2n. Check a2: 48 − 8 = 40 and 8 + 32 = 40. ✓
Lecture example · an = 2an−1 − an−2, a0 = 2, a1 = 4
  1. r² − 2r + 1 = (r − 1)² = 0: root 1, repeated twice.
  2. an = α1·1n + α2n·1n = α1 + α2n.
  3. α1 = 2, and 4 = 2 + α2, so α2 = 2.
  4. an = 2 + 2n: 2, 4, 6, 8, … ✓
Trap

With a repeated root, α1r0n + α2r0n collapses to one term and can’t match two initial conditions. You need the n.

Solve an = 8an−1 − 16an−2, a0 = 1, a1 = 8.tap

(r − 4)², root 4 twice. α1 = 1; (1 + α2)·4 = 8, so α2 = 1. an = (1 + n)4n. Check a2: 64 − 16 = 48 = 3·16. ✓

Part 2 · Inclusion–exclusion

Lecture 22 (Rosen 8.5–8.6). The goal: count a union of overlapping sets without counting anything twice.

2Two sets

|A ∪ B| = |A| + |B| − |A ∩ B|

Why: |A| + |B| counts every element of A ∩ B twice, once in each set. Subtracting |A ∩ B| once fixes it.

Example

Numbers 1–100 divisible by 2 or 5: 50 + 20 − 10 = 60. (Divisible by both 2 and 5 means divisible by 10.)

3Three sets

|A ∪ B ∪ C| = |A| + |B| + |C|
  − |A∩B| − |A∩C| − |B∩C|
  + |A∩B∩C|

Why the signs alternate

Track how many times an element is counted, depending on how many of the sets it’s in:

In+singles−pairs+tripleTotal
1 set1001
2 sets2−101
all 33−3+11

Every element of the union ends up counted exactly once. The pair terms over-correct for elements in all three sets (3 − 3 = 0), and the triple term adds them back.

Trap

Forgetting the last term (+|A∩B∩C|), or subtracting it. The signs go +, −, +.

4Divisibility counts

Key fact

The number of integers from 1 to N divisible by d is ⌊N/d⌋. Divisible by both a and b means divisible by lcm(a, b), which is ab when a and b share no factors.

Lecture example · numbers 1–600 divisible by 2, 3 or 5
  1. Singles: |A2| = 300, |A3| = 200, |A5| = 120.
  2. Pairs: divisible by 6 → 100; by 10 → 60; by 15 → 40.
  3. Triple: divisible by 30 → 20.
  4. 300 + 200 + 120 − 100 − 60 − 40 + 20 = 440.
Trap

When the numbers share factors, use the lcm, not the product: divisible by 4 and 6 means divisible by 12, not 24.

How many of 1–600 are divisible by none of 2, 3, 5?tap

Complement of the union: 600 − 440 = 160.

5Counting “none of” (the complement form)

Big idea

Most applications want objects with none of some bad properties. Count everything, then subtract the union of the bad sets.

#(none of the properties) = N − |A1 ∪ ⋯ ∪ An|N = total number of objects; Ai = objects with bad property i.

The recipe

  1. Define the universe and its size N.
  2. Define each bad set Ai (“has property i”).
  3. Find the sizes of all intersections. Usually all intersections of r sets have the same size, so you multiply by C(n, r).
  4. Answer = N − Σ|Ai| + Σ|Ai∩Aj| − ⋯
Example

Numbers 1–1000 divisible by neither 5 nor 7: 1000 − (200 + 142 − 28) = 1000 − 314 = 686. (⌊1000/7⌋ = 142, ⌊1000/35⌋ = 28.)

6Venn diagrams for 4 or more sets

A Venn diagram for n sets needs a region for every combination of in/out, so 2n regions, counting the outside. For 4 sets that’s 16.

Four overlapping circles can’t do it: they miss some combinations. For example, there’s no region for “in A and C only” or “in B and D only”. Correct 4-set diagrams use other shapes, like ellipses.

Fun fact from lecture

A rotationally symmetric Venn diagram with n sets can exist only if n is prime. Rotating by 1/n of a turn shuffles the regions lying in exactly r sets among themselves in groups of n, so n must divide C(n, r) for every 1 ≤ r < n. If n has a prime factor p < n, then n doesn’t divide C(n, p). Examples are known for n = 2, 3, 5, 7, 11, 13, 17, 19, 23.

7The general formula & its proof

|A1 ∪ ⋯ ∪ An| = Σ|Ai| − Σi<j|Ai∩Aj| + Σi<j<k|Ai∩Aj∩Ak| − ⋯ + (−1)n+1|A1∩⋯∩An|Add singles, subtract pairs, add triples, … alternating. There are 2n − 1 terms in all.

Proof (count each element once)

  1. Suppose x is in exactly r of the sets (r ≥ 1). It counts once on the left side.
  2. On the right, x appears in C(r, 1) single terms, C(r, 2) pair terms, C(r, 3) triple terms, and so on. Its total count is C(r,1) − C(r,2) + C(r,3) − ⋯ + (−1)r+1C(r,r).
  3. By the binomial theorem, 0 = (1 − 1)r = C(r,0) − C(r,1) + C(r,2) − ⋯ + (−1)rC(r,r).
  4. Since C(r, 0) = 1, rearranging gives C(r,1) − C(r,2) + ⋯ = 1. So x is counted exactly once on the right too. ∎

8Stars and bars with upper bounds

Big idea

Stars and bars handles lower bounds easily but not upper bounds. So count without the upper bounds, then use inclusion–exclusion to subtract the solutions that break a bound.

x1 + ⋯ + xk = n, xi ≥ 0  ⟹  C(n + k − 1, k − 1) solutionsBreaking “xi ≤ c” means xi ≥ c + 1. Substitute xi′ = xi − (c + 1) ≥ 0, which lowers the total n by c + 1.
Example (Rosen) · x1 + x2 + x3 = 11 with x1 ≤ 3, x2 ≤ 4, x3 ≤ 6
  1. No upper bounds: C(13, 2) = 78.
  2. Bad sets: A1: x1 ≥ 4 → total 7 → C(9, 2) = 36. A2: x2 ≥ 5 → total 6 → C(8, 2) = 28. A3: x3 ≥ 7 → total 4 → C(6, 2) = 15.
  3. Pairs: A1∩A2 → total 2 → C(4, 2) = 6. A1∩A3 → total 0 → 1. A2∩A3 → total −1 → 0. Triple → 0.
  4. 78 − (36 + 28 + 15) + (6 + 1 + 0) − 0 = 6.
Trap

If subtracting makes the total negative, there are 0 solutions for that term. Don’t plug a negative number into C(·, ·).

9Dice sums

A sum of dice is a bounded stars-and-bars problem: each die is between 1 and 6.

Lecture example · probability 6 dice sum to 21
  1. There are 66 equally likely rolls. Count solutions of x1 + ⋯ + x6 = 21 with 1 ≤ xi ≤ 6.
  2. Shift to start at 0: yi = xi − 1, so y1 + ⋯ + y6 = 15 with 0 ≤ yi ≤ 5.
  3. No upper bound: C(20, 5).
  4. Some yi ≥ 6: subtract 6 → total 9 → C(14, 5), for each of the 6 dice.
  5. Two y’s ≥ 6: total 3 → C(8, 5), for each of the C(6, 2) pairs. Three or more is impossible (18 > 15).
  6. Count = C(20,5) − 6·C(14,5) + C(6,2)·C(8,5) = 15504 − 12012 + 840 = 4332. Probability 4332/66 ≈ 0.093.
How many ways can 3 dice sum to 10?tap

y1 + y2 + y3 = 7 with yi ≤ 5. C(9, 2) = 36; one y ≥ 6 → total 1 → C(3, 2) = 3, times 3 dice; two ≥ 6 impossible. 36 − 9 = 27.

10Derangements

Definition

A derangement is a permutation of 1, …, n where no number is in its own position (i is never in spot i).

Dn = n! (1 − 1/1! + 1/2! − 1/3! + ⋯ + (−1)n/n!)

Where it comes from

  1. Let Ai = permutations with i in position i (the “bad” event). Derangements = n! − |A1 ∪ ⋯ ∪ An|.
  2. Fixing r particular numbers leaves the other n − r free: |Ai1 ∩ ⋯ ∩ Air| = (n − r)!.
  3. There are C(n, r) ways to choose which r, and C(n, r)(n − r)! = n!/r!.
  4. So Dn = n! − n!/1! + n!/2! − ⋯, which factors as the formula.
Small cases

D3 = 6(1 − 1 + ½ − ⅙) = 2: the arrangements 231 and 312. D4 = 24 − 24 + 12 − 4 + 1 = 9.

As n grows, Dn/n! → 1/e ≈ 0.368 (the Taylor series for e−1). So about 37% of random permutations are derangements, for any large n.

11The hat-check problem (expected value)

An easier question: in a random permutation, what is the expected number of i in position i?

Solution with indicators
  1. Xi = 1 if i is in position i. The count is X1 + ⋯ + Xn.
  2. E(Xi) = (n − 1)!/n! = 1/n: fix i, then permute the other n − 1.
  3. By linearity, E = n · 1/n = 1, for every n.

12Onto functions

#onto functions from an m-set to an n-set = Σr=0n (−1)r C(n, r)(n − r)m
= nm − C(n,1)(n−1)m + C(n,2)(n−2)m − ⋯

Where it comes from

  1. All functions: nm (each of the m inputs picks one of n outputs).
  2. Ai = functions that miss output i. Onto = nm − |A1 ∪ ⋯ ∪ An|.
  3. Missing r particular outputs leaves n − r choices per input: (n − r)m, and there are C(n, r) ways to pick those r.
Example (Rosen) · from a 5-element set onto a 3-element set

35 − 3·25 + 3·15 = 243 − 96 + 3 = 150.

How many onto functions from a 4-element set to a 2-element set?tap

24 − 2·14 = 14: all 16 functions except the 2 constant ones.

Part 3 · Relations (not on Quiz 7)

Lecture 23 (Rosen 9.1). Not on tomorrow’s quiz: a head start for the next quiz and the final. A relation records which pairs of things are “related”.

13What a relation is

a binary relation R from A to B is a subset R ⊆ A × BA × B = all ordered pairs (a, b) with a ∈ A, b ∈ B. Write aRb when (a, b) ∈ R, and a R̸ b when it isn’t.

That’s the whole definition: a relation is just a set of ordered pairs. Any set of pairs counts, even one with no pattern.

Examples
  • A = {1, 2, 3}, B = {a, b, c, d}, R = {(1, a), (1, b), (2, c), (2, d)}. Then 1Ra is true, 3Ra is false.
  • A = Berkeley classes, B = classrooms, aRb if class a meets in room b: Math 55 R Wheeler 150.
  • A = B = web pages, aRb if page a links to page b.
Trap

Order matters: (a, b) and (b, a) are different pairs. aRb doesn’t mean bRa.

14Standard examples

  • On numbers: =, <, ≤ on ℝ; divisibility a | b on positive integers (3 | 6, but 3 ∤ 2); congruence a ≡ b (mod m) on ℤ; “relatively prime” (aRb if gcd(a, b) = 1).
  • On sets: “element of” from A to P(A) (1 ∈ {1, 2}); “subset” ⊆ on P(C).
  • Empty relation: R = ∅, nothing is related.
  • Complete relation: R = A × B, everything is related to everything.
  • Graph of a function f : A → B: {(a, b) : f(a) = b}. For f(x) = x² on ℕ: {(0,0), (1,1), (2,4), (3,9), …}, so 2R4 is true and 4R2 is false.

15Relations on one set

A relation on A is a relation from A to itself, a subset of A × A.

You can draw one as a diagram: a dot for each element, an arrow a → b whenever aRb, and a loop at a when aRa.

We’ll use this R as a running example in the next sections.

16Reflexive

R is reflexive if aRa for every a ∈ AIn the diagram: a loop at every dot.

To show not reflexive: find one a with a R̸ a.

Examples
  • Running example: not reflexive, since (3, 3) ∉ R.
  • ⊆: reflexive (every set is a subset of itself). | on positive integers: reflexive (a | a). Congruence mod m: reflexive.
  • gcd(a, b) = 1: not reflexive (gcd(2, 2) = 2). gcd(a, b) ≠ 1: not reflexive either (gcd(1, 1) = 1).
Trap

The gcd examples show a relation and its “opposite” can both fail to be reflexive. Reflexive needs every element; one failure ruins it.

17Symmetric & antisymmetric

symmetric: aRb ⟹ bRa
antisymmetric: aRb and bRa ⟹ a = b

Symmetric: every arrow has a return arrow. Antisymmetric: between two different elements there is never a two-way arrow (loops are fine).

Caution · not opposites

“Antisymmetric” does not mean “not symmetric”. A relation can be both (=), neither, or just one.

Examples
  • Running example: 1R2 but 2 R̸ 1, so not symmetric. No two-way arrows between different elements, so antisymmetric.
  • ≤ on ℝ: not symmetric (1 ≤ 3, 3 ≰ 1); antisymmetric (a ≤ b and b ≤ a forces a = b).
  • ⊆: not symmetric; antisymmetric (A ⊆ B and B ⊆ A means A = B).
  • | on positive integers: not symmetric (2 | 4, 4 ∤ 2); antisymmetric (a | b and b | a forces a = b for positive integers).
  • gcd = 1: symmetric, since gcd(a, b) = gcd(b, a); not antisymmetric (2R3 and 3R2 but 2 ≠ 3). Same for gcd ≠ 1.
  • Congruence mod m: symmetric; not antisymmetric (1 ≡ 4 and 4 ≡ 1 mod 3).
Trap

Divisibility on all integers is not antisymmetric: 2 | −2 and −2 | 2. The positive-integer version is.

18Transitive

R is transitive if aRb and bRc ⟹ aRcIn the diagram: whenever you can go a → b → c in two steps, there must also be a direct arrow a → c.

How to check a finite relation

  1. For each pair (a, b) in R, look at every pair (b, c) in R that starts where it ends.
  2. Check (a, c) is in R. One missing (a, c) is a counterexample.
Examples
  • Running example: 1R2 and 2R3, and 1R3 ✓. The other chains involve loops, which always work. Transitive.
  • ≤, ⊆, | and congruence mod m are all transitive.
  • gcd = 1: not transitive: 2R3 and 3R4, but gcd(2, 4) = 2.
  • gcd ≠ 1: not transitive: 2S6 and 6S3, but gcd(2, 3) = 1.
Trap

Watch chains that come back: R = {(1, 2), (2, 1)} has 1R2 and 2R1, so transitivity needs 1R1. It isn’t transitive.

20Counting relations

Let |A| = n. A relation on A is any subset of A × A, which has n² pairs. Decide in or out for each pair:

KindHow manyWhy
all relations2n²each of the n² pairs is in or out
reflexive2n² − nthe n pairs (a, a) are forced in; the other n² − n are free
symmetric2n(n+1)/2n loops are free, and each of the C(n, 2) pairs {a, b} is decided together: both in or both out
antisymmetric (Rosen)2n·3C(n,2)loops free; for each {a, b}: only (a,b), only (b,a), or neither

n + C(n, 2) = n + n(n − 1)/2 = n(n + 1)/2, which explains the symmetric exponent.

For n = 2, how many relations, reflexive, symmetric?tap

24 = 16; 22 = 4; 23 = 8. (Antisymmetric: 4·3 = 12.)

21Composition

S ∘ R = {(a, c) : there is b with aRb and bSc}R goes from A to B, S from B to C, so S ∘ R goes from A to C. Do R first, then S, just like composing functions g ∘ f.

How

  1. For each pair (a, b) in R, find every pair in S that starts with b.
  2. Each (b, c) found gives (a, c) in S ∘ R.
Example

R = {(1, a), (1, b), (2, c)} and S = {(a, x), (b, y), (c, x)}.

1 → a → x, 1 → b → y, 2 → c → x, so S ∘ R = {(1, x), (1, y), (2, x)}.

Lecture example · gcd = 1 composed with itself

For any a, b pick a prime p bigger than both. Then gcd(a, p) = 1 and gcd(p, b) = 1, so aRp and pRb. So R ∘ R relates every pair (a, b), even (2, 2).

Trap

Order: in S ∘ R, the pair from R comes first in the chain. S ∘ R and R ∘ S are usually different.

22Powers Rⁿ

R1 = R,  Rn+1 = Rn ∘ Ra Rn b exactly when there’s a path of length n from a to b: a = a0 → a1 → ⋯ → an = b, each step an arrow of R.
Lecture example · R = {(1,2), (2,3), (3,1)} on {1, 2, 3}
  1. R is a cycle 1 → 2 → 3 → 1.
  2. R² (two steps): 1 → 3, 2 → 1, 3 → 2. So R² = {(1,3), (2,1), (3,2)}.
  3. R³ (three steps returns home): {(1,1), (2,2), (3,3)}.
  4. R⁴ = R again, so the powers repeat every 3: R = R⁴ = R⁷ = …, R² = R⁵ = …, R³ = R⁶ = …
Rosen 9.1 theorem

R is transitive if and only if Rn ⊆ R for all n ≥ 1. Paths of any length must already be direct arrows.
