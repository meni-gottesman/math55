1Logic & quantifiers8 pts

(a) [4] Let P(x, y) be a predicate. Write the negation of

∀x ∃y ( P(x, y) ∧ ∀z ( P(x, z) → z = y ) )

with no ¬ to the left of any quantifier. Say in plain words what the original statement and its negation mean.

(b) [4] The domain is ℤ. True or false? Justify each briefly.

  1. ∀x ∃y (x = 2y ∨ x = 2y + 1)
  2. ∃y ∀x (xy = x)
  3. ∀x ∃y (xy = 1)
  4. ∃x ∀y (x ≤ y)
Solutiontap

(a) Push the ¬ inward one step at a time:

  1. ¬∀x ∃y (…) ≡ ∃x ∀y ¬( P(x, y) ∧ ∀z (P(x, z) → z = y) )
  2. De Morgan: ≡ ∃x ∀y ( ¬P(x, y) ∨ ¬∀z (P(x, z) → z = y) )
  3. ¬∀z ≡ ∃z ¬, and ¬(p → q) ≡ p ∧ ¬q:
∃x ∀y ( ¬P(x, y) ∨ ∃z ( P(x, z) ∧ z ≠ y ) )

Meaning. Original: every x has exactly one y with P(x, y). Negation: some x has no such y, or at least two (for every candidate y, either P(x, y) fails or some other z also works).

(b)

  1. True. Take y = ⌊x/2⌋: even x gives x = 2y, odd x gives x = 2y + 1.
  2. True. y = 1 works for every x.
  3. False. x = 2: 2y = 1 has no integer solution. (x = 0 also fails.)
  4. False. For any x, y = x − 1 is an integer with y < x. ℤ has no least element.
What it tests

Mechanical negation rules (¬∀ = ∃¬, De Morgan, ¬(p → q) ≡ p ∧ ¬q), and reading the order of quantifiers.

Common mistake

Negating p → q as p → ¬q or ¬p → ¬q. The negation of an implication is an and: p ∧ ¬q. Also: in (ii), ∃y ∀x means one y that works for all x, which is stronger than ∀x ∃y.

2Functions & cardinality10 pts

(a) [4] Define f : ℤ × ℤ → ℤ by f(a, b) = 4a + 6b. Is f one-to-one? Onto? Prove your answers, and describe the range.

(b) [3] Let E be the set of infinite sequences (s1, s2, …) of 0s and 1s containing only finitely many 1s. Prove E is countable.

(c) [3] Prove that the set B of all infinite 0–1 sequences is uncountable.

Solutiontap

(a) Not one-to-one: f(3, −2) = 12 − 12 = 0 = f(0, 0), but (3, −2) ≠ (0, 0). Not onto: 4a + 6b = 2(2a + 3b) is always even, so 1 is not in the range.

Range = all even integers. Given 2k, take a = −k, b = k: 4(−k) + 6k = 2k.

(b) For n ≥ 0 let En be the sequences in E whose 1s all lie among the first n positions. A sequence in En is determined by its first n entries, so |En| = 2n, finite. Every s ∈ E has a last 1 (finitely many 1s), so s ∈ En for some n: E = E0 ∪ E1 ∪ E2 ∪ ⋯.

List E0, then the new elements of E1, then the new elements of E2, and so on. Each block is finite, so every element of E appears at some finite position. That list is a bijection with ℤ⁺ (E is infinite), so E is countable.

(c) Cantor’s diagonal argument. Suppose B were countable, listed as s(1), s(2), s(3), … Define t by flipping the diagonal:

tn = 1 − s(n)n

t is an infinite 0–1 sequence, so t ∈ B. But t differs from s(n) in position n, for every n, so t is not on the list. Contradiction: no list contains all of B. ∎

What it tests

Proving one-to-one/onto with explicit witnesses; countable unions of finite sets; the diagonal argument.

Common mistake

In (c), building t but never saying why t is missing from the list (it differs from the n-th sequence in the n-th place). In (b), arguing “E ⊆ B and B is uncountable, so E is uncountable”: subsets of uncountable sets can be countable.

3Induction10 pts

(a) [6] Prove that 7 divides 32n+1 + 2n+2 for every integer n ≥ 0.

(b) [4] A sequence has a0 = 1, a1 = 2 and an = an−1 + 2an−2 for n ≥ 2. Prove by strong induction that an = 2n for all n ≥ 0.

Solutiontap

(a) Let P(n): 7 | 32n+1 + 2n+2.

  1. Base n = 0: 3 + 4 = 7. ✓
  2. Inductive hypothesis: assume 32k+1 + 2k+2 = 7m for some integer m.
  3. Step: 32k+3 + 2k+3 = 9·32k+1 + 2·2k+2 = 9(32k+1 + 2k+2) − 7·2k+2 = 9·7m − 7·2k+2 = 7(9m − 2k+2).
  4. So P(k + 1) holds, and by induction P(n) holds for all n ≥ 0. ∎

(Check n = 1: 27 + 8 = 35 = 5·7.)

(b)

  1. Bases: a0 = 1 = 20 and a1 = 2 = 21.
  2. Hypothesis: fix n ≥ 2 and assume aj = 2j for all 0 ≤ j < n.
  3. Step: an = an−1 + 2an−2 = 2n−1 + 2·2n−2 = 2n−1 + 2n−1 = 2n. ∎
What it tests

Writing a complete induction (base, hypothesis, step, conclusion) and the trick of making the hypothesis appear in the step. Strong induction when the recurrence reaches back two steps.

Common mistake

In (b), checking only one base case. The step for n = 2 uses a1 and a0, so both must be verified. In (a), “assuming P(k + 1)” and working backwards is not a proof.

4Modular arithmetic & CRT12 pts

(a) [4] Use the Euclidean algorithm to find the inverse of 17 modulo 60.

(b) [2] Solve 17x ≡ 9 (mod 60).

(c) [4] Find all integers x with x ≡ 2 (mod 5), x ≡ 3 (mod 7), x ≡ 4 (mod 9).

(d) [2] Compute 7222 mod 11.

Solutiontap

(a) Euclid:

60 = 3·17 + 9
17 = 1·9 + 8
9 = 1·8 + 1

Back-substitute: 1 = 9 − 8 = 9 − (17 − 9) = 2·9 − 17 = 2(60 − 3·17) − 17 = 2·60 − 7·17.

So −7·17 ≡ 1 (mod 60): the inverse is −7 ≡ 53. Check: 17·53 = 901 = 15·60 + 1. ✓

(b) Multiply both sides by 53: x ≡ 9·53 = 477 ≡ 477 − 420 = 57 (mod 60). Check: 17·57 = 969 = 16·60 + 9. ✓

(c) Moduli 5, 7, 9 are pairwise coprime, so by CRT there’s exactly one solution mod 315. Substitute step by step:

  1. x ≡ 4 (mod 9): x = 4 + 9k.
  2. Mod 7: 4 + 9k ≡ 4 + 2k ≡ 3, so 2k ≡ −1 ≡ 6, k ≡ 3 (mod 7). k = 3 + 7j, x = 31 + 63j.
  3. Mod 5: 31 + 63j ≡ 1 + 3j ≡ 2, so 3j ≡ 1, j ≡ 2 (mod 5) (since 3·2 = 6 ≡ 1). x = 31 + 126 = 157.
  4. x ≡ 157 (mod 315), i.e. x = 157 + 315t. Check: 157 = 155 + 2 = 154 + 3 = 153 + 4. ✓

(d) 11 is prime and 11 ∤ 7, so Fermat gives 710 ≡ 1 (mod 11). 222 = 22·10 + 2, so 7222 ≡ 72 = 49 ≡ 5 (mod 11).

What it tests

Extended Euclid by back-substitution, using an inverse to solve a linear congruence, CRT by substitution, Fermat’s little theorem.

Common mistake

In (d), reducing the exponent mod 11 instead of mod 10 (= p − 1). In (c), giving only 157 without “mod 315”: the question says all integers.

5Proof by contradiction & number theory10 pts

(a) [4] Prove that log2 3 is irrational.

(b) [6] Prove that if p is a prime with p > 3, then 24 | p² − 1.

Solutiontap

(a) Suppose log2 3 = a/b with integers a, b. Since 3 > 1, log2 3 > 0, so we may take a, b ≥ 1. Then 2a/b = 3, and raising to the b-th power, 2a = 3b. The left side is even (a ≥ 1); the right side is odd. Contradiction. ∎

(b) Write p² − 1 = (p − 1)(p + 1). Since 24 = 8·3 with gcd(8, 3) = 1, it’s enough to show 8 | p² − 1 and 3 | p² − 1.

  1. Divisible by 8: p is odd (it’s a prime > 2), so p = 2k + 1 and p² − 1 = 4k² + 4k = 4k(k + 1). One of k, k + 1 is even, so 8 | 4k(k + 1).
  2. Divisible by 3: p > 3 is prime, so 3 ∤ p, so p ≡ 1 or 2 (mod 3). Then p² ≡ 1 or 4 ≡ 1 (mod 3), so 3 | p² − 1.
  3. 8 and 3 are coprime and both divide p² − 1, so their product 24 does. ∎

(Examples: 5² − 1 = 24, 7² − 1 = 48, 11² − 1 = 120.)

What it tests

Setting up a contradiction cleanly; splitting divisibility by a composite into coprime parts; case analysis mod small numbers.

Common mistake

Combining 4 | p² − 1 and 6 | p² − 1 to claim 24 | p² − 1. That step needs coprime factors (4 and 6 share 2: 12 is divisible by both, not by 24). In (a), forgetting to say why a ≥ 1, which is what makes 2a even.

6Counting12 pts

(a) [4] How many solutions in nonnegative integers does x1 + x2 + x3 + x4 = 20 have with x1 ≥ 3 and x2 ≤ 5?

(b) [4] How many distinct arrangements of the letters of PARALLEL are there? In how many are no two L’s adjacent?

(c) [4] Give a combinatorial proof that Σk=0n C(n, k)·2k = 3n.

Solutiontap

(a)

  1. Lower bound: let y1 = x1 − 3 ≥ 0. Now y1 + x2 + x3 + x4 = 17.
  2. Ignoring the upper bound: C(17 + 3, 3) = C(20, 3) = 1140.
  3. Subtract the bad ones, x2 ≥ 6: set y2 = x2 − 6, total 11: C(14, 3) = 364.
  4. Answer: 1140 − 364 = 776.

(b) PARALLEL has 8 letters: L three times, A twice, P, R, E once. Arrangements: 8!/(3!·2!) = 40320/12 = 3360.

No two L’s adjacent (gap method): arrange the 5 non-L letters P, A, R, A, E: 5!/2! = 60 ways. They create 6 gaps (ends included); choose 3 different gaps for the L’s: C(6, 3) = 20. Total 60·20 = 1200.

(c) Count strings of length n over the alphabet {0, 1, 2} in two ways.

  • RHS: each of the n positions has 3 choices: 3n.
  • LHS: sort by k = the number of nonzero positions. Choose which k positions are nonzero, C(n, k) ways; fill each with 1 or 2, 2k ways; the rest are 0. Different k give different strings, so the total is Σ C(n, k)2k.

Both sides count the same set, so they’re equal. ∎

What it tests

Stars and bars with a lower bound (substitute) and an upper bound (complement), permutations with repeated letters, the gap method, double counting.

Common mistake

In (c), using the binomial theorem ((1 + 2)n): correct, but it is an algebraic proof and earns little when a combinatorial one is asked. In (b), subtracting “arrangements containing LL” from 3360 without handling LLL, which gets double-counted.

7Conditional probability & Bayes12 pts

(a) [5] 2% of a population carries a certain gene. A screening test is positive for 95% of carriers and for 10% of non-carriers. A random person tests positive. What is the probability they carry the gene?

(b) [4] Two fair dice are rolled. Find P(at least one 6 | the sum is 8) and P(the sum is 8 | at least one 6).

(c) [3] Let A = “the first die is even”, B = “the sum is 7”, C = “the sum is 8”. Is A independent of B? Of C?

Solutiontap

(a) G = carrier, + = positive. Bayes:

P(G | +) = P(+ | G)P(G) / [P(+ | G)P(G) + P(+ | Ḡ)P(Ḡ)]

= (0.95)(0.02) / [(0.95)(0.02) + (0.10)(0.98)] = 0.019 / (0.019 + 0.098) = 0.019/0.117 = 19/117 ≈ 0.162.

Only about 16%: carriers are so rare that the false positives among the 98% swamp the true positives.

(b) Sum 8: (2,6), (3,5), (4,4), (5,3), (6,2), 5 equally likely outcomes, 2 with a 6. P = 2/5.

At least one 6: 36 − 25 = 11 outcomes; of these, sum 8: (2,6), (6,2). P = 2/11.

(c) P(A) = 1/2, P(B) = 6/36 = 1/6. A ∩ B = {(2,5), (4,3), (6,1)}: 3/36 = 1/12 = (1/2)(1/6). Independent.

P(C) = 5/36. A ∩ C = {(2,6), (4,4), (6,2)}: 3/36 = 1/12, but P(A)P(C) = 5/72. Not independent.

What it tests

Bayes’ theorem with the law of total probability; conditioning as shrinking the sample space; the definition of independence.

Common mistake

Answering 0.95 in (a), which is P(+ | G), not P(G | +). In (b), the two conditionals are different numbers: the condition is the new sample space. In (c), deciding independence by intuition instead of checking P(A ∩ B) = P(A)P(B).

8Expectation, variance, Chebyshev14 pts

(a) [5] A fair die is rolled 90 times. Let X be the number of rolls showing 1 or 2. Find E(X) and V(X), and use Chebyshev’s inequality to bound P(|X − 30| ≥ 10).

(b) [5] A fair coin is flipped 12 times. Find the expected number of times the pattern HTH appears in three consecutive flips (overlaps count: HTHTH contains it twice).

(c) [4] Let Ij be the indicator that HTH starts at flip j. Are I1 and I2 independent? Are I1 and I3? Does your answer affect part (b)?

Solutiontap

(a) X is binomial with n = 90, p = 2/6 = 1/3 (the rolls are independent).

  1. E(X) = np = 30.
  2. V(X) = np(1 − p) = 90 · (1/3) · (2/3) = 20.
  3. Chebyshev: P(|X − E(X)| ≥ r) ≤ V(X)/r². With r = 10: P(|X − 30| ≥ 10) ≤ 20/100 = 1/5.

(The true value is about 0.033. Chebyshev is crude but always valid.)

(b) HTH can start at flips 1, 2, …, 10 (it needs 3 flips): 10 positions. Let Ij indicate that flips j, j+1, j+2 read HTH; E(Ij) = (1/2)³ = 1/8. By linearity of expectation:

E(count) = Σj=110 E(Ij) = 10 · 1/8 = 5/4

(c) I1 = I2 = 1 would need flip 2 to be T (for I1) and H (for I2). Impossible, so P(I1 = I2 = 1) = 0 ≠ (1/8)² = 1/64. Not independent.

I1 = I3 = 1 means flips 1–5 read HTHTH: probability 1/32 ≠ 1/64. Not independent either (they share flip 3).

No effect on (b): linearity of expectation holds for any random variables, independent or not. (Independence would matter for the variance.)

What it tests

Recognizing a binomial, Chebyshev’s inequality, indicator variables with linearity, and knowing linearity needs no independence.

Common mistake

Using 12 positions instead of 10 in (b). Believing E(X + Y) = E(X) + E(Y) requires independence; it’s V(X + Y) = V(X) + V(Y) that does.

9Recurrences12 pts

(a) [6] Solve an = an−1 + 6an−2 with a0 = 3, a1 = 4.

(b) [6] Let sn be the number of strings of length n over {0, 1, 2} in which no 0 is immediately followed by a 1 (no “01”). Find a recurrence for sn with initial conditions, and compute s5.

Solutiontap

(a)

  1. Characteristic equation: r² − r − 6 = 0, (r − 3)(r + 2) = 0, roots 3 and −2.
  2. General solution: an = α·3n + β·(−2)n.
  3. a0: α + β = 3. a1: 3α − 2β = 4. Adding 2×(first): 5α = 10, α = 2, β = 1.
  4. an = 2·3n + (−2)n. Check a2: recurrence 4 + 18 = 22; formula 18 + 4 = 22. ✓

(b) Split valid strings of length n ≥ 2 by their last character.

  1. Ends in 0 or 2: any valid string of length n − 1, then that character (appending 0 or 2 can’t create “01”): 2sn−1.
  2. Ends in 1: a valid string of length n − 1 that does not end in 0, then 1. Valid strings of length n − 1 ending in 0 are just valid strings of length n − 2 followed by 0: there are sn−2 of them. So this case gives sn−1 − sn−2.
  3. Total: sn = 3sn−1 − sn−2 for n ≥ 2, with s0 = 1 (empty string), s1 = 3.
  4. Check s2 = 9 − 1 = 8: all 9 strings except 01. ✓
  5. s3 = 24 − 3 = 21, s4 = 63 − 8 = 55, s5 = 165 − 21 = 144.

(Fun: these are every other Fibonacci number.)

What it tests

Solving a linear homogeneous recurrence with distinct roots, and building a recurrence by conditioning on the last character.

Common mistake

In (b), claiming the strings ending in 1 number 2sn−2 or sn−1. Always test the recurrence on a case you can count by hand (s2 = 8). If you start from s1, s2 instead of s0, that’s fine too.

10Inclusion–exclusion10 pts

(a) [5] How many integers from 1 to 1000 are divisible by none of 6, 10, 15?

(b) [5] How many permutations of 1, 2, 3, 4, 5, 6 have 1 not in position 1, 2 not in position 2, and 3 not in position 3? (4, 5, 6 may go anywhere.)

Solutiontap

(a) Ad = multiples of d in 1..1000, |Ad| = ⌊1000/d⌋.

  1. Singles: |A6| = 166, |A10| = 100, |A15| = 66. Sum 332.
  2. Pairs use the lcm: lcm(6, 10) = lcm(6, 15) = lcm(10, 15) = 30, each ⌊1000/30⌋ = 33. Sum 99.
  3. Triple: lcm(6, 10, 15) = 30: 33.
  4. |A6 ∪ A10 ∪ A15| = 332 − 99 + 33 = 266. None: 1000 − 266 = 734.

(b) Let Bi = permutations with i in position i, for i = 1, 2, 3. Fixing r particular values leaves (6 − r)! permutations.

6! − C(3,1)·5! + C(3,2)·4! − C(3,3)·3! = 720 − 360 + 72 − 6 = 426
What it tests

The complement form of inclusion–exclusion, lcm for “divisible by both”, and adapting the derangement argument when only some positions are restricted.

Common mistake

Using products (60, 90, 150, 900) instead of lcms in (a); that gives 700, not 734. In (b), quoting the derangement number D6 = 265, which restricts all six positions.

11Relations & posets14 pts

(a) [5] On ℤ, define a R b when 3 | a² − b². Prove R is an equivalence relation and describe its equivalence classes.

(b) [6] Let S = {2, 4, 5, 10, 12, 20, 25}, ordered by divisibility. Draw the Hasse diagram. Find all minimal and maximal elements and any least or greatest element. Find lub{2, 5} and glb{12, 20}. Is (S, |) a lattice? Give a topological sort of S.

(c) [3] How many relations on {1, 2, 3, 4} are both reflexive and symmetric? How many equivalence relations on {1, 2, 3, 4} contain the pair (1, 2)?

Solutiontap

(a) 3 | a² − b² ⟺ a² ≡ b² (mod 3) ⟺ f(a) = f(b), where f(a) = a² mod 3. A relation of the form f(a) = f(b) is reflexive, symmetric and transitive because = is. (Directly: a² − a² = 0; b² − a² = −(a² − b²); a² − c² = (a² − b²) + (b² − c²).)

Classes: squares mod 3 are 0² ≡ 0, 1² ≡ 1, 2² ≡ 1. So f takes two values and there are two classes: the multiples of 3, {…, −3, 0, 3, 6, …}, and the non-multiples of 3.

(b) Covering pairs: 2–4, 2–10, 5–10, 5–25, 4–12, 4–20, 10–20.

  • Minimal: 2, 5. Maximal: 12, 20, 25. No least (2, 5 incomparable), no greatest.
  • lub{2, 5}: upper bounds 10, 20; the least is 10.
  • glb{12, 20}: lower bounds 2, 4; the greatest is 4.
  • Not a lattice: {4, 25} has no upper bound (no element of S is divisible by both; their lcm 100 ∉ S). (Also {12, 20} has no upper bound.)
  • Topological sort (repeatedly remove a minimal element): 2, 5, 4, 10, 12, 20, 25. Any order respecting the edges is fine.

(c) Reflexive forces the 4 loops. Symmetric: each of the C(4, 2) = 6 unordered pairs {a, b} is in (both directions) or out. 26 = 64.

Equivalence relations containing (1, 2) ↔ partitions of {1, 2, 3, 4} with 1, 2 in the same block ↔ partitions of the 3 objects {12, 3, 4}: B3 = 5.

What it tests

Proving an equivalence relation and finding classes; reading a poset (covers, maximal vs greatest, bounds); counting relations with constraints.

Common mistake

Saying 12 is the “greatest” because it is the largest number: 5 ∤ 12. Maximal ≠ greatest. In the Hasse diagram, drawing 2–20 or 5–20 (10 or 4 sits between). In (a), listing three classes [0], [1], [2]: [1] = [2] here because 1 ≡ 4 (mod 3).

12Graphs16 pts

(a) [3] A simple graph has 12 vertices: 6 have degree 5 and the other 6 all have the same degree d. It has 24 edges. Find d. Could a simple graph have 7 vertices, each of degree 3?

(b) [5] G1 is the cube Q3. G2 has vertices 0, 1, …, 7, with the 8-cycle 0–1–2–3–4–5–6–7–0 plus the four edges 0–4, 1–5, 2–6, 3–7. Are G1 and G2 isomorphic? Prove your answer.

(c) [4] Prove that every simple graph with at least 2 vertices has two vertices of the same degree.

(d) [4] H has vertices 1, …, 5 and edges 12, 13, 23, 24, 34, 35, 45. Using the adjacency matrix A (or otherwise), find the number of paths of length 2 from 1 to 4, the number of paths of length 3 from 1 to 5, and the number of triangles in H.

Solutiontap

(a) Handshaking: Σ deg = 2|E| = 48 = 6·5 + 6d, so 6d = 18, d = 3. Seven vertices of degree 3 would give degree sum 21, odd, which is impossible: no.

(b) Not isomorphic. Both have 8 vertices, 12 edges and every degree 3, so the easy invariants agree. But:

  • Q3 is bipartite: split the bit strings by the parity of their number of 1s; every edge flips one bit, so it joins opposite parities. Hence Q3 has no odd cycle.
  • G2 has the 5-cycle 0–1–2–3–4–0 (four cycle edges plus the edge 4–0).

Isomorphisms carry cycles to cycles of the same length, so they can’t be isomorphic. ∎

(c) Let n ≥ 2 be the number of vertices. In a simple graph each degree is in {0, 1, …, n − 1}: n possible values. But 0 and n − 1 can’t both occur: a vertex of degree n − 1 is adjacent to every other vertex, so no vertex has degree 0. So the n degrees take at most n − 1 different values, and by the pigeonhole principle two vertices share a degree. ∎

  • The diagonal of A³ is 2, 4, 6, 4, 2, so trace(A³) = 18, and triangles = 18/6 = 3 (123, 234, 345).
What it tests

Handshaking and its parity consequence; disproving isomorphism with an invariant (bipartite / odd cycle); a pigeonhole proof; counting paths with powers of the adjacency matrix.

Common mistake

In (b), stopping at “same degree sequence, so isomorphic”. In (c), forgetting to rule out degrees 0 and n − 1 together; without that, there are n pigeons and n holes and no conclusion.
