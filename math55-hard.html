ALogic & quantifiers

Rosen 1.1–1.6 · equivalences, functional completeness, nested quantifiers, negation, translation, rules of inference

A1HardComputation

Are (p → q) → r and p → (q → r) logically equivalent? If not, list every truth assignment where they differ, and decide whether either one implies the other.

Full solutiontap

Rewrite both using a → b ≡ ¬a ∨ b:

  • p → (q → r) ≡ ¬p ∨ ¬q ∨ r ≡ (p ∧ q) → r. It is false only at (p,q,r) = (T,T,F).
  • (p → q) → r ≡ ¬(¬p ∨ q) ∨ r ≡ (p ∧ ¬q) ∨ r. It is false when r = F and p ∧ ¬q is false: (T,T,F), (F,T,F), (F,F,F).

Not equivalent. They differ at (F,T,F) and (F,F,F), where the left side is false and the right side is true.

The left side is false at every row where the right side is false (the one row, TTF). So whenever the left side is true, the right side is true too: ((p → q) → r) → (p → (q → r)) is a tautology. The converse fails at (F,F,F).

Tests: → is not associative; checking "implies" means comparing the rows where each side is false. Common mistake: moving the parentheses as if → were ∧ or ∨.

A2HardNested quantifiers

The domain of every variable is ℤ. Give the truth value of each statement and justify it (a witness, a counterexample, or a short proof).

  1. ∀x ∃y (x = 2y ∨ x = 2y + 1)
  2. ∃y ∀x (x + y = xy)
  3. ∀x ∃y ∀z (z > y → z > x)
  4. ∃x ∀y (xy = y)
  5. ∀y ∃x (x² = y)
  6. ∀x ∀y ∃z (z² = x² + y²)
Full solutiontap
  1. True. Given x, take y = ⌊x/2⌋. The division algorithm gives x = 2y + r with r ∈ {0, 1}.
  2. False. Suppose some y works for every x. Taking x = 0 gives y = 0. Then taking x = 1 gives 1 + 0 = 0, which is false.
  3. True. Given x, take y = x. Then z > y → z > x is literally z > x → z > x, which holds for all z.
  4. True. The witness is x = 1.
  5. False. Counterexample: y = 2 (or y = −1). No integer squares to it.
  6. False. Counterexample: x = y = 1. That needs z² = 2, and no integer z works.

Tests: reading the quantifier order. In (c), y is chosen after x but before z, so it may depend on x and not on z. Common mistake: in (b) or (d), letting the ∃ variable depend on the ∀ variable that comes after it. ∃y∀x means one single y must work for every x.

A3HardPuzzle · case analysis

Knights always tell the truth and knaves always lie. A says: “B and C are both knaves.” B says: “Exactly one of the three of us is a knight.” C says: “B is a knave.” Find every possible assignment, and prove there are no others.

Full solutiontap

Case 1: B is a knight. Then B’s statement is true: B is the only knight, so A and C are knaves. Check the knaves: A says “B and C are both knaves”, which is false since B is a knight. Good. C says “B is a knave”, which is false. Good. This case is consistent.

Case 2: B is a knave. Then C’s statement is true, so C is a knight. B’s statement is false, so the number of knights is not 1. C is a knight and B is not, so there are 1 or 2 knights, which means exactly 2, and A is a knight. But then A’s statement “B and C are both knaves” must be true, and it is false because C is a knight. Contradiction.

The only solution: A is a knave, B is a knight, C is a knave.

Tests: splitting into exhaustive cases and checking every speaker in each case. Common mistake: finding one consistent assignment and stopping. The question asks you to rule out the others.

A4HarderCounting × logic

Two compound propositions count as the same if they are logically equivalent.

  1. How many different propositions φ(p, q, r) make φ → (p ∨ q) a tautology?
  2. How many satisfy φ(¬p, ¬q, ¬r) ≡ ¬φ(p, q, r) (they are called self-dual)?
Full solutiontap

Up to equivalence, a proposition in p, q, r is the same thing as its truth table: one T/F value for each of the 8 rows. That gives 2⁸ = 256 in total.

(a) φ → (p ∨ q) fails only where φ is T and p ∨ q is F. So φ must be F on the rows with p = q = F (2 rows, r free). The other 6 rows are free: 2⁶ = 64.

(b) Flipping all three variables pairs the 8 rows into 4 complementary pairs, such as TTT↔FFF and TTF↔FFT. The condition says φ takes opposite values on the two rows of each pair. So choosing φ on one row of each pair decides everything: 2⁴ = 16.

Tests: treating propositions as truth tables, then counting with the product rule. Common mistake: counting formulas (there are infinitely many) instead of equivalence classes.

A5HarderConstruction

Let p ↑ q (NAND) mean ¬(p ∧ q).

  1. Write ¬p, p ∧ q, p ∨ q and p → q using only ↑.
  2. Prove that {↑} is functionally complete.
  3. Write p ⊕ q using exactly four ↑’s.
Full solutiontap

(a)

  • ¬p ≡ p ↑ p, since ¬(p ∧ p) ≡ ¬p.
  • p ∧ q ≡ ¬(p ↑ q) ≡ (p ↑ q) ↑ (p ↑ q).
  • p ∨ q ≡ ¬(¬p ∧ ¬q) ≡ (p ↑ p) ↑ (q ↑ q) (De Morgan).
  • p → q ≡ ¬(p ∧ ¬q) ≡ p ↑ (q ↑ q).

(b) Every truth table is expressed by its disjunctive normal form, which uses only ¬, ∧, ∨. So {¬, ∧, ∨} is functionally complete. Each of those three operators can be written with ↑ by part (a). Replacing them one at a time turns any formula into an equivalent formula that uses only ↑. ∎

(c) Let t = p ↑ q. Then p ⊕ q ≡ (p ↑ t) ↑ (q ↑ t). Check: p ↑ t ≡ ¬p ∨ (p ∧ q) ≡ ¬p ∨ q, and similarly q ↑ t ≡ ¬q ∨ p. So the whole thing is ¬[(p → q) ∧ (q → p)] ≡ ¬(p ↔ q) ≡ p ⊕ q. All four rows were checked.

Tests: functional completeness means reducing to a set that is already known to be complete. Common mistake: “proving” completeness by expressing two or three examples. You must cover a complete set of connectives.

A6HarderTranslation & negation

Let L(x, y) mean “x loves y” (the domain is all people). In (b) and (d), push every ¬ all the way in.

  1. Translate: “There is exactly one person whom everybody loves.” (Don’t use ∃!.)
  2. Negate (a), then say the negation in plain English.
  3. Translate: “Everybody loves someone who doesn’t love them back.”
  4. Negate: ∀ε > 0 ∃N ∀n ≥ N (|an − L| < ε).
Full solutiontap
  1. ∃x [ ∀y L(y, x) ∧ ∀z ( ∀y L(y, z) → z = x ) ]
  2. ∀x [ ∃y ¬L(y, x) ∨ ∃z ( ∀y L(y, z) ∧ z ≠ x ) ]. In English: for every person x, either someone doesn’t love x, or some other person is loved by everybody. In other words, nobody is loved by everyone, or at least two people are.
  3. ∀x ∃y ( L(x, y) ∧ ¬L(y, x) )
  4. ∃ε > 0 ∀N ∃n ≥ N (|an − L| ≥ ε). The restriction ε > 0 stays as it is: ¬∀ε>0 P becomes ∃ε>0 ¬P.

Tests: encoding “exactly one” as existence plus uniqueness, and negating restricted quantifiers. Common mistake: in (d), writing “∃ε ≤ 0”, or negating ∀z(A → B) as ∃z(A → ¬B) instead of ∃z(A ∧ ¬B).

A7HarderValid or not?

For each one, prove it is valid or give a counterexample (a domain and predicates). In (d), Q is a proposition with no free x, and the domain is nonempty.

  1. ∃x P(x) ∧ ∃x Q(x) implies ∃x (P(x) ∧ Q(x)).
  2. ∀x (P(x) ∨ Q(x)) implies ∀x P(x) ∨ ∀x Q(x).
  3. ∃x ∀y R(x, y) implies ∀y ∃x R(x, y).
  4. ∀x (P(x) → Q) ≡ (∃x P(x)) → Q.
  5. The converse of (c).
Full solutiontap
  1. Invalid. Domain ℤ, P = “even”, Q = “odd”. Both existentials are true, and no integer is both.
  2. Invalid. Same P and Q. Every integer is even or odd, but neither “all even” nor “all odd” holds.
  3. Valid. Assume ∃x ∀y R(x, y). Let a be such an x (existential instantiation). Let y be arbitrary. Then R(a, y) (universal instantiation), so ∃x R(x, y) (existential generalization). Since y was arbitrary, ∀y ∃x R(x, y) (universal generalization).
  4. Valid. The left side is ∀x (¬P(x) ∨ Q). If Q is true, both sides are true. If Q is false, the left side becomes ∀x ¬P(x) ≡ ¬∃x P(x), and the right side (∃x P(x)) → F is also ¬∃x P(x).
  5. Invalid. Domain ℤ, R(x, y): x > y. Every y has a bigger x, but no x is bigger than every y.

Tests: ∃ distributes over ∨ (not ∧), and ∀ distributes over ∧ (not ∨). Common mistake: in (d), expecting the answer ∀x P(x) → Q. A ∀ inside the antecedent turns into ∃ when you pull it out.

A9BrutalProof · structural induction × logic
  1. Prove that {∧, ∨, →} is not functionally complete. Show that every formula built from variables using only ∧, ∨, → is true when all its variables are true, and conclude that ¬p cannot be expressed.
  2. Prove that p → q cannot be expressed using only ∧ and ∨.
Full solutiontap

(a) Let v be the assignment that makes every variable true. Claim: every formula φ in the class satisfies v(φ) = T. We use structural induction on how formulas are built.

Basis. φ is a variable, and v makes it true.

Inductive step. Suppose v(α) = v(β) = T. Then v(α ∧ β) = T ∧ T = T, v(α ∨ β) = T ∨ T = T, and v(α → β) = T → T = T.

So every such formula is true under v. But ¬p is false under v, so no formula in the class is equivalent to ¬p. A functionally complete set would express ¬p. ∎

(b) Use the same argument with the all-false assignment w. Variables are false under w, and F ∧ F = F, F ∨ F = F. So every {∧, ∨} formula is false under w. But w(p → q) = F → F = T, so p → q is not expressible. ∎

Tests: proving that something is impossible by finding an invariant that every buildable formula keeps. Common mistake: trying a few formulas, failing, and calling that a proof.

BProof techniques

Rosen 1.7–1.8 · direct, contrapositive, contradiction, cases, existence and uniqueness, iff, strategy stealing, infinite descent

B1HardTrue or false?

Prove each statement or give a counterexample. All letters are integers unless stated otherwise.

  1. If a | bc and a ∤ b, then a | c.
  2. The product of two irrational numbers is irrational.
  3. If x > 0 is irrational, then √x is irrational.
  4. n² − n + 41 is prime for every n ≥ 1.
  5. If 6 | n², then 6 | n.
  6. If 4 | n², then 4 | n.
Full solutiontap
  1. False. a = 4, b = c = 2: 4 | 4, 4 ∤ 2, and 4 ∤ 2.
  2. False. √2 · √2 = 2.
  3. True (contrapositive). If √x = p/q is rational, then x = p²/q² is rational.
  4. False. n = 41 gives 41², which is not prime.
  5. True. If 2 | n², then n is even (an odd n gives an odd n²). If 3 | n², then 3 | n, because 3 is prime and divides n·n (Euclid’s lemma). Since gcd(2, 3) = 1 and both divide n, 6 | n.
  6. False. n = 2.

Tests: one counterexample kills a universal claim; a true one needs a real proof. Common mistake: on (e), arguing “6 | n·n, so 6 | n” as if 6 were prime. That is exactly the argument that fails in (f).

B2HardProof by cases

Prove that x² + y² = 4z + 3 has no integer solutions. Conclude that 2027 is not a sum of two squares.

Full solutiontap

Lemma. Every square is ≡ 0 or 1 (mod 4). If n = 2k, then n² = 4k². If n = 2k + 1, then n² = 4(k² + k) + 1.

So x² + y² ≡ 0 + 0, 0 + 1, or 1 + 1, that is, 0, 1 or 2 (mod 4), and never 3. But 4z + 3 ≡ 3. No solution. ∎

2027 = 4·506 + 3, so it is not a sum of two squares.

Tests: choosing a modulus that makes the cases finite. Common mistake: splitting into 4 cases (x and y each even or odd) and then making an algebra error. Use the lemma once instead.

B3HardIf and only if

Prove: a positive integer n is a perfect square if and only if it has an odd number of positive divisors.

Full solutiontap

Pair each divisor d of n with n/d, which is also a divisor. This pairing is its own inverse: the partner of n/d is d. A divisor is paired with itself exactly when d = n/d, that is, d² = n.

(⇐) Suppose n is not a square. Then no divisor is paired with itself, the divisors split into pairs {d, n/d} with d ≠ n/d, and their number is even. Contrapositive: an odd number of divisors means n is a square.

(⇒) Suppose n = m² with m > 0. The only divisor paired with itself is m (the positive solution of d² = n). Every other divisor sits in a pair of two distinct divisors, so the count is 2·(number of pairs) + 1, which is odd. ∎

Tests: an iff needs both directions; a pairing (involution) argument proves a parity claim. Common mistake: proving one direction twice, phrased differently.

B4HarderContradiction

Prove that √2 + √3 is irrational. (Prove any lemma you use.)

Full solutiontap

Lemma: √6 is irrational. Suppose √6 = a/b in lowest terms. Then a² = 6b², so a² is even and a is even. Write a = 2c: 4c² = 6b², so 2c² = 3b². Then 3b² is even, so b² is even and b is even. Both a and b are even, contradicting lowest terms.

Main proof. Suppose √2 + √3 = r with r rational. Squaring: r² = 5 + 2√6, so √6 = (r² − 5)/2, which is rational. This contradicts the lemma. ∎

Tests: reducing to a simpler irrationality and proving it in full. Common mistake: claiming “a sum of irrationals is irrational”, which is false (√2 + (−√2) = 0).

B5HarderContradiction

Prove that log2 3 is irrational.

Full solutiontap

Since 3 > 1, log23 > 0. Suppose log23 = a/b with a, b positive integers. Then 2a/b = 3, and raising both sides to the power b gives 2a = 3b. Since a ≥ 1 the left side is even, and the right side is odd. Contradiction. ∎

Tests: getting rid of logs and roots by exponentiating, then using parity. Common mistake: forgetting to justify a, b > 0. With a = 0 the left side would be 1, which is odd.

B6HarderFind the error

Each “proof” below is wrong. Find the error and say whether the claim is true anyway.

  1. Claim: if 4 | n² then 4 | n. Proof: Let n = 4k. Then n² = 16k² = 4(4k²), so 4 | n².
  2. Claim: for real x, if x² > 4 then x > 2. Proof (contrapositive): If x ≤ 2, then x² ≤ 4.
  3. Claim: a + b ≥ 2√(ab) for a, b ≥ 0. Proof: Assume a + b ≥ 2√(ab). Squaring, a² + 2ab + b² ≥ 4ab, so (a − b)² ≥ 0, which is true. Done.
Full solutiontap
  1. It proves the converse (4 | n ⇒ 4 | n²). The claim itself is false: n = 2.
  2. “x ≤ 2 ⇒ x² ≤ 4” is false for x = −3. The claim is false: x = −3 has x² = 9 > 4.
  3. It starts from the conclusion and reaches something true. That proves nothing, since true statements follow from false ones too. The claim is true. A correct proof: 0 ≤ (√a − √b)² = a − 2√(ab) + b. Here every step goes in the forward direction.

Tests: the direction of implication. Common mistake: (c) is how many students write proofs. If you work backward on scratch paper, write the final proof forward.

B7HarderContrapositive

Prove: if 2n + 1 is prime (n ≥ 1), then n is a power of 2. Is the converse true?

Full solutiontap

Contrapositive: if n is not a power of 2, then 2n + 1 is composite. A number that is not a power of 2 has an odd factor m > 1, so write n = mk with m odd, m ≥ 3, k ≥ 1.

For odd m, xm + 1 = (x + 1)(xm−1 − xm−2 + ⋯ − x + 1). Multiply it out: the terms telescope. Put x = 2k: (2k + 1) | (2n + 1). Since 1 ≤ k < n, we have 1 < 2k + 1 < 2n + 1, a proper factor. So 2n + 1 is composite. ∎

Converse: false. 232 + 1 = 641 · 6700417.

Tests: spotting a factorization identity, and checking that the factor is proper. Common mistake: using xm + 1 with m even, where (x + 1) does not divide it.

B8HarderExistence & uniqueness
  1. Constructive existence. Prove there are 100 consecutive composite positive integers.
  2. Uniqueness. Prove that for every real x there is at most one integer n with n ≤ x < n + 1.
  3. Nonconstructive existence. Prove that if 7 real numbers sum to 50, at least one of them is greater than 7.
Full solutiontap

(a) Consider 101! + j for j = 2, 3, …, 101. Since 2 ≤ j ≤ 101, j divides 101!, so j divides 101! + j, and 1 < j < 101! + j. So all 100 numbers are composite.

(b) Suppose n and m both work. From n ≤ x < m + 1 we get n < m + 1, and symmetrically m < n + 1. So |n − m| < 1, and since n − m is an integer, n = m.

(c) Suppose not: every xi ≤ 7. Then the sum is at most 49 < 50. Contradiction. (We never find which number is big.)

Tests: the three flavors: build it, show two candidates must be equal, argue by contradiction. Common mistake: in (a), using 100! + j for j up to 101. The last one, 100! + 101, need not be composite.

B9BrutalStrategy stealing

The numbers 1, 2, …, n (n ≥ 2) are on a board. Two players alternate. A move is: pick a number still on the board and erase it and all of its divisors still on the board. The player who erases the last number wins. Prove that the first player has a winning strategy. (You may use: in a finite game with no draws, one player has a winning strategy.)

Full solutiontap

The game is finite (each move erases at least one number) and cannot be drawn, so one of the players has a winning strategy. Suppose, for contradiction, that it is the second player.

Let the first player open by picking 1. That erases only 1. The second player’s winning strategy now gives a reply: pick some m, erasing m and its divisors. Call the resulting position X. From X, the second player (who just moved) can force a win against any play.

Now the first player could instead have opened by picking m. Since 1 | m, that single move erases 1, m and every divisor of m, reaching exactly the same position X. The first player is then the one who just moved into X, and so can follow the strategy that wins from X. So the first player can force a win, which contradicts the assumption that the second player has a winning strategy.

Therefore the first player has a winning strategy. ∎ (The proof doesn’t say what the strategy is.)

Tests: strategy stealing: a “do-nothing” move that can be absorbed into any reply. Common mistake: forgetting why the stolen move reaches the same position. Here it is because 1 divides everything.

B10BrutalInfinite descent / well-ordering

Prove that a² + b² = 3c² has no solution in positive integers. Deduce that the circle x² + y² = 3 contains no point with both coordinates rational.

Full solutiontap

Squares mod 3 are 0 (if 3 | n) or 1 (n ≡ ±1 gives n² ≡ 1).

Suppose solutions exist. By well-ordering, choose one with c as small as possible. Then a² + b² ≡ 0 (mod 3). The only way to get 0 from two values in {0, 1} is 0 + 0, so 3 | a and 3 | b. Write a = 3a′, b = 3b′: 9(a′² + b′²) = 3c², so c² = 3(a′² + b′²). Then 3 | c², so 3 | c. Write c = 3c′: a′² + b′² = 3c′². This is a solution in positive integers with c′ = c/3 < c, which contradicts minimality. ∎

Circle. If x = p/r and y = q/r (common denominator r > 0) satisfy x² + y² = 3, then p² + q² = 3r². By the above, p and q can’t both be positive. If either is 0, say q = 0, we get p² = 3r², which would make √3 rational. Signs don’t matter since only squares appear. So there are no rational points.

Tests: descent: a solution produces a smaller one, contradicting well-ordering. Common mistake: forgetting to set up the minimal counterexample, which leaves the descent unfinished.

CSets, functions, cardinality

Rosen 2.1–2.3, 2.5 · identities, floor and ceiling, injective/surjective, composition, countability, diagonal arguments

C1HardProve or disprove
  1. A − (B − C) = (A − B) ∪ (A ∩ C)
  2. (A × B) ∪ (C × D) = (A ∪ C) × (B ∪ D)
  3. 𝒫(A) ∩ 𝒫(B) = 𝒫(A ∩ B)
  4. 𝒫(A) ∪ 𝒫(B) = 𝒫(A ∪ B). Find exactly when it holds.
Full solutiontap

(a) True. For any x: x ∈ A − (B − C) ⇔ x ∈ A ∧ ¬(x ∈ B ∧ x ∉ C) ⇔ x ∈ A ∧ (x ∉ B ∨ x ∈ C) ⇔ (x ∈ A ∧ x ∉ B) ∨ (x ∈ A ∧ x ∈ C) ⇔ x ∈ (A − B) ∪ (A ∩ C).

(b) False. A = B = {1}, C = D = {2}. Then (1, 2) is in the right side but not the left. (Only ⊆ holds.)

(c) True. S ∈ 𝒫(A) ∩ 𝒫(B) ⇔ S ⊆ A and S ⊆ B ⇔ S ⊆ A ∩ B.

(d) It holds if and only if A ⊆ B or B ⊆ A. If A ⊆ B, then A ∪ B = B and 𝒫(A) ⊆ 𝒫(B), so both sides equal 𝒫(B). If neither contains the other, pick a ∈ A − B and b ∈ B − A. Then {a, b} ∈ 𝒫(A ∪ B), but {a, b} ⊄ A (since b ∉ A) and {a, b} ⊄ B. For example, A = {1}, B = {2}.

Tests: element-chasing proofs, and Cartesian products. Common mistake: drawing a Venn diagram for (b). Products aren’t unions of regions; think of rectangles in a grid.

C2HardFloor & ceiling proofs
  1. Prove ⌊2x⌋ = ⌊x⌋ + ⌊x + ½⌋ for all real x.
  2. Prove ⌊⌊x/2⌋/2⌋ = ⌊x/4⌋ for all real x.
  3. True or false: ⌈x⌉ + ⌈y⌉ = ⌈x + y⌉.
Full solutiontap

(a) Write x = n + ε with n = ⌊x⌋ and 0 ≤ ε < 1.

  • If ε < ½: 2x = 2n + 2ε with 0 ≤ 2ε < 1, so ⌊2x⌋ = 2n. Also x + ½ = n + (ε + ½) with ½ ≤ ε + ½ < 1, so ⌊x + ½⌋ = n. The sum is n + n = 2n. ✓
  • If ε ≥ ½: 1 ≤ 2ε < 2, so ⌊2x⌋ = 2n + 1. Also x + ½ = (n + 1) + (ε − ½) with 0 ≤ ε − ½ < ½, so ⌊x + ½⌋ = n + 1. The sum is 2n + 1. ✓

(b) Let n = ⌊x/2⌋ and k = ⌊n/2⌋. Then 2k ≤ n ≤ 2k + 1, since n is an integer below 2k + 2. From n ≤ x/2 < n + 1: 4k ≤ 2n ≤ x < 2n + 2 ≤ 4k + 4. So k ≤ x/4 < k + 1, which means ⌊x/4⌋ = k. ✓

(c) False. x = y = ½: 1 + 1 = 2, but ⌈1⌉ = 1.

Tests: the standard method: write x = n + ε and split on where ε lies. Common mistake: using ⌊n/2⌋ ≤ n/2 without the sharper integer bound n ≤ 2k + 1, which is what makes (b) work.

C3HardInjective / surjective

Decide injective, surjective, both or neither, with proof:

  1. f: ℤ → ℤ, f(n) = n + (−1)n. If it is a bijection, find its inverse.
  2. g: ℤ × ℤ → ℤ, g(m, n) = 2m + 3n.
  3. h: ℕ × ℕ → ℤ+, h(m, n) = 2m3n.
Full solutiontap

(a) Bijection, and it is its own inverse. For even n, f(n) = n + 1, which is odd, so f(f(n)) = (n + 1) − 1 = n. For odd n, f(n) = n − 1, which is even, so f(f(n)) = (n − 1) + 1 = n. Since f ∘ f = id, f has an inverse (itself), so it is bijective.

(b) Surjective, not injective. For any k, g(−k, k) = −2k + 3k = k. But g(3, 0) = 6 = g(0, 2).

(c) Injective, not surjective. If 2m3n = 2m′3n′, unique prime factorization gives m = m′ and n = n′. The value 5 is never hit.

Tests: proving bijectivity by exhibiting an inverse. Common mistake: “checking” injectivity on a few inputs. You need the general argument (or one collision to disprove it).

C4HarderComposition · proofs & counterexamples

Let f: A → B and g: B → C.

  1. Prove: if g ∘ f is injective, then f is injective.
  2. Prove: if g ∘ f is surjective, then g is surjective.
  3. Give an example where g ∘ f is a bijection but neither f nor g is.
  4. True or false: if f and g ∘ f are bijections, then g is a bijection.
Full solutiontap

(a) If f(a) = f(a′), apply g: (g ∘ f)(a) = (g ∘ f)(a′). Injectivity of g ∘ f gives a = a′.

(b) Let c ∈ C. Some a has g(f(a)) = c, so b = f(a) ∈ B satisfies g(b) = c.

(c) A = C = {1}, B = {1, 2}, f(1) = 1, g(1) = g(2) = 1. Then g ∘ f = id{1}, but f misses 2 and g sends two inputs to 1.

(d) True. g = (g ∘ f) ∘ f−1, a composition of bijections.

Tests: which function inherits which property: the inner one gets injectivity, the outer one gets surjectivity. Common mistake: concluding that g is injective from (a). Example (c) refutes that.

C5HarderCounting functions
  1. How many functions f: {1,2,3,4} → {1,2,3,4} satisfy f ∘ f = f? Prove the characterization you use.
  2. How many f: {1,…,5} → {1,…,5} satisfy f ∘ f = id?
  3. How many f: {1,2,3,4} → {1,2,3,4} satisfy f ∘ f ∘ f = id?
Full solutiontap

(a) Claim: f ∘ f = f ⇔ f fixes every point of its image. (⇒) If y = f(x), then f(y) = f(f(x)) = f(x) = y. (⇐) f(x) is in the image, so f(f(x)) = f(x).

(b) f ∘ f = id makes f a bijection (it is its own inverse) whose cycles have length 1 or 2. With zero, one or two swaps: 1 + C(5,2) + C(5,2)·C(3,2)/2 = 1 + 10 + 15 = 26.

(c) f is a bijection (f ∘ f is its inverse), and every cycle length divides 3. So f is the identity or a single 3-cycle: 1 + C(4,3)·2 = 9. (A set of 3 elements carries 2 different 3-cycles.)

C6HarderConstruction · explicit bijection
  1. Give an explicit bijection from (0, 1] to (0, 1) and prove it is one.
  2. Do the same from [0, 1] to (0, 1).
  3. Prove |[0,1]| = |(0,1)| a second way, using the Schröder–Bernstein theorem.
Full solutiontap

(a) Define f(1/n) = 1/(n + 1) for n = 1, 2, 3, …, and f(x) = x for every other x. It shifts the sequence 1, ½, ⅓, … one step along, the way Hilbert’s hotel does.

  • Injective: f is injective on S = {1/n : n ≥ 1} and on its complement, and the images f(S) = {1/n : n ≥ 2} and (0,1] − S don’t overlap.
  • Surjective: take y ∈ (0, 1). If y = 1/m with m ≥ 2, then y = f(1/(m − 1)). Otherwise y ∉ S and y = f(y).

(b) Send 0 ↦ ½, 1/n ↦ 1/(n + 2) for n ≥ 1, and fix everything else. The set {0, 1, ½, ⅓, …} goes onto {½, ⅓, ¼, …}, so the same two checks work.

(c) Inclusion (0,1) → [0,1] is injective, and x ↦ x/2 + ¼ injects [0,1] into [¼, ¾] ⊂ (0,1). Schröder–Bernstein then gives a bijection.

Tests: absorbing extra points into a countable sequence. Common mistake: mapping 1 ↦ ½ and leaving ½ fixed, so two points collide.

C7HarderCountable or uncountable?

Classify each set, with proof.

  1. All finite bit strings.
  2. All infinite bit strings with only finitely many 1s.
  3. All infinite bit strings with infinitely many 1s.
  4. All reals in (0,1) whose decimal expansion uses only the digits 3 and 7.
  5. All polynomials with integer coefficients.
Full solutiontap

(a) Countable. List them by length, and within a length lexicographically: λ, 0, 1, 00, 01, …

(b) Countable. Such a string is determined by the finite set S of positions holding a 1. The map S ↦ Σi∈S 2i is a bijection to ℕ, by uniqueness of binary expansions.

(c) Uncountable. All infinite bit strings form an uncountable set (diagonal argument). That set is the union of (b) and (c). If (c) were countable, the union of two countable sets would be countable. Contradiction.

(d) Uncountable, by a diagonal argument. Given any list r1, r2, … of such numbers, build d whose n-th digit is 3 if the n-th digit of rn is 7, and 7 otherwise. Then d uses only 3s and 7s, and it differs from every rn in the n-th digit. Since no expansion involves 0s or 9s, each of these numbers has only one decimal expansion, so a different digit really means a different number.

(e) Countable. For each N, only finitely many polynomials have degree + Σ|coefficients| ≤ N. A countable union of finite sets is countable.

Tests: encoding into ℕ, complements inside an uncountable set, and a careful diagonal argument. Common mistake: “(b) is infinite, so it is uncountable”, or running a diagonal argument with digits 0 and 9 (0.0999… = 0.1000…).

C8BrutalDiagonal proof

Prove Cantor’s theorem: for any set A there is no surjection f: A → 𝒫(A). Then conclude that |A| < |𝒫(A)|.

Full solutiontap

Suppose f: A → 𝒫(A) is onto. Let D = {a ∈ A : a ∉ f(a)}. Then D ⊆ A, so D = f(d) for some d ∈ A.

  • If d ∈ D, then by the definition of D, d ∉ f(d) = D.
  • If d ∉ D = f(d), then d satisfies the defining condition, so d ∈ D.

Both cases give a contradiction, so no surjection exists. ∎

The map a ↦ {a} is an injection A → 𝒫(A), so |A| ≤ |𝒫(A)|. Equality would mean a bijection, which is in particular a surjection. So |A| < |𝒫(A)|. For example, 𝒫(ℕ) is uncountable.

Tests: the diagonal set D: “the elements that are not in their own image”. Common mistake: only handling finite A (2n > n). The proof has to work for every set.

C9BrutalDiagonal construction

Prove that the set of all bijections ℕ → ℕ is uncountable. (The naive diagonal g(n) = fn(n) + 1 doesn’t work. Why not?)

Full solutiontap

The naive g need not be a bijection: it can repeat values or miss them.

Suppose f0, f1, f2, … lists bijections of ℕ = {0, 1, 2, …}. Split ℕ into blocks {2n, 2n + 1}. On block n define:

  • if fn(2n) = 2n: g(2n) = 2n + 1 and g(2n + 1) = 2n (swap);
  • otherwise: g(2n) = 2n and g(2n + 1) = 2n + 1 (fix).

g maps each block bijectively onto itself, and the blocks partition ℕ, so g is a bijection. In the first case g(2n) = 2n + 1 ≠ 2n = fn(2n). In the second, g(2n) = 2n ≠ fn(2n). So g ≠ fn for every n, and g is not on the list. No list contains every bijection. ∎

Tests: adapting the diagonal argument so that the new object stays in the set. Common mistake: making g differ from each fn without checking that g is still a bijection.

E6HarderProof · well-ordering

Prove Bézout’s theorem: if a, b are integers, not both 0, then gcd(a, b) is the smallest positive integer of the form as + bt.

Full solutiontap

d | a. Divide: a = qd + r, 0 ≤ r < d. Then r = a − q(as0 + bt0) = a(1 − qs0) + b(−qt0) is also a combination of a and b. If r > 0, then r ∈ S and r < d, contradicting minimality. So r = 0. In the same way, d | b.

E8BrutalEuclid-style proof

Suppose the only such primes are p1, …, pk. Let N = 4p1p2⋯pk − 1. Then N > 1, N is odd, and N ≡ 3 (mod 4).

x ≡ 2·77·3 + 3·55·6 + 10·35·6 = 462 + 990 + 2100 = 3552 ≡ 87 (mod 385).

F2HarderNon-coprime moduli
  1. Solve x ≡ 5 (mod 12), x ≡ 11 (mod 18).
  2. Show that x ≡ 3 (mod 12), x ≡ 8 (mod 18) has no solution.
  3. State the general rule.
Full solutiontap

(a) Substitute x = 5 + 12k: 12k ≡ 6 (mod 18). Divide by 6: 2k ≡ 1 (mod 3), so k ≡ 2 (mod 3). That gives x = 5 + 12(2 + 3j) = 29 + 36j, i.e. x ≡ 29 (mod 36).

(b) The first congruence gives x ≡ 3 (mod 6), since 6 | 12. The second gives x ≡ 2 (mod 6), since 6 | 18. These contradict each other.

(c) x ≡ a (mod m), x ≡ b (mod n) is solvable iff a ≡ b (mod gcd(m, n)), and then the solution is unique mod lcm(m, n).

Tests: CRT when the moduli aren’t coprime. Common mistake: answering mod 12·18 = 216 instead of lcm = 36.

F3HarderCRT × counting

How many x in [0, 1000] satisfy x² ≡ 1 (mod 1001)? Find them all. (1001 = 7·11·13.)

Full solutiontap

By CRT, x² ≡ 1 (mod 1001) ⇔ x² ≡ 1 mod 7, mod 11 and mod 13. Modulo a prime p, p | (x − 1)(x + 1) forces x ≡ ±1. That is 2 choices for each prime, 2³ = 8 combinations, and CRT turns each combination into exactly one residue mod 1001.

Example, (+1, +1, −1): x = 1 + 77k ≡ −1 (mod 13). Since 77 ≡ −1 (mod 13), 1 − k ≡ −1, so k ≡ 2 and x = 155. Check: 155² = 24025 = 24·1001 + 1. ✓

x ∈ {1, 155, 274, 428, 573, 727, 846, 1000}

They come in pairs x ↔ 1001 − x, i.e. flipping all three signs.

Tests: CRT as a bijection between residues mod 1001 and triples of residues. Common mistake: answering 2 (only ±1). Modulo a composite number, a polynomial can have more roots than its degree.

F4HarderFermat · huge exponents
  1. Compute 310100 mod 13.
  2. 2027 is prime. Compute 22026 mod 2027 and 22028 mod 2027.
Full solutiontap

(a) Fermat: 312 ≡ 1 (mod 13), so reduce the exponent mod 12. Since 10² = 100 ≡ 4 (mod 12) and 4·10 = 40 ≡ 4, every 10k with k ≥ 2 is ≡ 4 (mod 12). So 310100 ≡ 3⁴ = 81 ≡ 3.

(b) Fermat gives 22026 ≡ 1 directly. Then 22028 ≡ 2² = 4.

F5HarderFermat × CRT proof

Prove that 2730 | n13 − n for every integer n. (2730 = 2·3·5·7·13.) Why can’t 11 be added to this list?

Full solutiontap

Fix p ∈ {2, 3, 5, 7, 13}. Note that p − 1 ∈ {1, 2, 4, 6, 12} always divides 12.

  • If p | n, then both n13 and n are ≡ 0.
  • Otherwise Fermat gives np−1 ≡ 1, so n12 = (np−1)12/(p−1) ≡ 1 and n13 ≡ n.

So each of these five distinct primes divides n13 − n, and so does their product 2730. ∎

For 11, p − 1 = 10 doesn’t divide 12. Concretely, 213 − 2 = 8190 = 2·3²·5·7·13, which is not a multiple of 11.

Tests: spotting “p − 1 | exponent − 1”. Common mistake: forgetting the case p | n, where Fermat’s hypothesis fails.

F6HarderPseudoprimes

Prove that a560 ≡ 1 (mod 561) for every a with gcd(a, 561) = 1, even though 561 = 3·11·17 is composite. What does this say about using Fermat’s theorem as a primality test?

Full solutiontap

gcd(a, 561) = 1 means a is coprime to 3, to 11 and to 17. Fermat gives a² ≡ 1 (mod 3), a10 ≡ 1 (mod 11), a16 ≡ 1 (mod 17). Since 560 = 2·280 = 10·56 = 16·35, raising to those powers gives a560 ≡ 1 modulo each of 3, 11, 17. Because they are pairwise coprime, a560 ≡ 1 (mod 561). ∎

So the converse of Fermat is false: a composite number can pass the test an−1 ≡ 1 for every coprime base. Such numbers are called Carmichael numbers.

Tests: applying Fermat prime by prime, then combining with CRT. Common mistake: applying Fermat with modulus 561 itself, which is not prime.

(b) 42² = 1764 ≡ 1764 − 4·391 = 200, and 200·42 = 8400 ≡ 8400 − 21·391 = 189. C = 189.

(c) Mod 17: 189 ≡ 2. Since 235 ≡ 11 (mod 16), 189235 ≡ 211 = 2048 ≡ 8. Mod 23: 189 ≡ 5. Since 235 ≡ 15 (mod 22), 515 = 5⁸·5⁴·5²·5 ≡ 16·4·2·5 = 640 ≡ 19. Now solve x ≡ 8 (mod 17), x ≡ 19 (mod 23): x = 19 + 23k ≡ 8 (mod 17), so 2 + 6k ≡ 8, 6k ≡ 6, k ≡ 1, and x = 42. ✓

F8BrutalRSA attack

An RSA modulus is n = 4189 = pq. Someone leaks (p − 1)(q − 1) = 4060. Recover p and q. With e = 3, find d.

Full solutiontap

F9BrutalProof

Prove that RSA decryption works for every message 0 ≤ M < n = pq, including M that share a factor with n: if ed ≡ 1 (mod (p − 1)(q − 1)), then Med ≡ M (mod n).

Mod p. If p | M, both Med and M are ≡ 0. Otherwise Fermat gives Mp−1 ≡ 1, so Med = M · (Mp−1)k(q−1) ≡ M. In both cases p | Med − M.

GInduction, strong induction, well-ordering

G1HardDivisibility

Prove 64 | 9n − 8n − 1 for all n ≥ 0.

Full solutiontap

Let an = 9n − 8n − 1. Basis: a0 = 0. Inductive step: assume 64 | an. Then

an+1 = 9·9n − 8n − 9 = 9(9n − 8n − 1) + 64n = 9an + 64n

Both terms are multiples of 64. ∎ (Alternative: 9n = (1 + 8)n = 1 + 8n + Σk≥2 C(n,k)8k.)

Tests: writing an+1 as (multiple of an) + (obvious multiple of 64). Common mistake: expanding an+1 − an = 8·9n − 8 and then being stuck on whether 64 | 8(9n − 1). (It does, but that needs its own argument.)

G2HardInequality

Prove 3n ≥ n³ for all integers n ≥ 0. (Watch which base cases you need.)

Full solutiontap

Bases n = 0, 1, 2, 3: 1 ≥ 0, 3 ≥ 1, 9 ≥ 8, 27 ≥ 27.

Step, for n ≥ 3: assume 3n ≥ n³. Then 3n+1 ≥ 3n³, and it suffices that 3n³ ≥ (n + 1)³, i.e. (1 + 1/n)³ ≤ 3. For n ≥ 3, (1 + 1/n)³ ≤ (4/3)³ = 64/27 < 3. ∎

The step fails at n = 2, since (3/2)³ = 3.375 > 3. So you cannot start the induction at 0 and go up one at a time: n = 0, 1, 2, 3 all need to be checked directly.

Tests: finding where the inductive step starts working and covering everything below it as base cases. Common mistake: using the step at n = 2 without noticing that it is false there.

G3HardStrong induction

Prove that every integer n ≥ 28 can be written as 5a + 8b with a, b ≥ 0. Show that 27 cannot.

Full solutiontap

Bases n = 28…32: 28 = 5·4 + 8·1, 29 = 5·1 + 8·3, 30 = 5·6, 31 = 5·3 + 8·2, 32 = 8·4.

Step: let n ≥ 33 and assume the claim for every k with 28 ≤ k < n. Then n − 5 ≥ 28, so n − 5 = 5a + 8b, and n = 5(a + 1) + 8b. ∎

27: 27 − 8b for b = 0, 1, 2, 3 gives 27, 19, 11, 3, none of which is divisible by 5.

Tests: strong induction with as many base cases as the step size (5). Common mistake: checking only 28 and stepping by 5, which leaves 29–32 uncovered.

G4HarderStrengthen the hypothesis

Prove Σk=1n 1/k² < 2 for all n ≥ 1. (Trying to prove “< 2” directly by induction fails. Why?)

Full solutiontap

Knowing that the sum is < 2 says nothing about whether adding 1/(n + 1)² keeps it below 2. The hypothesis is too weak. So prove the stronger statement P(n): Σk=1n 1/k² ≤ 2 − 1/n.

Basis: 1 ≤ 2 − 1. Step: assume P(n). Then Σk=1n+1 ≤ 2 − 1/n + 1/(n+1)². We need this to be ≤ 2 − 1/(n+1), i.e. 1/(n+1)² ≤ 1/n − 1/(n+1) = 1/(n(n+1)), i.e. n ≤ n + 1. ✓

So the sum is ≤ 2 − 1/n < 2. ∎

Tests: when the induction is stuck, prove something stronger. Common mistake: writing “sum < 2, and 1/(n+1)² is tiny, so the new sum is < 2”.

G5HarderFind the flaw

Each induction proof below “proves” something false. Find the exact step that fails.

  1. Claim: any n ≥ 2 lines in the plane, no two parallel, pass through one common point. Proof: Two non-parallel lines meet. Assume it for n lines, and take n + 1 lines. Lines 1…n meet at a point P, and lines 2…n+1 meet at a point Q. Lines 2…n pass through both P and Q, and two distinct lines meet in at most one point, so P = Q.
  2. Claim: 2n = 0 for every n ≥ 0. Proof (strong induction): 2·0 = 0. Assume 2j = 0 for all 0 ≤ j ≤ k. Write k + 1 = a + b with 0 ≤ a, b ≤ k. Then 2(k + 1) = 2a + 2b = 0 + 0.
  3. Claim: n² + n is odd for all n ≥ 1. Proof: If k² + k is odd, then (k + 1)² + (k + 1) = (k² + k) + 2(k + 1) is odd + even, which is odd.
Full solutiontap
  1. The step from n = 2 to n = 3 fails. The “middle” lines 2…n are then just line 2, a single line. One line contains both P and Q, so there is no second line to force P = Q. Every later step depends on this one, so the whole proof collapses.
  2. The step from k = 0 to k + 1 = 1 fails. You can’t write 1 = a + b with a, b ≤ 0. One of them would have to be 1, which is not ≤ k = 0.
  3. The step is fine, but there is no base case, and in fact 1² + 1 = 2 is even. (In fact n² + n = n(n + 1) is always even.)

Tests: checking that the step works for the smallest k it is applied to, and that the base case exists. Common mistake: saying vaguely “the induction hypothesis is used wrongly” without naming the k where it breaks.

G6HarderGeometric dissection

Prove that for every n ≥ 6, a square can be cut into exactly n smaller squares (they need not be the same size).

Full solutiontap

Bases.

  • 6: a 3×3 grid with one 2×2 block merged into a single square: 9 − 4 + 1 = 6.
  • 7: a 2×2 grid with one quarter split into 4: 4 − 1 + 4 = 7.
  • 8: a 4×4 grid with one 3×3 block merged: 16 − 9 + 1 = 8.

Step. If a square can be cut into k squares, split any one of them into 4 quarters. That gives k + 3 squares. For n ≥ 9, the claim for n − 3 ≥ 6 holds by strong induction, so it holds for n. ∎

Tests: strong induction with step size 3, which needs 3 base cases. Common mistake: proving only the step “k ⇒ k + 3” from one base case, which covers 6, 9, 12, … but not 7 or 8.

G7HarderStrong induction × Fibonacci

Let F1 = 1, F2 = 2 and Fk+1 = Fk + Fk−1 (so 1, 2, 3, 5, 8, 13, …). Prove that every positive integer is a sum of distinct terms of this sequence. Write 100 this way.

Full solutiontap

Strong induction on n. Basis: 1 = F1, 2 = F2, 3 = F3.

Step: let n ≥ 4 and assume the claim for all smaller positive integers. If n is itself a term, we are done. Otherwise pick k with Fk < n < Fk+1 (k ≥ 3). Let m = n − Fk. Then 0 < m < Fk+1 − Fk = Fk−1. By the hypothesis, m is a sum of distinct terms, each ≤ m < Fk−1 < Fk. So Fk is not among them, and n = Fk + (that sum) is a sum of distinct terms. ∎

100 = 89 + 11 = 89 + 8 + 3.

Tests: greedy choice plus strong induction, and proving distinctness. Common mistake: forgetting to show that Fk isn’t already used in the representation of m.

G8BrutalWell-ordering × graphs

A tournament is a directed graph in which every pair of distinct vertices has exactly one arrow between them. Prove that if a tournament has a directed cycle, it has a directed cycle of length 3.

Full solutiontap

The set of lengths of directed cycles is a nonempty set of positive integers. By well-ordering, pick a shortest cycle v1 → v2 → ⋯ → vk → v1. Here k ≥ 3, since there are no loops and no pair has arrows both ways. Suppose k ≥ 4. Look at the arrow between v1 and v3:

  • If v3 → v1, then v1 → v2 → v3 → v1 is a 3-cycle, shorter than k.
  • If v1 → v3, then v1 → v3 → v4 → ⋯ → vk → v1 is a cycle of length k − 1.

Either way we get a shorter cycle, contradicting minimality. So k = 3. ∎

Tests: the “shortest object” form of well-ordering. Common mistake: forgetting to explain why k ≥ 3 (tournaments have no loops and no 2-cycles), or not checking that the shortened sequence is still a genuine cycle. It is, because it uses a subset of the original distinct vertices.

G9BrutalConstruction by induction

Prove that for every n ≥ 1 there is an n-digit number, using only the digits 1 and 2, that is divisible by 2n. (The first ones are 2, 12, 112, 2112, 22112.)

Full solutiontap

Basis: n = 1, the number 2.

Step: suppose N has n digits, all 1 or 2, and N = 2nm. We put one more digit d ∈ {1, 2} in front: N′ = d·10n + N = 2n(d·5n + m). Then 2n+1 | N′ iff d·5n + m is even. Since 5n is odd:

  • if m is even, choose d = 2;
  • if m is odd, choose d = 1.

N′ has n + 1 digits, all 1 or 2, and is divisible by 2n+1. ∎

Tests: an induction that builds the object, and the hypothesis has to carry the factorization N = 2nm. Common mistake: appending the digit at the end. That changes divisibility by powers of 2 unpredictably; putting it in front keeps N’s factor.

HRecursive definitions & structural induction

Rosen 5.3–5.4 · recursively defined sets, strings, trees, structural induction, correctness of recursive algorithms

H1HardRecursive set

Define S ⊆ ℤ × ℤ by: (0, 0) ∈ S, and if (a, b) ∈ S then (a + 2, b + 3) ∈ S and (a + 3, b + 2) ∈ S.

  1. Prove that 5 | a + b for every (a, b) ∈ S.
  2. Is every pair of nonnegative integers with 5 | a + b in S?
  3. Describe S exactly, with proof.
Full solutiontap

(a) Structural induction. Basis: 0 + 0 = 0. Step: if 5 | a + b, then (a + 2) + (b + 3) = (a + b) + 5 and (a + 3) + (b + 2) = (a + b) + 5 are also multiples of 5.

(b) No. (5, 0) ∉ S. Every element has a, b ≥ 0, and an element with a + b = 5 is one step from (0, 0): (2, 3) or (3, 2).

(c) By induction in both directions, S consists exactly of the pairs (2i + 3j, 3i + 2j) with i, j ≥ 0 (use i steps of the first kind and j of the second). For such a pair, a + b = 5(i + j) and a − b = j − i. Conversely, given (a, b), set s = (a + b)/5 and d = a − b, and solve i + j = s, j − i = d: i = (s − d)/2, j = (s + d)/2. These are integers because 5s ≡ d (mod 2), so s ≡ d. They are ≥ 0 iff |d| ≤ s.

S = {(a, b) : 5 | a + b and 5|a − b| ≤ a + b}.

Tests: structural induction proves “every element has property P”, while the converse (every P-object is in S) needs a construction. Common mistake: assuming the invariant from (a) characterizes S.

H2HardStructural induction · strings

Balanced strings: λ ∈ P; if x ∈ P then (x) ∈ P; if x, y ∈ P then xy ∈ P. Prove that every w ∈ P has as many “(” as “)”, and that every prefix of w has at least as many “(” as “)”. List all strings in P of length 6.

Full solutiontap

Let β(u) = #( − #). Claim: β(w) = 0, and β(u) ≥ 0 for every prefix u of w.

Basis λ: its only prefix is λ, with β = 0.

(x): its prefixes are λ (β = 0), “(” followed by a prefix u of x (β = 1 + β(u) ≥ 1), and (x) itself (β = 1 + 0 − 1 = 0).

xy: a prefix is either a prefix of x (β ≥ 0 by hypothesis), or x followed by a prefix u of y, with β = β(x) + β(u) = 0 + β(u) ≥ 0. The total is β(x) + β(y) = 0.

Length 6: ((())), (()()), (())(), ()(()), ()()().

Tests: handling every constructor in the inductive step. Common mistake: proving only the equal-count statement. The prefix condition is the one that rules out “)(”.

H3HarderStructural induction + find the flaw

Recall λR = λ and (wa)R = a·wR for a symbol a.

  1. Prove (xy)R = yRxR by structural induction on y.
  2. Deduce (wR)R = w.
  3. “Claim: wR = w for every string w. Proof: λR = λ. If wR = w, then (wa)R = a·wR = aw = wa.” Find the error.
Full solutiontap

(a) Basis y = λ: (xλ)R = xR = λxR = λRxR. Step y = wa: (x(wa))R = ((xw)a)R = a(xw)R = a(wRxR) = (awR)xR = (wa)RxR. This uses the induction hypothesis and associativity of concatenation.

(b) Induction on w. λ is clear. Then ((wa)R)R = (a wR)R = (wR)R aR = w a, using (a) and aR = a.

(c) The step “aw = wa” is false: concatenation is not commutative. For example, with w = 0 and a = 1, (01)R = 10 ≠ 01.

Tests: inducting on the correct argument. For (a) it is y, because reversal is defined by peeling symbols off the right. Common mistake: inducting on x, which gets stuck immediately.

H4HarderWrite a recursive definition & prove it

Give a recursive definition of the set A of bit strings with no two consecutive 1s, and prove that your definition produces exactly A. How many such strings of length n are there?

Full solutiontap

Definition: λ ∈ A′ and 1 ∈ A′; if w ∈ A′ then w0 ∈ A′ and w01 ∈ A′.

A′ ⊆ A (structural induction). λ and 1 have no “11”. If w has no 11, appending 0 can’t create one. Appending 01 can’t either: the new 1 follows a 0, and the boundary character is 0.

A ⊆ A′ (strong induction on length). Let s ∈ A. If s = λ or s = 1, it is in A′. If s ends in 0, then s = w0 with w ∈ A shorter, so w ∈ A′ and s ∈ A′. If s ends in 1 and has length ≥ 2, its second-to-last symbol must be 0 (no 11), so s = w01 with w ∈ A shorter, and s ∈ A′.

Counting: an = an−1 + an−2 (ends in 0, or ends in 01), with a0 = 1, a1 = 2. So an = 1, 2, 3, 5, 8, 13, …, the Fibonacci number fn+2.

Tests: a correct recursive definition needs both inclusions. Common mistake: the rule “w ∈ A ⇒ w0, w1 ∈ A” (it produces 11), or forgetting the base string “1” (then 1 and 101 are missing).

H5HarderRecursive function

Define f(0) = 0 and f(n) = f(⌊n/2⌋) + (n mod 2) for n ≥ 1. Prove that f(n) is the number of 1s in the binary expansion of n, and that f(n) ≤ ⌊log2n⌋ + 1 for n ≥ 1.

Full solutiontap

Strong induction. f(0) = 0, and 0 has no 1s. For n ≥ 1, n = 2⌊n/2⌋ + (n mod 2), so the binary expansion of n is the expansion of ⌊n/2⌋ with the bit (n mod 2) appended. Then ones(n) = ones(⌊n/2⌋) + (n mod 2) = f(⌊n/2⌋) + (n mod 2) = f(n), using the hypothesis for ⌊n/2⌋ < n.

For the bound: n has exactly ⌊log2n⌋ + 1 bits (since 2k ≤ n < 2k+1 with k = ⌊log2n⌋), and f(n) counts some of them. Equality holds iff n = 2k+1 − 1.

Tests: strong induction for recursions that jump from n to n/2. Common mistake: using ordinary induction (n − 1 ⇒ n), whose hypothesis doesn’t mention ⌊n/2⌋.

H6HarderAlgorithm correctness + cost

The recursive algorithm power(a, n, m): if n = 0 return 1 mod m; if n is even, set t = power(a, n/2, m) and return t·t mod m; otherwise return a·power(a, n − 1, m) mod m.

  1. Prove it returns an mod m.
  2. Let M(n) be the number of multiplications. Prove M(n) ≤ 2⌊log2n⌋ + 1 for n ≥ 1.
Full solutiontap

(a) Strong induction on n. For n = 0 it returns 1 = a⁰ mod m. For even n > 0: by hypothesis t ≡ an/2, so t² ≡ an. For odd n: by hypothesis power(a, n − 1, m) ≡ an−1, and multiplying by a gives an. (Reducing mod m at every step is valid, since congruences can be multiplied.)

(b) M(0) = 0. For even n, M(n) = M(n/2) + 1. For odd n, M(n) = M(n − 1) + 1. Strong induction:

  • n = 1: M(1) = 1 ≤ 1.
  • n even ≥ 2: M(n) ≤ 2⌊log2(n/2)⌋ + 2 = 2⌊log2n⌋.
  • n odd ≥ 3: M(n) = M((n − 1)/2) + 2 ≤ 2⌊log2(n − 1)⌋ − 2 + 3 ≤ 2⌊log2n⌋ + 1.

Tests: correctness proofs for recursive algorithms are strong induction on the input size. Common mistake: in (b), treating odd n as one step. An odd input costs two multiplications before it halves.

H7HarderFull binary trees

Full binary trees: a single vertex is one, and so is a root joined to two full binary trees T1, T2. Let n(T) be the number of vertices, l(T) the number of leaves, and h(T) the height (0 for a single vertex, 1 + max(h1, h2) otherwise). Prove that (a) l(T) = (n(T) + 1)/2 and (b) n(T) ≤ 2h(T)+1 − 1. Is there a full binary tree with 2026 vertices?

Full solutiontap

Basis (single vertex): l = 1 = (1 + 1)/2, and n = 1 ≤ 2¹ − 1.

Step. n = 1 + n1 + n2, l = l1 + l2, h = 1 + max(h1, h2).

(a) l = (n1 + 1)/2 + (n2 + 1)/2 = (n1 + n2 + 2)/2 = (n + 1)/2.

(b) n ≤ 1 + (2h1+1 − 1) + (2h2+1 − 1) ≤ 2·2max+1 − 1 = 2h+1 − 1.

By (a), n = 2l − 1 is always odd. So no full binary tree has 2026 vertices.

Tests: structural induction on trees, with the right recursive formulas for n, l and h. Common mistake: inducting on height or on n with ordinary induction, then mishandling subtrees of different sizes.

H8BrutalRecursive gcd · correctness & speed

gcd(a, b) with a ≥ b ≥ 0: if b = 0 return a, else return gcd(b, a mod b).

  1. Prove gcd(a, b) = gcd(b, a mod b) for b > 0, and conclude that the algorithm is correct.
  2. Prove: if a ≥ b > 0, then a mod b < a/2.
  3. Deduce that the algorithm makes at most 2⌊log2b⌋ + 2 recursive calls when b ≥ 1.
Full solutiontap

(a) Write a = qb + r. Any common divisor of a and b divides r = a − qb. Any common divisor of b and r divides a = qb + r. So the two pairs have the same common divisors, hence the same gcd. Correctness then follows by strong induction on b: gcd(a, 0) = a, and for b > 0 the call on (b, r) with r < b returns gcd(b, r) = gcd(a, b).

(b) If b ≤ a/2, then a mod b < b ≤ a/2. If b > a/2, then q = 1 and a mod b = a − b < a/2.

(c) Two consecutive calls go (a, b) → (b, r1) → (r1, r2) with r2 = b mod r1 < b/2 by (b). So the second argument at least halves every two calls. After 2k calls it is < b/2k. Once k = ⌊log2b⌋ + 1, that is < 1, i.e. 0, and the recursion stops. So there are at most 2k calls.

Tests: proving a running-time bound from a halving lemma. Common mistake: claiming that the remainder halves at every step. It can go 100 → 99 → 1 (it’s every two steps).

H9BrutalRecursive function · induction in an unusual order

I5HarderPigeonhole
  1. Prove that among any 5 points with integer coordinates in the plane, some two have a midpoint with integer coordinates. Is 4 enough? How many points are needed in 3-space?

I6HarderExtremal pigeonhole

What is the smallest k such that every k-element subset of {1, …, 100} contains two numbers that differ by exactly 10? Prove both bounds.

Full solutiontap

Upper bound. A set with no such pair takes no two consecutive elements from any chain. A 10-element chain allows at most 5 (pair up its elements as 1st–2nd, 3rd–4th, …; at most one from each pair). So such a set has at most 50 elements, and any 51 numbers contain a pair.

Sharp. {1–10, 21–30, 41–50, 61–70, 81–90} has 50 elements and no two differ by 10.

I7HarderClever pigeonhole

Prove that if you choose n + 1 numbers from {1, 2, …, 2n}, one of them divides another. Show that n numbers are not enough.

Tests: finding the right “pigeonhole” (the odd part). Common mistake: using parity or residues mod n as boxes. Those don’t force divisibility.

I8BrutalPigeonhole on subsets

Prove that any set of 10 distinct two-digit numbers (10–99) has two disjoint nonempty subsets with the same sum.

Full solutiontap

E[X²] = Σi E[Ii²] + Σi≠j E[IiIj] = n·(1/n) + n(n − 1)·1/(n(n − 1)) = 2. Here Ii² = Ii, and both i and j are fixed with probability (n − 2)!/n!.

V(X) = 2 − 1² = 1.

The Ii are not independent (if n − 1 points are fixed, so is the last one), so the variance of the sum is not the sum of the variances. That would give n·(1/n)(1 − 1/n) = 1 − 1/n, which is wrong.

Tests: expanding E[X²] over pairs of indicators. Common mistake: applying Bienaymé to dependent indicators.

L8BrutalFirst-step analysis × recurrences

Full solutiontap

HH. Let E be the expected number of flips from the start, and EH the expected number still needed when the last flip was H. Then:

E = 1 + ½EH + ½E
EH = 1 + ½·0 + ½E

The first equation gives E = 2 + EH. Substituting into the second, EH = 1 + 1 + EH/2, so EH = 4 and E = 6.

HT. Wait for the first H (expected 2 flips). After that, extra H’s don’t lose anything, so wait for a T (expected 2 more). E = 4.

Tests: setting up linear equations by conditioning on the first flip. Common mistake: “every 2-flip pattern has probability 1/4, so the expected wait is 4 for both”.

(a) 1 comes first and 12 last. The middle elements {2, 3, 4, 6} need 2 before 4, 2 before 6, and 3 before 6. Listing them: 2346, 2364, 2436, 3246, 3264. 5.

(b) 1 first and 30 last. The middle six are the atoms 2, 3, 5 and the products 6, 10, 15, each of which must come after its two atoms. Fix the order in which the atoms appear, say a, b, c (3! = 6 ways). Then a and b come first, in that order: c can’t precede b, and no product can come before b. The remaining four, c, ab, ac, bc, can go in any order with c before ac and bc. That is 4!/3 = 8 orders. Total 6·8 = 48.

Tests: counting linear extensions by fixing a structural choice. Common mistake: in (b), assuming all atoms must come before all products. 6 can come before 5.

O8BrutalProof · paths and closures

Let R be a relation on a set A with |A| = n. Prove: (a) the transitive closure is R* = ∪k≥1 Rk; (b) in fact R* = R ∪ R² ∪ ⋯ ∪ Rn.

Full solutiontap

(a) (a, b) ∈ Rk iff there is a path of length k from a to b. We check that R* is the smallest transitive relation containing R.

  • R ⊆ R*.
  • R* is transitive: a path a → b followed by a path b → c is a path a → c.
  • If S is transitive and S ⊇ R, then Rk ⊆ S for every k, by induction: Rk+1 = Rk ∘ R ⊆ S ∘ S ⊆ S. So R* ⊆ S.

(b) Suppose there is a path from a to b of length m > n: a = x0, x1, …, xm = b. The m + 1 ≥ n + 2 vertex occurrences take only n values, so xi = xj for some i < j by pigeonhole. Delete the loop xi+1, …, xj. The result is still a path from a to b, of length m − (j − i) < m and still ≥ 1. Repeat until the length is ≤ n. So every pair in R* is already in some Rk with k ≤ n. ∎

Tests: combining pigeonhole with path shortening, and proving that a closure really is the smallest. Common mistake: in (a), showing that R* is transitive but not that it is smallest.

O9BrutalLattices
  1. Show that (𝒫(S), ⊆) is a lattice, identifying lub and glb.
  2. Show that (ℤ+, |) is a lattice.
  3. Prove that every finite nonempty lattice has a greatest element.
Full solutiontap

(a) A ∪ B contains both A and B, and any set that contains both contains A ∪ B, so lub = A ∪ B. In the same way, glb = A ∩ B.

(b) lub(a, b) = lcm(a, b): it is a common multiple, and every common multiple is a multiple of it (prime exponents: max). glb = gcd, similarly.

(c) Let the elements be x1, …, xn. Define u1 = x1 and uk+1 = lub(uk, xk+1). By induction, uk is an upper bound of x1, …, xk: uk+1 ≥ uk ≥ each earlier xi (transitivity), and uk+1 ≥ xk+1. So un is above every element, i.e. it is the greatest element. ∎ (This fails for infinite lattices: (ℤ+, |) has no greatest element.)

Tests: lub/glb definitions, and induction over a finite list. Common mistake: in (c), taking a maximal element and asserting it is greatest without using the lattice property.

P1HardDegree sequences

Does a simple graph exist with each degree sequence? Prove your answer each time.

  1. 5, 5, 4, 3, 3, 2
  2. 4, 4, 4, 1, 1
  3. 5, 4, 3, 2, 1, 1
  4. 3, 3, 3, 3, 3
  5. 6, 5, 5, 4, 3, 3, 2

Also: a 4-regular simple graph has 10 edges. How many vertices does it have?

Full solutiontap

Method (Havel–Hakimi): remove the largest degree d, subtract 1 from the next d degrees, and repeat. The sequence is graphical iff this reaches all zeros without a negative number or running short.

  1. Yes. 5,5,4,3,3,2 → 4,3,2,2,1 → 2,1,1,0 → 0,0,0.
  2. No. With 5 vertices, a degree-4 vertex is adjacent to everyone. Three of them make each degree-1 vertex adjacent to at least 3 vertices.
  3. No. The degree-5 vertex is adjacent to all others. Removing it leaves 3,2,1,0,0, and the 3 needs three neighbors with positive degree but only two exist.
  4. No. The degree sum 15 is odd (handshaking).
  5. Yes. → 4,4,3,2,2,1 → 3,2,1,1,1 → 1,0,0,1 → 0,0,0.

4-regular with 10 edges: 2·10 = 4n, so n = 5 (it is K5).

Tests: even degree sum is necessary but not sufficient. Common mistake: answering “yes” for (b) and (c) because their sums are even.

P3HarderIsomorphism
  1. K3,3 and the triangular prism (two triangles joined by three parallel edges) both have 6 vertices, 9 edges and every degree equal to 3. Are they isomorphic?
  2. Prove that the complement of C5 is isomorphic to C5 by giving an explicit isomorphism.
  3. How many simple graphs on 4 vertices are there up to isomorphism?
Full solutiontap

(a) No. The prism contains a triangle, a cycle of length 3. K3,3 is bipartite, so it has no odd cycles. Isomorphisms preserve cycles of each length.

(b) C5 has edges {i, i+1} (mod 5), and its complement has edges {i, i+2}. Let f(i) = 2i mod 5, which is a bijection since 2 is invertible mod 5. f sends the edge {i, i+1} to {2i, 2i+2}, a pair differing by 2, which is an edge of the complement. Both graphs have 5 edges and f is injective on edges, so it is an isomorphism.

(c) By number of edges: 0:1, 1:1, 2:2 (sharing a vertex, or disjoint), 3:3 (triangle, path P4, star K1,3), 4:2 (C4, triangle plus a pendant edge), 5:1, 6:1. The counts for 4–6 edges follow from 2–0 by taking complements. 11.

Tests: finding an invariant that tells graphs apart, or an explicit map that matches them. Common mistake: “same degree sequence, so isomorphic”. Part (a) refutes it.

P4HarderCounting walks
  1. In Km, let sk be the number of walks of length k from a vertex u back to u, and wk the number from u to a fixed v ≠ u. Find recurrences for them, and prove wk = ((m−1)k − (−1)k)/m and sk = ((m−1)k + (m−1)(−1)k)/m. Evaluate both for K4 with k = 5.
  2. In C6 (vertices 0–5), how many walks of length 6 go from 0 to 3? From 0 to 0?
Full solutiontap

(a) Classify walks by their second-to-last vertex. A walk ending at u comes from one of the m − 1 other vertices: sk+1 = (m − 1)wk. A walk ending at v comes from u or from one of the other m − 2 vertices: wk+1 = sk + (m − 2)wk. Bases: s0 = 1, w0 = 0, and the formulas give (1 + m − 1)/m = 1 and 0. ✓

Induction step: (m−1)wk = ((m−1)k+1 + (m−1)(−1)k+1)/m ✓, and sk + (m−2)wk = [(m−1)k(1 + m − 2) + (−1)k(m − 1 − m + 2)]/m = ((m−1)k+1 + (−1)k)/m ✓.

K4, k = 5: w = (243 + 1)/4 = 61 and s = (243 − 3)/4 = 60. These are the entries of A⁵.

(b) 0 → 3: 0. C6 is bipartite, so every step changes the parity of the vertex, and after 6 steps you are at an even vertex. 0 → 0: each step is ±1, and the total must be ≡ 0 (mod 6). That happens with three +1s and three −1s (C(6,3) = 20) or six steps in the same direction (2). 22.

Tests: (Aᵏ)uv counts walks, and you can find it by a recurrence instead of multiplying matrices. Common mistake: counting paths (no repeated vertices) instead of walks.

P5HarderAdjacency matrix proof

Prove that for a simple graph with adjacency matrix A, trace(A³) = 6 × (number of triangles). Use this to count the triangles in W5, given trace(A³) = 30, and in K4.

Full solutiontap

(A³)ii counts closed walks of length 3 starting at i: i → j → k → i. There are no loops, so j ≠ i and k ≠ j, k ≠ i. So {i, j, k} is a triangle. Each triangle through i gives exactly 2 such walks (the two directions). Summing over i, each triangle is counted for each of its 3 vertices, twice each: trace(A³) = 6T. ∎

W5: T = 30/6 = 5 (the hub with each rim edge). K4: trace(A³) = 4·6 = 24, so T = 4 = C(4,3).

Tests: reading matrix entries as walk counts and handling the overcount. Common mistake: dividing by 3 (forgetting direction) or by 2 (forgetting the starting vertex).

P6HarderConnectivity

Find the vertex connectivity κ and edge connectivity λ of W5, K2,5 and Q3, with justification. (Recall κ ≤ λ ≤ minimum degree.)

Full solutiontap

W5: κ = λ = 3. Removing the hub and two non-adjacent rim vertices disconnects it, so κ ≤ 3. Any 2 removals leave it connected: if the hub stays, it reaches everything; if the hub goes, removing one rim vertex leaves a path. So κ = 3, and κ ≤ λ ≤ δ = 3 gives λ = 3.

K2,5: κ = λ = 2. Removing the 2-vertex side disconnects it, and removing one vertex can’t. The minimum degree is 2, so λ ≤ 2, and λ ≥ κ = 2.

Q3: κ = λ = 3. Think of Q3 as a top 4-cycle and a bottom 4-cycle joined by 4 vertical edges. Remove any 2 vertices. If both are on top, the bottom cycle is intact and every remaining top vertex has its vertical edge down. If one is on each level, each level minus one vertex is a path, and at most 2 of the 4 vertical edges are destroyed, so at least one connects the two paths. Hence κ ≥ 3, and κ ≤ λ ≤ δ = 3.

Tests: an upper bound from an explicit cut plus a lower bound by case analysis. Common mistake: giving only the cut. To show κ ≥ 3 you have to argue that no smaller cut exists.

P7HarderProof · edges force connectivity

Prove that a simple graph with n vertices and more than C(n − 1, 2) edges is connected. Show that the bound is sharp.

Full solutiontap

Suppose G is disconnected. Then V splits into nonempty sets of sizes a and n − a (1 ≤ a ≤ n − 1) with no edges between them. So

|E| ≤ C(a,2) + C(n−a,2) = C(n,2) − a(n − a)

Also a(n − a) ≥ n − 1, because (a − 1)(n − a − 1) ≥ 0 expands to exactly this. So |E| ≤ C(n,2) − (n − 1) = C(n − 1, 2), a contradiction. ∎

Sharp: Kn−1 plus an isolated vertex has exactly C(n − 1, 2) edges and is disconnected.

Tests: the contrapositive plus an extremal bound. Common mistake: assuming the worst case is two equal halves. It is actually the most lopsided split, a = 1.

P8BrutalSelf-complementary graphs

A graph is self-complementary if it is isomorphic to its complement. Prove that a self-complementary graph on n vertices has n ≡ 0 or 1 (mod 4), and give examples for n = 4 and n = 5.

Full solutiontap

Isomorphic graphs have the same number of edges, and |E(G)| + |E(Ḡ)| = C(n, 2). So |E| = n(n − 1)/4, which means 4 | n(n − 1). One of n and n − 1 is odd, so 4 divides the other one: n ≡ 0 or 1 (mod 4). ∎

Examples: the path P4 (its complement is again a P4), and C5 (problem P3b). So no self-complementary graph has 6 or 7 vertices.

Tests: using a simple invariant (the edge count) together with divisibility. Common mistake: only proving n(n − 1)/2 is even. You need 4 | n(n − 1).

P9BrutalCharacterization proof

Prove that a graph is bipartite if and only if it has no cycle of odd length.

Full solutiontap

(⇒) Along any cycle, the colors alternate, because each edge joins the two parts. Returning to the starting color takes an even number of steps.

Lemma. Every closed walk of odd length contains an odd cycle. Strong induction on the length L. If the walk repeats no vertex except at the start and end, it is a cycle (L ≥ 3, since there are no loops and L is odd). Otherwise some vertex appears twice in the middle. Split the walk there into two shorter closed walks whose lengths add up to L. One of them has odd length, and it contains an odd cycle by the hypothesis.

(⇐) Assume no odd cycle. It is enough to 2-color each connected component. Fix a vertex v and color u by the parity of d(v, u). Suppose some edge xy had d(v,x) ≡ d(v,y) (mod 2). Then a shortest path v → x, the edge x → y, and a shortest path y → v form a closed walk of length d(v,x) + 1 + d(v,y), which is odd. By the lemma it contains an odd cycle, a contradiction. So every edge joins different colors. ∎

Tests: a BFS-distance 2-coloring, and getting from an odd closed walk to an odd cycle. Common mistake: claiming that the closed walk is itself a cycle. It can repeat vertices, which is why the lemma is needed.
