Part 1 · Closures (Rosen 9.4)

A relation is missing a property. What’s the least you can add to give it that property?

1What a closure is

Big idea

Take a relation R and a property P (reflexive, symmetric, transitive). The closure of R with respect to P is the smallest relation that contains R and has P. “Smallest” means: it is contained in every relation that contains R and has P.

closure of R = R plus exactly the pairs that are forcedEvery pair you add must be one that any relation with property P containing R would have to include anyway.

That is how you prove something is the closure: show (1) it contains R, (2) it has the property, (3) every pair you added was forced.

Trap

Not every property has closures. If R already contains (1, 1), no relation containing R is irreflexive, so there is no “irreflexive closure”. Same for antisymmetric: if (1, 2) and (2, 1) are both in R, adding pairs never removes the problem. Closures exist for properties you can fix by adding.

2Reflexive & symmetric closures

reflexive closure: R ∪ Δ,  Δ = {(a, a) : a ∈ A}
symmetric closure: R ∪ R−1,  R−1 = {(b, a) : (a, b) ∈ R}Δ is the “diagonal” (equality relation). R−1 is the inverse relation: every arrow reversed.

Why these are the smallest

  • A reflexive relation must contain every (a, a). So any reflexive relation containing R contains R ∪ Δ, and R ∪ Δ is reflexive.
  • A symmetric relation containing (a, b) must contain (b, a). So it contains R ∪ R−1, and that union is symmetric: reversing a pair of R gives a pair of R−1 and vice versa.
Example · the running R
  • Reflexive closure: add the 4 loops (1,1), (2,2), (3,3), (4,4). Total 8 pairs.
  • Symmetric closure: add the 4 reversed arrows (2,1), (3,2), (4,3), (2,4). Total 8 pairs.
On A = {a, b, c}, R = {(a, b), (b, b), (c, a)}. Find the reflexive and symmetric closures.tap

Reflexive: add (a, a) and (c, c) (b already has its loop): {(a,a), (a,b), (b,b), (c,a), (c,c)}.

Symmetric: add (b, a) and (a, c): {(a,b), (b,a), (b,b), (c,a), (a,c)}. The loop (b, b) is its own reverse.

3Paths & the connectivity relation R*

Transitivity is harder: adding a pair can create new two-step chains, which force more pairs. The clean way to think about it is with paths.

a path of length n from a to b: a = x0 → x1 → ⋯ → xn = b, each step a pair of RFrom the relations basics: a Rn b exactly when there’s a path of length n from a to b. A path that starts and ends at the same element is a circuit (cycle).
R* = R ∪ R2 ∪ R3 ∪ ⋯The connectivity relation: a R* b when there is a path of some positive length from a to b.
Example · running R

From 1 you can reach 2 (1 step), 3 (1→2→3), 4 (1→2→3→4). From 2 you reach 3, 4, and back to 2 (2→3→4→2). Same for 3 and 4. Nothing reaches 1.

So R* = {(1,2), (1,3), (1,4), (2,2), (2,3), (2,4), (3,2), (3,3), (3,4), (4,2), (4,3), (4,4)}: 12 pairs.

Lemma · you never need long paths

If |A| = n and there is a path from a to b, there is one of length at most n (at most n − 1 if a ≠ b).

Why: a path of length m visits m + 1 positions x0, …, xm. If m > n, some element repeats (pigeonhole), say xi = xj with i < j. Cut out the loop xi → ⋯ → xj; it’s still a path from a to b, and shorter. Repeat until no repeats are forced.

|A| = n  ⟹  R* = R ∪ R2 ∪ ⋯ ∪ Rn

4Transitive closure = R*

Theorem

The transitive closure of R is the connectivity relation R*.

Proof (three checks)

  1. Contains R: R = R1 ⊆ R*.
  2. Transitive: if a R* b and b R* c, glue a path a → ⋯ → b to a path b → ⋯ → c. That’s a path a → ⋯ → c, so a R* c.
  3. Smallest: let S be transitive with R ⊆ S. Take any path a = x0 → x1 → ⋯ → xn = b in R. Each step is in S. Transitivity of S gives x0 S x2, then x0 S x3, …, then a S b (induction on n). So R* ⊆ S. ∎

Recipe for a small relation

  1. For each element a, list everything reachable from a by following arrows (one or more steps).
  2. Put (a, b) in the closure for each reachable b. Include (a, a) only if a lies on a circuit.
Trap · one round is not enough

R ∪ R² is not the closure in general. For R = {(1,2), (2,3), (3,4)}, R ∪ R² = R ∪ {(1,3), (2,4)} still misses (1, 4), which needs 3 steps. Keep going until nothing new appears.

Trap · loops in the closure

(a, a) is in R* only when a path leaves a and comes back. In the running example, 2, 3, 4 get loops (they’re on the circuit 2→3→4→2), but 1 does not. The transitive closure is not automatically reflexive.

Trap · order of closures

Taking a symmetric closure can destroy transitivity. R = {(1,2), (3,2)} is transitive (no two-step chains). Its symmetric closure has 1→2→3 but not (1, 3). To get the smallest equivalence relation containing R, close in the order reflexive, symmetric, then transitive.

Find the transitive closure of R = {(1,2), (2,1), (3,3)} on {1, 2, 3}.tap

1→2→1 forces (1, 1); 2→1→2 forces (2, 2). Closure: {(1,1), (1,2), (2,1), (2,2), (3,3)}.

How many pairs are in the transitive closure of {(1,2), (2,3), (3,1), (3,4)} on {1, 2, 3, 4}?tap

1, 2, 3 lie on the circuit 1→2→3→1, so each reaches 1, 2, 3, and also 4 (via 3). That’s 3 × 4 = 12 pairs. 4 reaches nothing. 12.

5Computing it: matrices & Warshall

Write R as a 0–1 matrix MR: entry (i, j) is 1 when i R j. Then:

MR² = MR ⊙ MR  (Boolean product)
MR* = MR ∨ MR[2] ∨ ⋯ ∨ MR[n]Boolean product: like matrix multiplication, but with “or” for + and “and” for ×. Entry (i, j) of M ⊙ M is 1 when some k has i R k and k R j, a 2-step path. ∨ is entrywise “or”.

Warshall’s idea

Instead of all powers, build up the allowed middle stops one element at a time. Let Wk[i][j] = 1 when there’s a path from i to j whose interior stops all lie in {1, …, k}.

W0 = MR;  Wk[i][j] = Wk−1[i][j] ∨ (Wk−1[i][k] ∧ Wk−1[k][j])At step k: if i can reach k and k can reach j (using stops 1…k−1), then i can now reach j. Wn = MR*.

By hand: at step k, look at column k (who reaches k) and row k (where k goes). Add every pair (who, where).

Example · R = {(1,3), (2,1), (3,4)} on {1, 2, 3, 4}
  1. k = 1: into 1: {2}. Out of 1: {3}. Add (2, 3).
  2. k = 2: nothing goes into 2. No change.
  3. k = 3: into 3: {1, 2}. Out of 3: {4}. Add (1, 4), (2, 4).
  4. k = 4: nothing leaves 4. No change.
  5. Closure: {(1,3), (1,4), (2,1), (2,3), (2,4), (3,4)}. Check by paths: 2→1→3→4 reaches everything after 2. ✓
Trap

At step k, use the matrix as updated so far (Wk−1), including pairs added at earlier steps. The pair (2, 3) found at k = 1 is what lets k = 3 add (2, 4).

Cost: computing all n Boolean powers takes about n⁴ bit operations; Warshall takes about 2n³. For the exam, the path view is usually fastest on small examples.

Part 2 · Equivalence relations (Rosen 9.5)

Relations that behave like “is the same as, in some respect”.

6Definition

equivalence relation = reflexive + symmetric + transitiveWrite a ∼ b when a R b. Elements related by an equivalence relation are called equivalent.
Big idea

An equivalence relation says “a and b are the same in one particular respect” (same remainder, same length, same birthday). The three properties are exactly what “same” must obey: everything is the same as itself; sameness goes both ways; and things the same as a common thing are the same as each other.

The master example

For any function f : A → B, the relation a ∼ b ⟺ f(a) = f(b) is an equivalence relation, because = is. Almost every example is this one in disguise: pick f = “remainder mod m”, “length”, “floor”, … (In fact every equivalence relation is of this form: take f(a) = the class of a.)

How to prove a relation is an equivalence relation

  1. Reflexive: show a ∼ a for an arbitrary a.
  2. Symmetric: assume a ∼ b; derive b ∼ a.
  3. Transitive: assume a ∼ b and b ∼ c; derive a ∼ c.

Or, faster: rewrite the relation as f(a) = f(b) for some function f, and quote the master example.

How to show it is not

Give one concrete counterexample to one property.

7Classic examples

Congruence mod m on ℤ (m ≥ 2)

a ≡ b (mod m) means m | (a − b).

  1. Reflexive: a − a = 0 = 0·m.
  2. Symmetric: if a − b = km, then b − a = (−k)m.
  3. Transitive: if a − b = km and b − c = lm, then a − c = (k + l)m.

(Or: a ≡ b ⟺ a mod m = b mod m, the master example with f = remainder.)

Strings of the same length

On the set of all bit strings, s ∼ t when they have the same length. This is f(s) = f(t) with f = length, so it’s an equivalence relation. 0110 ∼ 1111, but 01 ≁ 010.

Same fractional part

On ℝ, x ∼ y when x − y ∈ ℤ. Equivalently x − ⌊x⌋ = y − ⌊y⌋: same fractional part. So 2.3 ∼ −0.7 ∼ 5.3.

Non-examples (find the failing property)
  • x ∼ y when |x − y| ≤ 1 on ℝ: reflexive and symmetric but not transitive (0 ∼ 1, 1 ∼ 2, 0 ≁ 2).
  • a | b on ℤ⁺: not symmetric (2 | 4, 4 ∤ 2).
  • “shares a letter” on English words: not transitive (“cat” ∼ “to” ∼ “so”, but “cat” and “so” share nothing).
  • The empty relation on a nonempty set: symmetric and transitive (vacuously), but not reflexive.
Trap · the “proof” that symmetric + transitive ⇒ reflexive

“a ∼ b and b ∼ a give a ∼ a by transitivity.” This only works if a is related to something. An element with no partners breaks it, which is why the empty relation is a counterexample.

On ℤ, define a ∼ b when a² ≡ b² (mod 5). Equivalence relation? What are the classes?tap

Yes: it’s f(a) = f(b) with f(a) = a² mod 5. Squares mod 5: 0² = 0, 1² = 4² = 1, 2² = 3² = 4. So three classes: {a : a ≡ 0}, {a : a ≡ ±1}, {a : a ≡ ±2} (mod 5).

8Equivalence classes

[a] = {x ∈ A : x ∼ a}The equivalence class of a: everything equivalent to a. Any element b of [a] is a representative of the class.
Examples
  • Mod 4 on ℤ: [0] = {…, −4, 0, 4, 8, …}, [1] = {…, −3, 1, 5, …}, [2], [3]. Exactly 4 classes, called congruence classes mod 4. [7] = [3] = [−1].
  • Same length on bit strings: [0110] = all 16 strings of length 4. One class per length 0, 1, 2, …
  • x − y ∈ ℤ on ℝ: [0.25] = {…, −0.75, 0.25, 1.25, …}. Each class has exactly one representative in [0, 1).
Theorem · three equivalent statements

For an equivalence relation R and any a, b:  (i) a R b  ⟺  (ii) [a] = [b]  ⟺  (iii) [a] ∩ [b] ≠ ∅.

Proof

  1. (i) ⇒ (ii): suppose a R b. If x ∈ [a], then x R a; with a R b, transitivity gives x R b, so x ∈ [b]. So [a] ⊆ [b]. By symmetry b R a, and the same argument gives [b] ⊆ [a].
  2. (ii) ⇒ (iii): a ∈ [a] by reflexivity, so [a] = [b] contains a and is nonempty.
  3. (iii) ⇒ (i): pick c in both. Then c R a and c R b. Symmetry: a R c. Transitivity with c R b: a R b. ∎

So two classes are either identical or disjoint. Nothing in between.

9The classes partition the set

a partition of A: nonempty subsets Ai, pairwise disjoint, whose union is AThe Ai are the blocks (or parts). Every element of A lies in exactly one block.
Theorem

The distinct equivalence classes of an equivalence relation on A form a partition of A.

Proof

  1. Nonempty, and they cover A: each a lies in its own class [a] (reflexivity). So no class is empty and the union of all classes is A.
  2. Disjoint: if two classes [a], [b] share an element, the theorem in section 8 says [a] = [b]. So distinct classes are disjoint. ∎
Trap

The classes [a] for different a are not all different: [0] = [3] = [6] above. A partition lists each block once. When asked “list the classes”, don’t repeat.

10Partitions give equivalence relations

Theorem (converse)

Given a partition {Ai} of A, define a ∼ b when a and b lie in the same block. This is an equivalence relation, and its classes are exactly the blocks.

Proof

  1. Reflexive: a is in some block (the blocks cover A), and it’s in the same block as itself.
  2. Symmetric: “same block” doesn’t care about order.
  3. Transitive: if a, b share block Ai and b, c share block Aj, then b ∈ Ai ∩ Aj. Blocks are disjoint, so Ai = Aj, and a, c share it. ∎
equivalence relations on A  ⟷  partitions of AA one-to-one correspondence: relation → its set of classes; partition → “same block”. Doing one then the other returns where you started.
Example · reading a partition as pairs

Partition {1, 2, 3}, {4, 5}, {6} of {1, …, 6}. The relation contains every ordered pair inside each block: 3² + 2² + 1² = 9 + 4 + 1 = 14 pairs.

#pairs in an equivalence relation = Σ (block size)²
An equivalence relation on a 7-element set has classes of sizes 4, 2, 1. How many ordered pairs does it contain?tap

16 + 4 + 1 = 21.

11Counting equivalence relations

By section 10, counting equivalence relations on an n-set is the same as counting partitions of an n-set. These counts are the Bell numbers Bn.

n123456
Bn1251552203
Example · B4 = 15 by block sizes
  1. One block {1234}: 1.
  2. Sizes 3 + 1: choose the singleton: 4.
  3. Sizes 2 + 2: pair 1 with one of the other 3; the rest is forced: 3.
  4. Sizes 2 + 1 + 1: choose the pair: C(4, 2) = 6.
  5. All singletons: 1. Total 1 + 4 + 3 + 6 + 1 = 15.

Two useful counts

  • Exactly 2 classes: 2n−1 − 1. Element 1’s block is set; each of the other n − 1 elements either joins it or not (2n−1), minus the one case where everyone joins (only 1 class).
  • Equal blocks: to split 6 elements into three pairs, line them up (6!), divide by orderings inside each pair (2!³) and by the order of the pairs (3!): 720/(8·6) = 15.
Trap · blocks are unlabeled

When blocks have the same size, divide by the number of ways to order them. {1,2},{3,4} and {3,4},{1,2} are the same partition.

How many equivalence relations on {1, 2, 3, 4, 5} have exactly 2 classes?tap

24 − 1 = 15. (Check by block sizes: 4 + 1 gives 5; 3 + 2 gives C(5, 2) = 10. Total 15.)

How many equivalence relations on {1, 2, 3, 4} have 1 ∼ 2?tap

Glue 1 and 2 into a single object. Partitions of the 3 objects {12, 3, 4}: B3 = 5.

Part 3 · Partial orders (Rosen 9.6)

Relations that behave like “comes before” or “is at most”.

12Posets

partial order = reflexive + antisymmetric + transitiveA set S with a partial order R is a partially ordered set, or poset, written (S, R). We often write a ≼ b for a R b, and a ≺ b for “a ≼ b and a ≠ b”.
Big idea

An equivalence relation glues things together; a partial order ranks them. Antisymmetry says two different elements can’t each be below the other: no ties between distinct things.

Standard posets
  • (ℤ, ≤): reflexive (a ≤ a), antisymmetric (a ≤ b ≤ a ⇒ a = b), transitive.
  • (ℤ⁺, |): a | a; if a | b and b | a with both positive then a = b; a | b, b | c ⇒ a | c.
  • (P(S), ⊆): A ⊆ A; A ⊆ B ⊆ A ⇒ A = B; ⊆ is transitive.
Non-examples
  • (ℤ, <): not reflexive. (It’s a strict order.)
  • (ℤ, |) on all integers: not antisymmetric (3 | −3 and −3 | 3).
  • “is at least as tall as” on people: not antisymmetric (two different people of the same height).
On ℤ⁺ × ℤ⁺, define (a, b) ≼ (c, d) when a ≤ c and b ≤ d. Partial order?tap

Yes. Reflexive: a ≤ a, b ≤ b. Antisymmetric: a ≤ c ≤ a and b ≤ d ≤ b force (a, b) = (c, d). Transitive: coordinatewise. (It’s called the product order. Note (1, 2) and (2, 1) are incomparable.)

13Comparability & total orders

a, b comparable: a ≼ b or b ≼ a“Partial” means some pairs may be incomparable: in (ℤ⁺, |), neither 2 | 3 nor 3 | 2.
total (linear) order: every two elements are comparableA totally ordered set is also called a chain.
  • (ℤ, ≤) is total. (ℤ⁺, |) is not. ({1, 2, 4, 8, 16}, |) is total: each divides the next.
  • (P(S), ⊆) is total only if |S| ≤ 1: {a} and {b} are incomparable.
  • Well-ordered: a total order where every nonempty subset has a least element. (ℕ, ≤) is; (ℤ, ≤) isn’t (ℤ has no least element). This is what makes induction work.

14Lexicographic order

(a1, a2) ≺ (b1, b2) ⟺ a1 ≺ b1, or (a1 = b1 and a2 ≺ b2)Dictionary order: compare first coordinates; only on a tie, compare second coordinates. Then ≼ means ≺ or =. Extends to n-tuples: the first coordinate where they differ decides.
Examples in ℤ × ℤ with ≤
  • (2, 5) ≺ (3, 1): first coordinates decide, 2 < 3. The 5 vs 1 is never looked at.
  • (4, −1) ≺ (4, 0): tie in the first coordinate, then −1 < 0.
Strings

Compare letter by letter; the first difference decides. If one string runs out first (it’s a prefix of the other), the shorter one comes first. So ab ≺ abc ≺ b, and “disc” ≺ “discreet” ≺ “discrete”.

Trap

Lexicographic is not “compare coordinatewise” (that’s the product order). Under lex, every two pairs are comparable when the coordinate orders are total; under the product order (2, 5) and (3, 1) are incomparable.

15Hasse diagrams

Big idea

The arrow diagram of a partial order is cluttered: loops everywhere, plus every arrow implied by transitivity. A Hasse diagram keeps only the essential arrows and lets “up the page” mean “bigger”.

Recipe

  1. Drop all loops (reflexivity is understood).
  2. Drop every arrow implied by transitivity: keep a → b only if b covers a: a ≺ b with nothing strictly between them.
  3. Place each element above the ones it covers, and drop the arrowheads.

To read it back: a ≼ b exactly when you can climb from a to b along edges, always going up.

Example · reading the divisors-of-12 diagram
  • 2 | 12: climb 2 → 4 → 12 (or 2 → 6 → 12). ✓
  • 4 and 6: no upward route between them, so incomparable (4 ∤ 6, 6 ∤ 4).
  • There’s no edge 1–4 because 2 sits between them (1 | 2 | 4). There’s no edge 2–12 because 4 and 6 sit between.
Trap

Drawing an edge for every relation (like 1–12) is the most common error. Only covers: ask “is there anything strictly between?”

Which pairs form the edges of the Hasse diagram of ({1, 2, 3, 6, 9, 18}, |)?tap

1–2, 1–3, 2–6, 3–6, 3–9, 6–18, 9–18. (Seven edges. 2 and 9 are incomparable; 2 is below 18 only through 6.)

16Maximal, minimal, greatest, least

WordMeaningIn the diagram
maximal anothing is strictly above ano edge goes up from a
minimal anothing is strictly below ano edge goes down from a
greatest ab ≼ a for every beverything climbs to a
least aa ≼ b for every ba climbs to everything
The difference

“Maximal” says nothing beats a. “Greatest” says a beats everything. With incomparable elements around, those are very different: a maximal element can simply be incomparable to the rest.

Example · S above
  • Minimal: 2 and 3 (nothing in S divides them except themselves).
  • Maximal: 12 and 18.
  • No greatest: 12 and 18 are incomparable, so neither is above everything. No least for the same reason with 2 and 3.

Divisors of 12, by contrast: 1 is least (and the only minimal); 12 is greatest (and the only maximal).

Facts (with reasons)
  • Greatest is unique if it exists: if a and a′ are both greatest, a ≼ a′ and a′ ≼ a, so a = a′ by antisymmetry.
  • Greatest ⇒ the only maximal: anything else is below it, so not maximal.
  • Every finite nonempty poset has a minimal element: start anywhere, step down while you can; you can’t step down forever in a finite set without repeating, and a repeat would contradict antisymmetry.
  • Infinite posets can have none: (ℤ, ≤) has no maximal or minimal element. (ℤ⁺, |) has least element 1 but no maximal element.
Trap

“Only one maximal element” does not guarantee a greatest element in infinite posets. In finite posets it does (every element climbs to some maximal one).

17Bounds, lub, glb

u is an upper bound of a subset A if a ≼ u for all a ∈ A
l is a lower bound of A if l ≼ a for all a ∈ ABounds come from the whole poset S and need not be in A.
lub(A) = least upper bound: an upper bound below every other upper bound
glb(A) = greatest lower boundAlso called supremum and infimum. Each is unique if it exists.

Recipe

  1. List all upper bounds (everything that every element of A climbs to).
  2. If that list has a least element, that’s the lub. If the list is empty, or has no least element, there’s no lub.
Example · S = {2, 3, 4, 6, 9, 12, 18} under |
  1. A = {2, 3}: upper bounds 6, 12, 18; least of these is 6. lub = 6. Lower bounds: none (nothing in S divides both 2 and 3; 1 ∉ S). No glb.
  2. A = {12, 18}: upper bounds none, no lub. Lower bounds 2, 3, 6; greatest is 6. glb = 6.
  3. A = {4, 9}: no upper bound (36 ∉ S), no lower bound.
  4. A = {4, 6}: upper bound 12 only, lub = 12; lower bound 2, glb = 2.
In (ℤ⁺, |)

lub{a, b} = lcm(a, b) and glb{a, b} = gcd(a, b). In (P(S), ⊆), lub{A, B} = A ∪ B and glb{A, B} = A ∩ B.

Trap

Having upper bounds isn’t enough: the upper bounds must have a least one. If the upper bounds were, say, two incomparable elements, there’d be no lub.

In the same S, find the lub and glb of {6, 9}, and of {2, 9}.tap

{6, 9}: upper bounds {18}, lub 18; lower bounds {3}, glb 3. {2, 9}: upper bounds {18}, lub 18; no lower bounds, so no glb.

18Lattices (briefly)

lattice: a poset in which every pair of elements has both a lub and a glb
  • (ℤ⁺, |): lattice (lcm and gcd). Divisors of any n under |: lattice (lcm and gcd of divisors of n are divisors of n).
  • (P(S), ⊆): lattice (∪ and ∩).
  • Every total order: lattice (lub = the larger, glb = the smaller).
  • S = {2, 3, 4, 6, 9, 12, 18} under |: not a lattice, since {12, 18} has no lub.
  • ({1, 2, 3, 4, 5}, |): not a lattice, since {2, 3} has no upper bound.
Trap

To show “not a lattice”, exhibit one pair missing a lub or a glb, and say why (list its upper bounds).

19Topological sorting

Big idea

You have tasks with prerequisites (a partial order). You must do them one at a time. A topological sort lists all elements in a total order that respects the partial order: if a ≺ b, then a comes before b. (Also called a compatible total order, or linear extension.)

Algorithm

  1. Pick any minimal element (one with nothing still below it). One exists: section 16.
  2. Write it down and delete it. What’s left is still a poset.
  3. Repeat until empty.

Why it respects the order: when b is picked it’s minimal among what’s left, so anything below b was already picked.

Example · six tasks

Prerequisites: A and B before C; B before D; C and D before E; E before F.

  1. Minimal at the start: A, B. Pick B.
  2. Now minimal: A, D. Pick A. Then C, D are minimal; pick C, then D.
  3. Then E, then F. Order: B, A, C, D, E, F.
  4. Different choices give other valid orders; this poset has exactly 5 (ABCDEF, ABDCEF, BACDEF, BADCEF, BDACEF).
Example · divisors of 12

1 must be first and 12 last. In between, 2 before 4 and 6, and 3 before 6. One valid order: 1, 3, 2, 6, 4, 12. There are 5 in total.

Trap

A topological sort must include every element, and for incomparable elements either order is fine. Don’t try to “compare” 4 and 6; just respect the edges.

Give a topological sort of S = {2, 3, 4, 6, 9, 12, 18} under |.tap

One answer: 2, 3, 4, 6, 9, 12, 18 (increasing numbers always works for |, since a | b with a ≠ b means a < b). Many others are valid, e.g. 3, 9, 2, 6, 18, 4, 12.

In a simple graph, an edge is just an unordered pair {u, v} with u ≠ v. That’s a symmetric, irreflexive relation on V. A directed graph (digraph) has edges (u, v) with a direction: exactly a relation on V.

  • u and v are adjacent (neighbors) if an edge joins them; that edge is incident with u and v.
  • The neighborhood N(v) is the set of neighbors of v.
  • In a digraph, edge (u, v) has initial vertex u and terminal vertex v.
Trap

On the final, “graph” usually means simple graph unless loops or multiple edges are mentioned. Read the problem for which kind it means.

Each of the C(4, 2) = 6 possible edges is in or out: 26 = 64. In general 2C(n,2). (Up to isomorphism there are only 11; see section 27.)

21Degree & the handshaking theorem

deg(v) = number of edges incident with v, a loop counting twicedeg 0: isolated vertex. deg 1: pendant vertex.
Handshaking theorem:  Σv ∈ V deg(v) = 2|E|

Proof

Count “edge-ends”. Every edge has two ends, so there are 2|E| ends in total. Each end sits at a vertex, and deg(v) is exactly the number of ends at v (a loop puts both of its ends at the same vertex, which is why it counts twice). Summing deg(v) over all vertices counts every end once. ∎

Corollary · odd-degree vertices come in pairs

Every graph has an even number of vertices of odd degree.

Proof: split the sum: Σ deg = (sum over even-degree vertices) + (sum over odd-degree vertices). The total is 2|E|, even, and the first part is even, so the second part is even. A sum of odd numbers is even only if there’s an even number of them. ∎

Examples
  • Degrees 3, 3, 2, 2, 2: sum 12, so |E| = 6.
  • A graph where 9 vertices all have degree 4: |E| = 36/2 = 18.
  • Can 11 people each shake hands with exactly 3 others? Degree sum 33 is odd. Impossible.
Trap · even sum isn’t enough

Is there a simple graph with degrees 5, 5, 4, 3, 2, 1? The sum (20) is even, but no: with 6 vertices, degree 5 means adjacent to all others. Two such vertices make every vertex’s degree at least 2, but one vertex has degree 1. Always also check simple-graph limits (degree ≤ n − 1).

A simple graph has 10 vertices: 4 have degree 4, the rest have degree d, and there are 17 edges. Find d.tap

2·17 = 34 = 4·4 + 6d, so 6d = 18, d = 3.

Is there a simple graph with degrees 3, 3, 3, 1?tap

Sum 10 is even, but no. On 4 vertices, degree 3 means adjacent to all three others. Three such vertices would each be adjacent to the fourth, giving it degree 3, not 1.

24Bipartite graphs

G is bipartite if V = V1 ∪ V2 (disjoint) with every edge joining V1 to V2No edge inside V1, none inside V2. Equivalently: you can color the vertices with 2 colors so every edge joins different colors (a proper 2-coloring).
Theorem · the odd-cycle test

A graph is bipartite if and only if it has no cycle of odd length.

Why

  1. Bipartite ⇒ no odd cycle: walking around a cycle, the colors alternate with every step. To return to the starting color you need an even number of steps.
  2. No odd cycle ⇒ bipartite (for each connected piece): pick a vertex v. Color a vertex red if its distance from v is even, blue if odd. Suppose some edge xy joined two same-colored vertices. Then shortest route v→x, edge xy, and shortest route y→v back form a closed walk of odd length (even + 1 + even, or odd + 1 + odd). An odd closed walk always contains an odd cycle, a contradiction.

Recipe: 2-color greedily

  1. Color any vertex red. Color all its neighbors blue, all their uncolored neighbors red, and so on.
  2. If you ever need to give a vertex the color it already conflicts with, you’ve found an odd cycle: not bipartite. If everything gets colored, the colors are the two sides.
Which special graphs are bipartite?
  • Cn: bipartite exactly when n is even.
  • Kn: only for n ≤ 2 (K3 is a triangle).
  • Wn: never (hub + two adjacent rim vertices form a triangle).
  • Qn: always. Sides: strings with an even number of 1s vs. odd. Flipping one bit changes the parity.
  • Km,n: always, by definition.
Trap

Adding a diagonal to C6 between opposite vertices keeps it bipartite (it closes two 4-cycles). A diagonal between vertices two apart creates a triangle and breaks it. Check parity, not looks.

Matchings (brief)

A matching is a set of edges with no shared endpoints. In a bipartite graph with sides V1, V2, a complete matching from V1 matches every vertex of V1. Hall’s theorem: one exists if and only if |N(A)| ≥ |A| for every subset A ⊆ V1. The “only if” is easy: the matched partners of A are |A| different neighbors of A.

Is the 6-cycle with one extra edge between two vertices at distance 2 bipartite?tap

No: that edge and the two cycle edges between its endpoints form a triangle, an odd cycle.

What is the largest number of edges in a bipartite simple graph on 10 vertices?tap

With sides of size m and 10 − m, at most m(10 − m) edges, maximized at m = 5: 25 (K5,5).

25Subgraphs, unions, complements

  • Subgraph H = (W, F) of G = (V, E): W ⊆ V and F ⊆ E (each edge of F with both endpoints in W). Proper if H ≠ G.
  • Induced subgraph on W: keep the vertices W and every edge of G between them.
  • Removing an edge e: G − e keeps all vertices. Removing a vertex v: G − v also deletes every edge at v.
  • Union G1 ∪ G2: vertex set V1 ∪ V2, edge set E1 ∪ E2.
  • Complement Ḡ of a simple graph: same vertices, and uv is an edge exactly when it is not an edge of G. So |E(G)| + |E(Ḡ)| = C(n, 2).
Example

W5 − hub = C5. K4 − (one edge) has 5 edges. The complement of C6 has 15 − 6 = 9 edges.

Trap

“Subgraph” doesn’t require keeping all edges between the chosen vertices; “induced subgraph” does. C4 is a subgraph of K4, but not an induced one.

27Isomorphism

G1 ≅ G2 if there is a bijection f : V1 → V2 with
u, v adjacent in G1 ⟺ f(u), f(v) adjacent in G2f is an isomorphism: a renaming of the vertices that turns one edge set exactly into the other. Same graph, different labels or drawing.
Big idea

Drawings lie. Two pictures that look nothing alike can be the same graph, and two that look similar can differ. Decide using the definition and invariants, not the picture.

The pentagram is just a 5-cycle traced in a different order (every other point), so it’s isomorphic to the pentagon: both are C5.

Recipe: proving two graphs ARE isomorphic

  1. Check the easy invariants match (vertex count, edge count, degree sequence). If not, stop: not isomorphic.
  2. Match up vertices with special features first: unique degrees, the neighbors of those, vertices on triangles…
  3. Write the bijection f explicitly.
  4. Verify every edge: each edge uv of G1 maps to an edge f(u)f(v) of G2. Same number of edges ⇒ that’s enough.
Example

G1: vertices a, b, c, d, e; edges ab, bc, cd, da, ae (a square with a pendant at a).
G2: vertices 1–5; edges 13, 35, 52, 21, 42.

  1. Degrees in G1: a 3, b 2, c 2, d 2, e 1. In G2: 2 has degree 3 (neighbors 5, 1, 4), 1, 3, 5 have degree 2, 4 has degree 1. Same sequence.
  2. Forced: a ↦ 2 (only degree 3) and e ↦ 4 (only degree 1). a’s other neighbors b, d must go to 2’s other neighbors 1, 5; c (opposite a on the square) goes to 3.
  3. Try f: a↦2, b↦1, c↦3, d↦5, e↦4.
  4. Check: ab→21 ✓, bc→13 ✓, cd→35 ✓, da→52 ✓, ae→24 ✓. All 5 edges land on edges, so G1 ≅ G2.
Trap

Matching degree sequences does not prove isomorphism. You must give the bijection and check edges (or find an invariant that differs, next section).

3 vertices: 4 (0, 1, 2, or 3 edges: with 3 vertices each edge count gives one shape). 4 vertices: 11. Compare with 23 = 8 and 26 = 64 labeled graphs.

29Paths, circuits, components

path of length n from u to v: a sequence of n edges e1, …, en leading u = x0 – x1 – ⋯ – xn = vCircuit: a path of length ≥ 1 that ends where it starts. Simple: no edge repeated. (Rosen’s “path” may repeat vertices and edges; some books call that a walk.)
  • An undirected graph is connected if every two vertices have a path between them.
  • Theorem: in a connected graph, any two distinct vertices have a simple path between them. (Take a shortest path; if it repeated a vertex, you could cut out the loop and get a shorter one.)
  • A connected component is a maximal connected subgraph: a piece you can’t enlarge and stay connected. Every graph is the disjoint union of its components.
Components are equivalence classes

“u = v or there is a path from u to v” is an equivalence relation on V (reflexive by fiat; reverse a path for symmetry; glue paths for transitivity). Its classes are the vertex sets of the components. This is Part 2 applied to graphs.

Trap

A single vertex with no edges is a component by itself. Count isolated vertices when asked for the number of components.

30Cut vertices & cut edges

cut vertex: removing it (and its edges) increases the number of components
cut edge (bridge): removing it increases the number of components
Example · reading the picture
  • Remove 3: {1, 2} is cut off from {4, 5, 6}. Cut vertex. Same for 4.
  • Remove 1: the rest stays connected (2–3 still there). Not a cut vertex.
  • Remove edge 3–4: two triangles, disconnected. Cut edge. Removing a triangle edge, say 1–2, leaves 1–3–2, still connected.
Key fact

An edge is a cut edge exactly when it lies on no circuit (no simple cycle). If it’s on a cycle, the rest of the cycle is a detour around it.

Connectivity numbers: κ(G), the vertex connectivity, is the fewest vertices whose removal disconnects G (or leaves one vertex); λ(G), the edge connectivity, is the fewest edges whose removal disconnects G. κ(Kn) = λ(Kn) = n − 1. In general κ(G) ≤ λ(G) ≤ min degree.

Trap

The endpoint of a cut edge is not always a cut vertex: in a path a–b, removing a leaves just b, still connected. A pendant vertex is never a cut vertex.

Find all cut vertices and cut edges of the star K1,4 (one center joined to 4 leaves).tap

Cut vertex: the center only. Cut edges: all 4 edges (no edge lies on a cycle).

31Strong & weak connectivity

strongly connected: a directed path u → v and v → u for every u, v
weakly connected: the underlying undirected graph is connected

Strongly ⇒ weakly, but not conversely. The strongly connected components are the maximal strongly connected subgraphs; they partition the vertices (mutual reachability is an equivalence relation).

Example

1, 2, 3 reach each other around the cycle. 4 is reachable from 3 but nothing leaves 4, so 4 can’t get back. Strong components: {1, 2, 3} and {4}. The graph is weakly connected (ignoring directions everything is joined).

Digraph on {1, …, 5} with edges 1→2, 2→3, 3→4, 4→2, 5→4, 5→1. Strong components? Weakly connected?tap

2→3→4→2 is a cycle: {2, 3, 4}. Nothing returns to 1 or to 5. Components: {1}, {2, 3, 4}, {5}. Weakly connected: yes.
