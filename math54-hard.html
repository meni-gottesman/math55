1.8Brutalconceptual

A is 4×4. Ax = e₁, Ax = e₂, Ax = e₃ are each consistent, but Ax = e₄ is not.

(a) What is Col A? (b) How many solutions does Ax = 0 have? (c) How many solutions does Ax = 2e₁ − e₃ have? (d) Is Ax = e₂ + e₄ consistent?

Full solutiontap
  1. (a) Col A is a subspace containing e₁, e₂, e₃, so it contains Span{e₁, e₂, e₃}, which is 3-dimensional. It is not all of ℝ⁴ (misses e₄). So Col A = Span{e₁, e₂, e₃} = {x₄ = 0}.
  2. (b) rank 3 ⇒ one free variable ⇒ infinitely many solutions.
  3. (c) 2e₁ − e₃ ∈ Col A (consistent) and there is a free variable ⇒ infinitely many.
  4. (d) If Ax = e₂ + e₄ had a solution x, and Ay = e₂, then A(x − y) = e₄, contradiction. Inconsistent.
Crack it · what it tests / common mistake

Col A is closed under combinations — that’s what makes the problem solvable without knowing A. For a square matrix, failing to be onto forces failing to be one-to-one (IMT preview).

2.2Hardertrue / false
  1. If v₁, v₂, v₃ ∈ ℝ³ and none is a multiple of another, then {v₁, v₂, v₃} is linearly independent.
  2. If {v₁, v₂, v₃} is linearly dependent, then v₃ is a linear combination of v₁ and v₂.
  3. No linear transformation ℝ⁵ → ℝ³ is one-to-one.
  4. If T is linear and {T(u), T(v)} is independent, then {u, v} is independent.
  5. The map T(x) = Ax + b with b ≠ 0 is linear.
Full solutiontap
  1. False. (1, 0, 0), (0, 1, 0), (1, 1, 0): pairwise non-parallel, but the third is the sum of the first two. The “no multiples” test only works for two vectors.
  2. False. v₁ = (1, 0), v₂ = (2, 0), v₃ = (0, 1). Dependent (2v₁ − v₂ = 0), but v₃ is not in Span{v₁, v₂}. The theorem only says some vector is a combination of the preceding ones.
  3. True. Its 3×5 matrix has at most 3 pivots, so at least 2 free variables ⇒ nontrivial kernel.
  4. True. Contrapositive: if au + bv = 0 nontrivially, apply T: aT(u) + bT(v) = 0 nontrivially.
  5. False. Linear maps send 0 to 0; here T(0) = b ≠ 0.
Crack it · what it tests / common mistake

Independence is about the whole set. Linear maps can destroy independence (e.g. the zero map) but can never create it.

2.6Harderproof

Full solutiontap
  1. Suppose c₁T(v₁) + ⋯ + cₖT(vₖ) = 0. By linearity T(c₁v₁ + ⋯ + cₖvₖ) = 0 = T(0).

3.2Hardermatrix algebra

Assume A, B, C, X are n×n and invertible. Solve for X: (B⁻¹XA)⁻¹ = CB. Then explain why “X = BC⁻¹A⁻¹ B⁻¹” type guesses fail.

Full solutiontap
  1. Invert a product in reverse order: (B⁻¹XA)⁻¹ = A⁻¹X⁻¹B.
  2. So A⁻¹X⁻¹B = CB. Right-multiply by B⁻¹: A⁻¹X⁻¹ = C. Left-multiply by A: X⁻¹ = AC.
  3. X = (AC)⁻¹ = C⁻¹A⁻¹.
  4. Check: A⁻¹X⁻¹B = A⁻¹(AC)B = CB ✓. Guesses fail because matrix multiplication isn’t commutative: you may only multiply both sides on the same side.
Crack it · what it tests / common mistake

Two errors to avoid: (PQ)⁻¹ = P⁻¹Q⁻¹ (wrong order) and “cancelling” matrices that aren’t adjacent.

3.3Hardertrue / false
  1. If A is n×n and Ax = b has at least one solution for every b, then the columns of A are independent.
  2. If A² = 0, then A is not invertible.
  3. If A, B are n×n and AB is invertible, then A is invertible.
  4. If A is 3×2 and B is 2×3, then AB can be invertible.
  5. If A is invertible, then A + I is invertible.
  6. (A + B)⁻¹ = A⁻¹ + B⁻¹ whenever all three inverses exist.
Full solutiontap
  1. True. Onto ⇒ pivot in every row ⇒ (square) pivot in every column ⇒ independent columns. IMT.
  2. True. If A⁻¹ existed, A = A⁻¹A² = 0, which is not invertible. (Or det(A)² = 0.)
  3. True. det A · det B = det(AB) ≠ 0. Or: A·(B(AB)⁻¹) = I, and a one-sided inverse of a square matrix is two-sided.
  4. False. ABx = 0 whenever Bx = 0, and B (2×3) has a nontrivial kernel. So AB (3×3) is singular. (BA, 2×2, can be invertible.)
  5. False. A = −I: invertible, but A + I = 0.
  6. False. A = B = I: (2I)⁻¹ = ½I ≠ 2I.
Crack it · what it tests / common mistake

The IMT applies only to square matrices. Non-square products like AB (3×3 from 3×2·2×3) are rank-limited.
