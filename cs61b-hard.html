Real questions from the official exam archive, 2017–2026 · final Thu Dec 17 · the five mock finals are excluded

Mocks

How to do these

  1. Timed. Set a timer for the listed minutes and stop when it rings. Running over is a sign to review that topic.
  2. Closed notes, except the exam reference card (linked from the archive; from 2025 on, every exam uses the same card).
  3. Write code on paper first, with every line and brace, before opening anything. For traces, write down each intermediate state.
  4. Then check against the solution page and, if there is one, the walkthrough video. Redo any question you missed 2–3 days later.

Each unit is ordered hardest first and mixes code, trace, runtime, design and concept questions. Links open the exact PDF page. Some questions span the next page or two, so scroll. Tick the box on a card when you finish it; ticks are saved only in this browser.
