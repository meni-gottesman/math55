# Math 55 notes

Course notes for Math 55 (Discrete Mathematics), UC Berkeley, Fall 2026.
Live at <https://meni-gottesman.github.io/math55/>.

All 16 lectures: logic, proofs, sets and functions, infinity, number theory through RSA,
induction and recursion, counting, combinatorial proofs and probability. Every section has a one-line gist, definitions, analogies,
worked examples, and a short check-yourself with hints and answers. Includes a Midterm 2
plan with a readiness check, three practice midterms with solutions, an exam-day sheet
and a list of common mistakes.

Also includes a homework playbook for HW 1–6 (each problem condensed, with its key idea
and answer).

One self-contained page, no build step.
