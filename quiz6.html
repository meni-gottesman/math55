Part 1 · Expected value & variance

Lecture 20 and Rosen 7.4. You already know probability of events; now we attach numbers to outcomes and average them.

1Random variables

Big idea

A random variable is just a rule that turns each outcome into a number, so you can ask about averages and spreads.

X : S → ℝA function from the sample space S (all outcomes) to real numbers. It assigns the number X(s) to each outcome s.

The name is misleading: X is not random and not a variable. It’s a fixed function. The randomness is in which outcome happens.

Notation: p(X = r) means the probability of the event “X equals r”, i.e. the set of all outcomes s with X(s) = r. To compute it, list those outcomes and add their probabilities.

Example · two fair coins

X = number of heads. The four outcomes are equally likely (1/4 each).

OutcomeHHHTTHTT
X2110

So p(X = 2) = 1/4, p(X = 1) = 2/4 = 1/2 (two outcomes), p(X = 0) = 1/4.

Example · two fair dice

Y = (first die) − (second die). There are 36 equally likely ordered outcomes.

  1. p(Y = −5): only (1, 6) gives −5, so it’s 1/36.
  2. p(Y = 0): the dice match: (1,1), (2,2), …, (6,6). That’s 6 outcomes, so 6/36 = 1/6.
Same dice. What is p(Y = 3)?tap

3/36 = 1/12. First − second = 3 happens for (4,1), (5,2), (6,3).

2Expected value

Big idea

E(X) is the weighted average of X: each value counts in proportion to how likely it is. Repeat the experiment many times and the average of X settles near E(X).

E(X) = Σs∈S p(s) · X(s)
       = Σr r · p(X = r)Top line: add over outcomes. Bottom line: group outcomes by the value they give. Both give the same number; use whichever is easier.

How to compute it directly

  1. List every possible value r of X.
  2. Find p(X = r) for each. These must add to 1, a good check.
  3. Multiply each value by its probability and add.
Example · two coins, X = number of heads

E(X) = 0·¼ + 1·½ + 2·¼ = 0 + ½ + ½ = 1.

Makes sense: two coins, each heads half the time, so one head on average.

Example · one fair die

E(X) = (1 + 2 + 3 + 4 + 5 + 6)/6 = 21/6 = 7/2.

Note that E(X) = 3.5 is a value X can never take. An expected value is an average, not a likely outcome.

Example · dice difference, the long way

For Y = first − second, the values run from −5 to 5 with probabilities 1/36, 2/36, 3/36, 4/36, 5/36, 6/36, 5/36, …, 1/36. Each value r pairs with −r at the same probability, so they cancel and E(Y) = 0. The next section gets this in one line.

Trap

Don’t just average the possible values. For two coins, the values 0, 1, 2 average to 1 here by luck, but in general you must weight by probability. A biased coin with p(H) = 0.9 has E(heads in 2 flips) = 1.8, not 1.

You win $10 with probability 1/5 and lose $2 otherwise. What is your expected winnings?tap

10·(1/5) + (−2)·(4/5) = 2 − 1.6 = $0.40.

3Linearity of expectation

Big idea

The expected value of a sum is the sum of the expected values. Always. No independence needed. This is the single most useful fact on the quiz.

E(X1 + ⋯ + Xn) = E(X1) + ⋯ + E(Xn)
E(aX + b) = a·E(X) + bFor any random variables on the same sample space and any constants a, b.

Why it’s true

Write each expectation as a sum over outcomes and split the sum:

E(X1+X2) = Σ p(s)(X1(s)+X2(s))
= Σ p(s)X1(s) + Σ p(s)X2(s) = E(X1) + E(X2)

Nothing in that algebra cared whether X1 and X2 are related, which is why independence isn’t needed. Same idea for E(aX + b): pull out a, and Σ p(s)·b = b because the probabilities add to 1.

Example · dice difference in one line
  1. Let Y1 = first die and Y2 = second die, so Y = Y1 − Y2.
  2. Each die has expected value 7/2.
  3. E(Y) = E(Y1) − E(Y2) = 7/2 − 7/2 = 0.
Example · sum of three dice

E = 7/2 + 7/2 + 7/2 = 21/2. Listing all 216 outcomes would take forever; linearity takes one line.

Trap

Linearity works for sums, not products. E(XY) = E(X)E(Y) needs independence (section 6).

4The indicator trick (counting with linearity)

Big idea

To find the expected number of something, break the count into 0/1 pieces. The expected count is the sum of the probabilities of each piece happening.

Xk = 1 if event k happens, 0 if not  ⟹  E(Xk) = p(event k)Called an indicator random variable. Its expectation is 1·p + 0·(1 − p) = p.

The recipe

  1. Name what you’re counting: “X = number of ____.”
  2. Write X = X1 + ⋯ + Xn, one indicator per thing that could happen.
  3. Find p(each thing happens). Often they’re all equal.
  4. Add: E(X) = p1 + ⋯ + pn. Done, with no need to find the distribution of X.
Example · two coins again

X1 = 1 if coin 1 is heads; X2 = 1 if coin 2 is heads. Then X = X1 + X2 and E(X) = ½ + ½ = 1, matching section 2.

Example · Bernoulli trials (the big one)

n independent trials, each a success with probability p. Let X = number of successes.

  1. Xk = 1 if trial k succeeds, so X = X1 + ⋯ + Xn.
  2. E(Xk) = p·1 + (1 − p)·0 = p.
  3. E(X) = p + p + ⋯ + p = np.

100 coins with a 3/10 chance of heads: E = 100 · 0.3 = 30 heads.

Trap

The pieces are allowed to depend on each other. Don’t stop to check independence; linearity doesn’t need it.

Roll a fair die 12 times. Expected number of sixes?tap

Bernoulli trials with n = 12, p = 1/6: E = 12 · 1/6 = 2.

Flip a coin with p(H) = 0.2 ten times. Expected number of heads?tap

np = 10 · 0.2 = 2.

5Two lecture examples: records & chasing losses

Why new records are rare

100 people with different scores appear in a uniformly random order. A “record” is a score higher than every score before it. Let X = number of records. What is E(X)?

Solution
  1. Xk = 1 if the k-th score is a record. X = X1 + ⋯ + X100.
  2. The k-th score is a record exactly when it’s the largest of the first k. By symmetry, each of those k scores is equally likely to be the largest, so p = 1/k.
  3. E(X) = 1 + 1/2 + 1/3 + ⋯ + 1/100 = H100 ≈ 5.19.

Hn (the harmonic number) grows like ln n, so records get rarer and rarer: about 5 in 100 people.

Expected number of records among 4 people?tap

1 + 1/2 + 1/3 + 1/4 = 25/12 ≈ 2.08.

Chasing losses (the “martingale” — don’t do this)

Roulette: win your bet with probability 0.48, lose it with probability 0.52. Bob bets $1; each time he loses he doubles the bet. When he finally wins, he’s up exactly $1, since 2k − (1 + 2 + ⋯ + 2k−1) = 2k − (2k − 1) = 1.

Why it fails
  • Every single bet has expected value 0.48 − 0.52 = −$0.04 per dollar. By linearity, a sum of losing bets is a losing strategy.
  • The rare disaster is huge: losing 10 in a row (probability 0.5210 ≈ 0.0014) costs 1 + 2 + ⋯ + 512 = $1023. Repeat the strategy enough times and that streak becomes likely.

6Independent random variables

Big idea

X and Y are independent if knowing the value of one tells you nothing about the other.

p(X = r1 and Y = r2) = p(X = r1) · p(Y = r2)…for every pair of values r1, r2. One failing pair is enough to show they’re not independent.
Independent · two dice

X = first die, Y = second die. For any values, p(X = r1, Y = r2) = 1/36 = (1/6)(1/6). ✓

Not independent · heads vs. tails

Flip two coins. X = number of heads, Y = number of tails (so X + Y = 2 always).

  1. p(X = 1) = 1/2 and p(Y = 1) = 1/2.
  2. p(X = 1 and Y = 1) = p({HT, TH}) = 1/2.
  3. But (1/2)(1/2) = 1/4 ≠ 1/2, so not independent. Makes sense: knowing X tells you Y exactly.

Products of independent variables

X, Y independent  ⟹  E(XY) = E(X)·E(Y)

Why: E(XY) = Σ r1r2 · p(X = r1, Y = r2). Independence lets you split the probability into p(X = r1)p(Y = r2), and then the double sum factors into (Σ r1p(X = r1))(Σ r2p(Y = r2)) = E(X)E(Y). That splitting step is the only place independence is used.

Trap · it fails without independence

Heads vs. tails again. XY = 0 for HH and TT, and XY = 1·1 = 1 for HT and TH.

E(XY) = ½, but E(X)E(Y) = 1·1 = 1. Not equal.

7Variance & standard deviation

Big idea

E(X) tells you the center. Variance tells you how spread out X is around that center: the average squared distance from E(X).

V(X) = Σs (X(s) − E(X))² · p(s)
σ(X) = √V(X)σ is the standard deviation, in the same units as X. Variance is never negative, and it’s 0 only if X is constant.
Example · two coins, X = heads (definition)

E(X) = 1. Squared distances: TT → (0−1)² = 1, HT/TH → 0, HH → (2−1)² = 1.

V(X) = ¼·1 + ½·0 + ¼·1 = ½.

The shortcut formula (use this one)

V(X) = E(X²) − E(X)²“Mean of the square minus square of the mean.” Proof: expand (X − E(X))², use linearity, and the middle term −2E(X)·E(X) combines with +E(X)² to leave −E(X)².
  1. Compute E(X).
  2. Compute E(X²) = Σ r² p(X = r): square the values, keep the same probabilities.
  3. Subtract: E(X²) − E(X)².
Example · one fair die
  1. E(X) = 7/2.
  2. E(X²) = (1 + 4 + 9 + 16 + 25 + 36)/6 = 91/6.
  3. V(X) = 91/6 − 49/4 = 182/12 − 147/12 = 35/12 ≈ 2.92.

Scaling and shifting

V(aX + b) = a² · V(X)Shifting by b doesn’t change the spread. Scaling by a multiplies distances by a, so squared distances by a² (Rosen 7.4).
Trap

E(X²) is not E(X)². For a die, 91/6 ≈ 15.17 vs. 49/4 = 12.25. Their difference is exactly the variance.

X is 0 or 10, each with probability ½. Find V(X) and σ(X).tap

E(X) = 5, E(X²) = ½·0 + ½·100 = 50. V = 50 − 25 = 25, σ = 5. Every value sits exactly 5 from the mean, which matches σ.

8Variance of a sum (Bienaymé’s formula)

Big idea

For independent variables, variances add, just like expectations. Without independence, they generally don’t.

X1, …, Xn independent  ⟹
V(X1 + ⋯ + Xn) = V(X1) + ⋯ + V(Xn)

Why (two variables, as in lecture)

  1. V(X1+X2) = E((X1+X2)²) − (E(X1) + E(X2))².
  2. Expand both squares. The first gives E(X1²) + 2E(X1X2) + E(X2²); the second gives E(X1)² + 2E(X1)E(X2) + E(X2)².
  3. Independence makes E(X1X2) = E(X1)E(X2), so the cross terms cancel.
  4. What’s left is (E(X1²) − E(X1)²) + (E(X2²) − E(X2)²) = V(X1) + V(X2).
Example · sum of two dice

The dice are independent, each with variance 35/12. V = 35/12 + 35/12 = 35/6.

Example · Bernoulli trials (the big one, again)
  1. Indicators again: X = X1 + ⋯ + Xn, with Xk = 1 on success.
  2. Xk is 0 or 1, so Xk² = Xk and E(Xk²) = p.
  3. V(Xk) = p − p² = p(1 − p).
  4. The trials are independent, so add: V(X) = np(1 − p).

100 coins with p = 0.3: V = 100 · 0.3 · 0.7 = 21, so σ ≈ 4.58. Expect about 30 ± 4.6 heads.

Trap

Heads + tails of two coins is always 2, so V(X + Y) = 0, but V(X) + V(Y) = ½ + ½ = 1. They aren’t independent, so the formula doesn’t apply.

10 flips with p(H) = 0.2. Variance of the number of heads?tap

np(1−p) = 10 · 0.2 · 0.8 = 1.6.

9Chebyshev’s inequality

Big idea

If the variance is small, X can’t often be far from its mean. Chebyshev turns that into a number, using only E(X) and V(X).

p( |X − E(X)| ≥ r ) ≤ V(X) / r²For any random variable X and any r > 0. “The chance of landing at least r away from the mean is at most variance over r².”

Why it’s true

Let A be the set of outcomes where |X(s) − E(X)| ≥ r. Then

V(X) = Σall s (X(s) − E(X))² p(s)
≥ Σs∈A (X(s) − E(X))² p(s)
≥ Σs∈A r² p(s) = r² · p(A)

Dropping outcomes outside A can only shrink the sum (every term is ≥ 0), and inside A each squared distance is at least r². Divide by r² to get the inequality.

How to use it

  1. Find E(X) and V(X), usually with sections 4 and 8.
  2. Rewrite the question as “at least r away from the mean” to identify r.
  3. Compute V(X)/r². That’s an upper bound, not the exact probability.
Example · 100 fair coins

X = heads: E = 50, V = 100 · ½ · ½ = 25. Probability of being 10 or more away from 50?

p(|X − 50| ≥ 10) ≤ 25/10² = 1/4. (The true value is about 0.057; Chebyshev is safe but loose.)

Example · n fair coins (Rosen)

E = n/2, V = n/4. Take r = √n: p(|X − n/2| ≥ √n) ≤ (n/4)/n = 1/4, for every n.

Example · one die

E = 7/2, V = 35/12. Rolling a 1 or a 6 means being 2.5 away. p ≤ (35/12)/(2.5)² = 7/15 ≈ 0.47. True value: 2/6 = 1/3. ✓ The bound holds.

Trap

Square r in the denominator, and use V, not σ. And the answer is “≤”: never claim the bound is the exact probability.

Part 2 · Recurrence relations

Thursday’s lecture (Rosen 8.1–8.2). Two skills: set up a recurrence from a word problem, and solve one with the characteristic equation.

10What a recurrence relation is

Big idea

A recurrence defines each term of a sequence from earlier terms. Add enough starting values and the whole sequence is determined.

  • Recurrence relation: a rule giving an in terms of a0, …, an−1. Example: an = an−1 + 3.
  • Initial conditions: the first few terms, given outright. Example: a0 = 2.
  • Solution: any sequence that satisfies the rule. A closed form is a direct formula for an, like an = 2 + 3n.

To check a proposed closed form, plug it into the rule and the initial conditions. Or just compute the first few terms both ways and compare.

Example · iterate to guess a formula

an = an−1 + 3, a0 = 2: terms 2, 5, 8, 11, … Each step adds 3, so an = 2 + 3n.

Trap

A degree-k recurrence (an uses the previous k terms) needs k initial conditions. One is not enough for an = an−1 + an−2.

11Setting up a recurrence (modeling)

Big idea

Ask: “How does a size-n object break into smaller ones?” Usually you split by the last step (or first step) and count each case using smaller sizes.

Example · compound interest

$1000 earns 5% a year. Pn = amount after n years.

Pn = Pn−1 + 0.05Pn−1 = 1.05Pn−1, P0 = 1000. Iterating gives Pn = 1000 · 1.05n (≈ $1628.89 after 10 years).

Example · Tower of Hanoi

Move n disks from peg 1 to peg 3, never putting a larger disk on a smaller one. Hn = minimum moves.

  1. Move the top n − 1 disks out of the way: Hn−1 moves.
  2. Move the biggest disk: 1 move.
  3. Move the n − 1 disks back on top of it: Hn−1 moves.

Hn = 2Hn−1 + 1, H1 = 1. Terms: 1, 3, 7, 15, 31 … which looks like 2n − 1 (proved in section 16).

Example · bit strings with no two consecutive 0s

an = number of length-n bit strings with no “00”. Split by the last bit:

  1. Ends in 1: the first n − 1 bits can be any valid string. That’s an−1 strings.
  2. Ends in 0: the bit before it must be 1 (otherwise “00”), so the string ends “10” and the first n − 2 bits are any valid string. That’s an−2 strings.
  3. The cases don’t overlap, so add them (sum rule): an = an−1 + an−2.
  4. Initial conditions by hand: a1 = 2 (0, 1) and a2 = 3 (01, 10, 11).

Then a3 = 5, a4 = 8, a5 = 13: Fibonacci numbers.

Trap

Check that your cases are disjoint and cover everything, and compute the initial conditions by actually listing small cases.

Write a recurrence for the number of length-n bit strings that contain no “11”.tap

Same argument with 0 and 1 swapped: bn = bn−1 + bn−2, b1 = 2, b2 = 3. Ends in 0 → any valid string of length n−1; ends in 1 → must end “01”.

12Linear homogeneous recurrences & the characteristic equation

Big idea

For a certain nice kind of recurrence, guessing an = rn turns the whole problem into solving a polynomial.

an = c1an−1 + c2an−2 + ⋯ + ckan−kLinear: each earlier term appears to the first power, multiplied by a number. Homogeneous: no extra term that isn’t a multiple of some aj. Constant coefficients: the c’s are fixed numbers, not depending on n. Degree k (with ck ≠ 0).
RecurrenceLinear homogeneous, constant coeff.?
an = an−1 + an−2Yes, degree 2
an = an−5Yes, degree 5
an = an−1 + an−22No: not linear (squared term)
Hn = 2Hn−1 + 1No: not homogeneous (the +1)
Bn = nBn−1No: coefficient n isn’t constant

Where the characteristic equation comes from

  1. Guess an = rn in an = c1an−1 + c2an−2.
  2. You get rn = c1rn−1 + c2rn−2.
  3. Divide by rn−2: r² = c1r + c2.
r² − c1r − c2 = 0The characteristic equation. Its solutions are the characteristic roots. Each root r gives a solution rn.

Fast way to write it: replace an by rk, an−1 by rk−1, …, an−k by 1, then move everything to one side.

Trap · signs

For an = 5an−1 − 6an−2 the equation is r² − 5r + 6 = 0. Both signs flip when you move the terms over.

13Solving: two distinct roots

roots r1 ≠ r2  ⟹  an = α1r1n + α2r2nEvery solution has this form. The constants α1, α2 are pinned down by the two initial conditions.

The recipe (memorize this)

  1. Write the characteristic equation and find its roots.
  2. Write the general form an = α1r1n + α2r2n.
  3. Plug in n = 0 and n = 1 (or whichever initial conditions you’re given) to get two equations.
  4. Solve for α1, α2.
  5. Check by computing a2 from the recurrence and from your formula.
Example · an = 5an−1 − 6an−2, a0 = 1, a1 = 4
  1. r² − 5r + 6 = (r − 2)(r − 3) = 0, so r = 2, 3.
  2. an = α12n + α23n.
  3. n = 0: α1 + α2 = 1. n = 1: 2α1 + 3α2 = 4.
  4. Subtract twice the first from the second: α2 = 2, then α1 = −1.
  5. an = 2·3n − 2n. Check: recurrence gives a2 = 20 − 6 = 14; formula gives 18 − 4 = 14. ✓
Example (Rosen) · an = an−1 + 2an−2, a0 = 2, a1 = 7
  1. r² − r − 2 = (r − 2)(r + 1) = 0, so r = 2, −1.
  2. α1 + α2 = 2 and 2α1 − α2 = 7. Adding: 3α1 = 9, so α1 = 3, α2 = −1.
  3. an = 3·2n − (−1)n. Check a2: 7 + 4 = 11 and 12 − 1 = 11. ✓
Example · Fibonacci

fn = fn−1 + fn−2, f0 = 0, f1 = 1. Roots of r² − r − 1 = 0 are (1 ± √5)/2. Solving for the α’s gives

fn = (1/√5)·((1+√5)/2)n − (1/√5)·((1−√5)/2)n

Irrational roots are fine; the recipe is identical.

Solve an = 7an−1 − 10an−2, a0 = 2, a1 = 7.tap

r² − 7r + 10 = (r − 2)(r − 5), roots 2 and 5. α1 + α2 = 2, 2α1 + 5α2 = 7 → α1 = α2 = 1.

an = 2n + 5n. Check a2: 49 − 20 = 29 = 4 + 25. ✓

14Solving: a repeated root

Big idea

If both roots are the same number r0, then α1r0n + α2r0n is really just one term, which can’t fit two initial conditions. The fix: the second solution is n·r0n.

double root r0  ⟹  an = α1r0n + α2·n·r0n = (α1 + α2n) r0n

You spot a repeated root when the quadratic is a perfect square, like r² − 4r + 4 = (r − 2)².

Example · an = 4an−1 − 4an−2, a0 = 1, a1 = 6
  1. r² − 4r + 4 = (r − 2)² = 0: double root r0 = 2.
  2. an = (α1 + α2n)2n.
  3. n = 0: α1 = 1. n = 1: (1 + α2)·2 = 6, so α2 = 2.
  4. an = (1 + 2n)2n. Check a2: 24 − 4 = 20 and 5·4 = 20. ✓
Example (Rosen) · an = 6an−1 − 9an−2, a0 = 1, a1 = 6

(r − 3)² = 0. α1 = 1 and (1 + α2)·3 = 6, so α2 = 1. an = (1 + n)3n.

Trap

Writing α1r0n + α2r0n for a repeated root. The equations will be inconsistent. You need the extra n.

Solve an = −6an−1 − 9an−2, a0 = 1, a1 = 0.tap

r² + 6r + 9 = (r + 3)², double root −3. an = (α1 + α2n)(−3)n. α1 = 1; (1 + α2)(−3) = 0 → α2 = −1.

an = (1 − n)(−3)n. Check a2: −6·0 − 9·1 = −9 and (−1)(9) = −9. ✓

Same recipe, bigger polynomial. A degree-k recurrence has a degree-k characteristic equation and needs k initial conditions.

root r with multiplicity m contributes
(α0 + α1n + ⋯ + αm−1nm−1) rnDistinct roots: m = 1, a plain αrn. Double root: (α0 + α1n)rn. Triple root: up to n². Add up the contributions of all roots.
Example (Rosen) · an = 6an−1 − 11an−2 + 6an−3, a0 = 2, a1 = 5, a2 = 15
  1. r³ − 6r² + 11r − 6 = (r − 1)(r − 2)(r − 3). Tip: test small integers like r = 1 first.
  2. an = α1 + α22n + α33n.
  3. Three equations from n = 0, 1, 2 give α1 = 1, α2 = −1, α3 = 2.
  4. an = 1 − 2n + 2·3n. Check a3: 90 − 55 + 12 = 47 and 1 − 8 + 54 = 47. ✓

16Nonhomogeneous recurrences

Big idea

When there’s an extra term F(n) (like the +1 in Hanoi), find one solution that handles F(n), then add the general solution of the recurrence without F(n).

an = c1an−1 + ⋯ + ckan−k + F(n)
all solutions = an(p) + an(h)(p) = one particular solution. (h) = general solution of the associated homogeneous recurrence (drop F(n)), found with sections 13–15.

The recipe

  1. Solve the homogeneous part (drop F(n)) to get an(h) with unknown α’s.
  2. Guess a particular solution shaped like F(n), with unknown coefficients (table below). Plug it in and solve for them.
  3. Add the two, then use the initial conditions to find the α’s.

Example · Tower of Hanoi, Hn = 2Hn−1 + 1, H1 = 1
  1. Homogeneous: Hn = 2Hn−1 → α·2n.
  2. F(n) = 1 is constant, so try A: A = 2A + 1 → A = −1.
  3. General: Hn = α·2n − 1. H1 = 1 gives 2α − 1 = 1, α = 1.
  4. Hn = 2n − 1, matching 1, 3, 7, 15, … ✓
Example (Rosen) · an = 3an−1 + 2n, a1 = 3
  1. Homogeneous: α·3n.
  2. F(n) = 2n is degree 1, so try cn + d: cn + d = 3(c(n−1) + d) + 2n. Match the n terms: c = 3c + 2 → c = −1. Match constants: d = −3c + 3d → d = −3/2.
  3. General: an = α·3n − n − 3/2. a1 = 3 gives 3α − 5/2 = 3, α = 11/6.
  4. an = (11/6)·3n − n − 3/2. Check a2: 9 + 4 = 13 and 16.5 − 3.5 = 13. ✓
Trap

17Bayes refresher

From Lecture 19, and HW 9 leans on it, so it could reappear.

p(F | E) = p(E | F)p(F) / [ p(E | F)p(F) + p(E | F̄)p(F̄) ]Numerator: the way E happens through F. Denominator: all the ways E happens (total probability).
Example · medical test

1% of people have a disease. The test catches 99% of cases but also flags 2% of healthy people. You test positive. Chance you’re sick?

  1. Sick and positive: 0.01 · 0.99 = 0.0099.
  2. Healthy and positive: 0.99 · 0.02 = 0.0198.
  3. p(sick | +) = 0.0099 / (0.0099 + 0.0198) = 1/3.

Only 1/3, because healthy people vastly outnumber sick ones.

Trap

p(E | F) and p(F | E) are different: 0.99 vs. 1/3 above.
